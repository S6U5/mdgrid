# Obsidian Bases の対応範囲

[English](obsidian-bases.md)

mdgrid は Obsidian Bases のファイル(`.base`)を開き、その table ビューを表で見せる。`.base` には公開された文法が無く、Obsidian の版で意味が変わりうるので、table ビューのよく使う部分を正しく扱い、それ以外は正直に未対応と出す。推測で行や値を作らない。

この文書は、mdgrid が解釈するものと解釈しないものの一覧。下の関数・メソッド・`file` のプロパティの一覧は、式の読み取りと試験(`tests/test_bases_docs.rs`)で突き合わせている。読み取りに関数を足してこの文書を直さないと試験が落ち、読み取りが受け付けない関数をここに書いても落ちる。

mdgrid は既にある `.base` を書き換えない(ビューの書き出しは、利用者が名前を決めた新しい `.base` を作る)。知らないキーはエラーにせず無視する。

## 探すノート

行は `.base` の属する保管庫のノート。保管庫の根は、`.base` のあるフォルダから上へたどって最初に `.obsidian/` を持つフォルダで、その下の全ノートを読む。`.obsidian/` が見つからないとき(設定のフォルダを除いて写した保管庫など)は `.base` のあるフォルダの下だけを探すので、`file.inFolder("Projects")` のような絞り込みが何にも当たらないことがある。そのときビューが空なら、探したフォルダを知らせる(画面の下の行と、`--print` では stderr)。直すには、保管庫の根に空の `.obsidian/` フォルダを作る。

Obsidian と同じく、名前が `.` で始まるフォルダ(`.obsidian`・`.git`・`.trash` など)の中は探さない。`node_modules` も探さないので、コードのリポを開いても依存のパッケージの文書は行にならない。起動の引数に渡したフォルダは、名前が `.` で始まっても探す。

## 読む項目

一番外:

| キー | mdgrid での扱い |
|---|---|
| `filters` | 全部のビューに効く。ビューの `filters` と AND でつなぐ。 |
| `formulas` | 名前の付いた式。`formula.<名前>` の列として出せ、並べ替えとグループ分けに使え、ほかの式から参照できる。 |
| `properties` | `displayName` だけを読み、列の見出しにする。キーは `status` とも `note.status` とも書ける。displayName の無い列は Obsidian の既定の見出し(式の列は式の名前、`file.name` は `file name`、`file.ctime` は `created time` など)。`--print --format json` の鍵も同じ。 |
| `views` | ビューの並び。ビューごとにタブになり、起動時は先頭のビューを開く。 |
| `summaries` | 式で書いた集計(`values.mean()` など)は評価しない。それを使うビューも開き、下の帯に未対応と出る。[集計](#集計)を見る。 |

ビューの中:

| キー | mdgrid での扱い |
|---|---|
| `type` | `table` でなければならない。[ビューの型](#ビューの型)を見る。 |
| `name` | タブの名前。 |
| `filters` | そのビューの絞り込み。 |
| `order` | 列の並び。ノートのキー(`status` か `note.status`)・`file.*`・`formula.*`。`order` が無ければ、`file.name` とノートにあるフロントマターの全キー。 |
| `sort` | `property` と `direction`(`ASC` か `DESC`。大文字小文字は問わず、ほかは `ASC`)の並び。先のものが優先。 |
| `groupBy` | `property` と `direction`。値ごとの見出しの下にまとめ、空の値は `(空)` にまとめる。まとまりの中は `sort` の順。 |
| `limit` | 整数。最後に、全体の行数に効く。 |
| `summaries` | 列(`estimate`・`note.estimate`・`file.*`・`formula.*`)から組み込みの集計の名前へのマップ。[集計](#集計)を見る。 |

`filters`(一番外とビューの両方)は、式の文字列か、`and`・`or`・`not` のマップ。それぞれの中は式の文字列か、さらにマップの並び。1つのマップに複数あれば AND でつなぐ。`not` は、中のどれも真でない行を残す。マップにほかのキーがある・形が違うときは、そのビューを開かない([解釈しないもの](#解釈しないもの)を見る)。絞り込みは、式が `if` と同じ真偽の規則で真の行だけを残す(`null`・`false`・`0`・空の文字列は偽)。

ノートのキーで並べるときは、向きにかかわらず、列の型に合う値(指定の向き)→ 型に合わない値(文字の昇順)→ 空の値 の順。`formula.*`・`file.*` で並べるときは列の型が無いので、型の違う値は型の順(真偽・数・期間・日付と日時・文字列・リスト)に並び、`DESC` ではその順も含めて逆になる。空の値(`null`・空の文字列・空のリスト)はどちらでも最後。鍵が同じ行は元の順を保つ。

ほかのキー(`columnSize`・`rowHeight`・mdgrid の知らないキーなど)は無視する。mdgrid はそのファイルを書き換えないので、消えることもない。

## ビューの型

`table` だけ。ほかの `type`(`cards`・`list`・`map`・プラグインのビューなど)や `type` の無いビューは開かない。タブには並ぶが、表の欄に理由(例: `cards のビュー「Gallery」は未対応(mdgrid は table のビューだけ)`)が出て、下の帯に `[` `]` でほかのビューへ移るよう案内が出る。これらのビューを表の見た目で作り直すことはしない。

## 演算子

| 演算子 | 意味 |
|---|---|
| `==` `!=` | 等しい・等しくない。どの型にも使え、型が違えば等しくない(日付は例外。下を見る)。`===`・`!==` は `==`・`!=` と同じに読む。 |
| `<` `<=` `>` `>=` | 数・文字列・真偽・期間・日付と日時の大小。期間と数はミリ秒として比べる。ほかの型の組は `null`。 |
| `&&` `\|\|` `!` | かつ・または・でない。真偽は `if` と同じ規則。 |
| `+` `-` `*` `/` `%` | 数の算術。`+` は文字列(と、文字列と数)をつなぐ。0 での割り算とあふれは `null`。 |
| `-x` `+x` | 単項のマイナスとプラス。 |
| `( )` | 括弧。`*` `/` `%` が `+` `-` より強く、次に比較、`==` `!=`、`&&`、`\|\|` の順。同じ強さは左から結ぶ。 |
| `x[i]` | リストの `i` 番目(0 から数える)。 |

日付の計算:

- 日付 `+`・`-` 期間の文字列(`due + "1d"`・`today() - "2 weeks"`・`now() + "1d 3h"` など)。単位は `y`/`year`・`M`/`month`・`w`/`week`・`d`/`day`・`h`/`hour`・`m`/`min`/`minute`・`s`/`sec`/`second`(複数形と `yr`・`hr`・`hrs`・`mins`・`secs` も可)。月と年は暦で足し、月の終わりを越える日はその月の最後の日にする。
- 日付 `+`・`-` `duration()` の値(`due + duration("1d")` など)。`duration()` の値どうしも足し引きできる。
- 日付 `-` 日付は期間(ミリ秒)。
- 期間 `*`・`/` 数は期間(1秒に満たない期間は `ms` で見せる)。日の数を出すには `number()` を使う: `number(due - today()) / 86400000`。

値:

- 書ける値: 文字列(`"..."` か `'...'`。`\n`・`\t`・`\r` が使える)・数・`true`・`false`・`null`・リスト `[a, b]`。
- 参照: 素の名前か `note.名前` はフロントマターのキー。空白のあるキーは `note["a b"]`。`formula.名前`(か `formula["名前"]`)は formula。`file.name` などは [file のプロパティ](#file-のプロパティ)にある。無いキーは `null`。
- フロントマターの `YYYY-MM-DD` の形の文字列は日付、`YYYY-MM-DDTHH:MM(:SS)` は日時(Obsidian と同じく地域の時刻)として読む。`today()` と `now()` も地域の時刻。比較と `+`・`-` で片方が日付・日時、もう片方が文字列なら、文字列も日付として読む。

型の合わない演算は止まらずに `null` になる。

## 関数

- `if(条件, 真のとき, 偽のとき)`: 条件が真なら2つ目、偽なら3つ目。3つ目は省けて、そのときは `null`。
- `date(文字列)`: `YYYY-MM-DD` を日付、`YYYY-MM-DDTHH:MM(:SS)` を日時として読む。日付はそのまま。ほかは `null`。
- `now()`: 今の日時。
- `today()`: 今日の日付。
- `duration(文字列)`: `"1d"`・`"2 weeks"` などの期間の文字列をミリ秒にする(1か月は 30 日、1年は 365 日とする)。
- `number(値)`: 期間はミリ秒、日付・日時は 1970-01-01 からのミリ秒、`true`・`false` は 1・0、数として読める文字はその数。ほかは `null`。
- `max(a, b, ...)`: 数のうち一番大きいもの。数でない値が1つでもあれば `null`。
- `min(a, b, ...)`: 数のうち一番小さいもの。数でない値が1つでもあれば `null`。
- `list(値)`: リストはそのまま。ほかの値は、その値1つのリストにする。

## メソッド

- `contains(値)`: 文字列ならその文字を含むか、リストなら等しい要素があるか。
- `containsAll(a, b, ...)`: 全部を含むか。
- `containsAny(a, b, ...)`: どれか1つでも含むか。
- `isEmpty()`: `null`・空の文字列・空のリストなら真。
- `toString()`: 値を文字列にする。
- `lower()`: 文字列を小文字にする。文字列でなければ `null`。
- `upper()`: 文字列を大文字にする。`status.upper() == "ACTIVE"` を絞り込みに使える。
- `title()`: 文字列の語ごとに、先頭を大文字、残りを小文字にする。
- `trim()`: 文字列の両端の空白を除く。
- `startsWith(文字)`: 文字列がその文字で始まるか。
- `endsWith(文字)`: 文字列がその文字で終わるか。
- `slice(始め, 終わり)`: 文字列かリストの、始めから終わりの手前まで。終わりは省ける。負の数は後ろから数える。
- `replace(パターン, 置き換え)`: 文字列の中のパターンの文字を全部置き換える。正規表現は未対応。
- `split(区切り, n)`: 文字列を区切りの文字で切ってリストにする(n があれば n 個まで)。正規表現は未対応。
- `reverse()`: リストを逆の順にする。文字列なら文字を逆の順にする。
- `round(桁)`: 数を一番近い整数に丸める。桁があれば小数のその桁まで。
- `floor()`: 数を切り下げる。
- `ceil()`: 数を切り上げる。
- `abs()`: 数の絶対値。
- `date()`: 日付・日時を日付にする(時刻を落とす)。
- `time()`: 日付・日時の時刻を `HH:mm:ss` の文字にする(日付なら `00:00:00`)。
- `format(形)`: 日付・日時を文字にする。形は Moment の記号(名前は英語)を読む: `YYYY` `YY` `Q` `MMMM` `MMM` `MM` `M` `DDDD` `DDD` `DD` `Do` `D` `dddd` `ddd` `dd` `d` `e` `E` `HH` `H` `hh` `h` `A` `a` `mm` `ss` `SSS` `X` `x`、ISO の週 `GGGG` `WW` `W`、日曜始まりの週 `gggg` `ww` `w`(1月1日を含む週が第1週)。ほかの文字と `[...]` の中はそのまま。
- `join(区切り)`: リストの要素を区切りでつないだ文字。
- `unique()`: リストから重なる要素を除く(それぞれ最初のものを残す)。
- `sort()`: リストを小さい順に並べる。
- `flat()`: リストの中のリストを1段開く。
- `length`: 文字列の文字数か、リストの要素の数。括弧を付けずに書く(`tags.length`)。
- `year`: 日付・日時の年。括弧を付けずに書く(`due.year`)。下の5つも同じ。
- `month`: 月(1 〜 12)。
- `day`: 日。
- `hour`: 時(日付なら 0)。
- `minute`: 分(日付なら 0)。
- `second`: 秒(日付なら 0)。

## file のプロパティ

値:

- `file.name`: 拡張子つきのファイル名。
- `file.basename`: 拡張子なしのファイル名。
- `file.ext`: 拡張子。
- `file.path`: 保管庫の根からのパス。
- `file.folder`: 保管庫の根からのフォルダ。
- `file.size`: 大きさ(バイト)。
- `file.mtime`: 最後に変えた日時。
- `file.ctime`: 作った日時。
- `file.tags`: ノートのタグ。フロントマターの `tags`(`tag`・`Tags` など大文字小文字を問わない。リストか、`,` と空白で区切った文字)と本文の `#タグ`。
- `file.links`: ノートがリンクする先のノートのリスト。本文とフロントマターの値の `[[名前]]`・`[[名前|表示]]`・`[[名前#見出し]]`・`![[名前]]`・`[文字](パス.md)` から拾う。コードの区画とインラインのコードの中、外のアドレスは拾わない。値は行き先のノートの保管庫の根からのパスの `.md` を除いたもの(例: `sub/c`)。行き先は、保管庫の根からのそのパスのノート(`[文字](パス)` はノートのフォルダからの相対を先に見る)、無ければ同じ名前のノートで、同じ名前が複数なら根に近い(次にパスの短い)もの。大文字小文字は問わない。どのノートにも当たらないリンクは書いた文字のまま(`[[無い]]` は `無い`)。同じ行き先は1つにまとめる。
- `file.backlinks`: このノートへリンクするノートのリスト(値は `.md` を除いたパス。リンクの決まりは `file.links` と同じ)。

`file` の関数:

- `file.hasTag(タグ, ...)`: どれかのタグを持てば真。先頭の `#` は除き、大文字小文字は問わず、入れ子のタグ `a/b` は親の `a` でも当たる。
- `file.inFolder(フォルダ)`: そのフォルダか、その下のフォルダにあれば真。
- `file.hasProperty(名前)`: フロントマターにそのキーがあれば真。
- `file.hasLink(ノート)`: そのノート(名前・パス・`this.file`)へリンクしていれば真。

## this

`.base` のファイルを直接開いたとき、`this` はその `.base` のファイル。`this.file` はそのパス、`this.file.name`・`this.file.basename`・`this.file.ext`・`this.file.path`・`this.file.folder`・`this.file.size`・`this.file.mtime`・`this.file.ctime` はノートと同じ意味の値(`this.file.tags` は空のリスト)。例: `file.inFolder(this.file.folder)` は `.base` と同じフォルダ(とその下)のノート、`file.links.contains(this.file)` は `.base` へリンクする(`[[Projects.base]]` か `[[P/Projects.base]]`。`.base` を名前かパスで指すリンクは `this.file` と同じ値になる)ノート。指す `.base` の無いところ(フォルダの mdgrid のビュー)では、`this` を使う式は未対応。

## 集計

ビューの `summaries` があると、表の下(下の帯のすぐ上)に1行の集計の行が出る。左のノートの列に `集計`(英語では `Summary`)、集計した列の下に集計の名前と値(例: `合計 18`・`最早 2026-10-05`。英語では Obsidian の名前で `Sum 18`・`Earliest 2026-10-05`)が、列の位置にそろって出る(横に送ると一緒に動く)。集計は今ビューに出ている行(ビューの絞り込み・ビューの設定・簡易の絞り込みのあと)で計算するので、絞り込むと値も変わる。ためた(保存前の)値も数える。`summaries` の無いビューには集計の行が無い。

```yaml
views:
  - type: table
    name: Open
    summaries:
      estimate: Sum
      due: Earliest
      done: Checked
```

組み込みの集計は Obsidian と同じ。型の合わない値は数えない。数える値が無いとき、数と日付の集計は空欄、数を数える集計は `0`。

| 名前 | 画面の名前 | 数えるもの | 値 |
|---|---|---|---|
| `Average` | 平均 | 数 | 平均 |
| `Min` | 最小 | 数 | 一番小さい数 |
| `Max` | 最大 | 数 | 一番大きい数 |
| `Sum` | 合計 | 数 | 合計 |
| `Range` | 範囲 | 数か日付 | `Max` − `Min`。日付の列では `Latest` − `Earliest` の期間 |
| `Median` | 中央値 | 数 | 真ん中の数(数が偶数なら真ん中の2つの平均) |
| `Stddev` | 標準偏差 | 数 | 母集団の標準偏差(個数で割る) |
| `Earliest` | 最早 | 日付と日時 | 一番早いもの |
| `Latest` | 最遅 | 日付と日時 | 一番遅いもの |
| `Checked` | チェックあり | 真偽 | `true` の数 |
| `Unchecked` | チェックなし | 真偽 | `false` の数 |
| `Empty` | 空 | どれでも | 空の値(`null`・キーが無い・空の文字列・空のリスト)の数 |
| `Filled` | 空でない | どれでも | 空でない値の数 |
| `Unique` | 種類 | どれでも | 空でない値の種類の数(数の `1` と文字の `"1"` は別) |

## 解釈しないもの

次のものは評価しない。推測で結果を作らない。

- Obsidian のほかの関数とメソッド。主なもの: `link()`・`icon()`・`image()`、メソッドの `map()`・`filter()`・`reduce()`・`relative()`・`toFixed()`・`repeat()`・`asFile()`・`linksTo()` など、`replace()`・`split()` に渡す正規表現。Obsidian の一覧は増えうる。この文書に無いものは未対応として扱う。
- `file` のプロパティの `file.embeds`・`file.properties`・`file.file` と、関数の `link()`。
- [this](#this) に並べた `this.file` とその値のほかの `this`、ノートに埋め込んだ base の `this`(mdgrid が開くのは `.base` のファイルだけ)。
- 式で書いた集計: 一番外の `summaries`(例: `customAverage: 'values.mean()'`)と、それを名前で使うビューの集計、組み込みでない名前。ビューは開き、下の帯の `未対応:` の後ろに並び、ほかの集計は出る。
- まとまりごとの集計。`groupBy` のあるビューでも集計の行は表全体の1行で、下の帯にそう出る。
- `table` 以外のビュー: `cards`・`list`・`map`・プラグインのビュー。
- ノートの中の `base` のコードブロック。mdgrid が開くのは `.base` のファイルだけ。

これらに出会ったときの画面(BV-7):

- `filters`(一番外かビュー)の中: そのビューは開かない。表の欄に、名前つきの理由が出る(例: `(このビューは開けない: ビュー「Open」の filters を評価できない: 未対応の関数・項目 .relative()(式: due.relative() == "yesterday"))`)。下の帯には、このビューは開けないと出る。ほかのビューは開けるので、`[` `]` で移る。
- 列(`order` の `formula.*` か `file.*`)の中: その列のセルは全部、値の代わりに薄い `?` を出し、編集できない。薄い `?` は空欄(キーが無い)とも、本当の値の `?` とも見分けられる。そのセルを選ぶと、下の帯に未対応の式が出る(薄い表示が出ない端末でも見分けられる)。列は下の帯の `未対応:` の後ろにも並ぶ。
- `sort` か `groupBy` の中: 全部の行でその鍵を空として扱い、下の帯にその鍵で並べられないと出る。
- 無い formula を参照する formula や、循環する formula も、同じく未対応として扱う。
- 式の文法の誤りも同じように出る(名前の代わりに理由が出る)。
