# キーの割り当て

[English](keys.md)

mdgrid の既定のキーの割り当てを、モードごとに並べる。設定のファイルでキーを割り当て直すときに書く動作の名前も、ここにある。mdgrid の中では `?` で同じ一覧をヘルプとして出せる(先頭に今押せるキー)。

## 割り当て直し

設定のファイルに `[keys.<モード>]` の表を作り、その下に `"キー" = "動作の名前"` と書く([設定の `keys`](config.ja.md#keys))。モードは下の節の見出し(`table`・`edit` など)、動作の名前は表の「動作」の列か、末尾の一覧のもの。

```toml
[keys.table]
"ctrl+f" = "search"   # Ctrl+F でも検索を始める
"a" = "none"          # "none" でキーを外す
"ctrl+n" = "new_note" # 新しいノートを a から Ctrl+N に移す
```

- キーは `"j"`・`"G"`・`"ctrl+s"`・`"shift+tab"`・`"pagedown"` のように書く。修飾キーとキーの名前の大文字小文字は問わない。Shift つきの英字は大文字で書く(`"G"`)。続けて押すキーは空白で区切る(`"g g"`)。下の表のキーの表記もそのまま書ける。`\` のキーは、TOML の基本の文字列では `"\\"`、リテラルの文字列では `'\'` と書く。
- 動作のあるキーに別の動作を書くと、その動作に置き換わる。動作の名前 `"none"` でキーを外せるので、外してから別の動作に使える。
- 動作を割り当てられるのは、その動作が既定でキーを持つモードだけ。同じモードで1つのキーに2つの動作は割り当てられず、1つのキーを続けて押すキーの最初のキーと兼ねることもできない(`g` と `g g`)。先にぶつかるキーを `"none"` で外す。
- どのモードにも抜ける動作(`table` なら `quit` か `palette`、`edit` なら `cancel` など)のキーを1本は残す。設定でそれが0本になるときは、既定のキーを残して警告する。
- 知らないモード・キー・動作は警告して飛ばす。
- 文字を打つモード(`edit`・`palette`・`search`・`filter`・`settings_input`・`list_select`)では、既定で文字1つのキーに動作が無く、続けて押すキーも書けない。

表では、日本語入力が有効なまま打った全角の英数字と記号は半角のキーと同じに働き、`、` と `・` は `,` と `/` と同じに働く。

## `freq`

選んだ列の頻度表(`%`)。値ごとに、行の数と、今見えている全部の行に対する割合を添え、多い順(同じ数は値の順)に並べる。リストのプロパティは要素ごとに数えるので、割合の合計は 100% を超えることがある。値の無い行は `(空)` として数える。数えるのは今の絞り込みのあとの行で、`,` や前の頻度表で絞った同じ値の絞り込みも効いたまま数える。`Enter` はその絞り込みを置き換えずに重ねるので、値に添えた数が、絞ったあとに出る行の数と同じになる。ノートの読み込みの途中は開かず、表を組み直したとき(外でノートが変わったときなど)は閉じる。

| キー | 動作 | 説明 |
|---|---|---|
| `Enter` | `run` | 選んだ値の行だけにして(`,` と同じ絞り込み)閉じる |
| `Esc` | `close` | 何もせずに閉じる |
| `j` | `down` | 次の値 |
| `Down` | `down` | 次の値 |
| `k` | `up` | 前の値 |
| `Up` | `up` | 前の値 |
| `g g` | `top` | 先頭の値へ |
| `G` | `bottom` | 末尾の値へ |

値をクリックするとその値の行だけにし、窓の外をクリックすると閉じるだけ。端末が狭くて窓が入らないときは開かず、理由を出す。絞り込みは `table` のモードの `Esc` で解ける。

## `relations`

関係マップ(`R`・`:relation_map`、または表を登録すると右上に出る **関係** のタブ)。登録した表(と今の表)を、行の数と列を書いた箱で並べ、ほかの表を指す列から矢印を引く。指す側に `N`、指される側に `1`(多対一)か `N`(多対多。リンクのリスト)。段組みは端末の大きさに合わせる: 幅 120 以上は表の一覧・マップ・詳細を並べ、80 以上はマップと詳細、それより狭いと表とつながりの一覧。高さ 30 以上なら、選んだつながりのつながった行を下に出す。

マウスでも操作できる: 表(一覧の行かマップの箱)をクリックすると選び、選んでいる表をもう一度クリックするとその表を開く。線・矢印・札(狭い画面ではつながりの行)をクリックするとそのつながりを選ぶ。つながった行をクリックするとそのノートを開く。ホイールで表を上下に選ぶ。

| キー | 動作 | 説明 |
|---|---|---|
| `Enter` | `run` | 選んだ表を開く |
| `Esc` | `close` | 表に戻る |
| `R` | `relation_map` | 表に戻る |
| `q` | `close` | 表に戻る |
| `j` | `down` | 次の表 |
| `Down` | `down` | 次の表 |
| `k` | `up` | 前の表 |
| `Up` | `up` | 前の表 |
| `l` | `right` | 選んだ表の次のつながり |
| `Right` | `right` | 選んだ表の次のつながり |
| `h` | `left` | 選んだ表の前のつながり |
| `Left` | `left` | 選んだ表の前のつながり |
| `?` | `help` | ヘルプを出す |

右上の **表** のタブをクリックすると表に戻る。

### パレットだけのコマンド

次のコマンドにはキーが無く、設定でも割り当てられない。コマンドのパレットから使う。

- `export_base` — mdgrid のビューを、名前を決めた新しい `.base` に書き出す(既にある `.base` は書き換えない)
- `import_base` — `.base` を選び、そのビューを mdgrid のビューとして取り込む
- `open_place` — 登録した表(`places.toml`)の一覧を出し、選んだ表を開く
- `register_place` — 今の表を、名前と分類を付けて登録する
- `open_link` — リンクのセルの行き先のノートを開く(行き先の表で、その行を選ぶ)
- `linked_rows` — 今のノートを指しているノートを、どの表のどの列からかと一緒に並べる
- `workspace_new` — 今の表で、ワークスペース(`workspaces.toml`)を作る
- `workspace_add` — 今の表をワークスペースに足す(選ぶか、新しい名前を打つ)
- `workspace_remove` — 今の表をワークスペースから外す
- `workspace_open` — ワークスペースを選び、その表を選んで、そのワークスペースの中で開く
