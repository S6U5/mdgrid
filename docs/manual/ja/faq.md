## セルの印は何?

| 印 | 意味 |
|---|---|
| (空欄) | ノートにそのキーが無い |
| `""` | 空の文字列 |
| `∅` | null(キーはあり、値が無い) |
| 値の前の `!` | 列の型に合わない値(そのまま見せ、勝手には変えない) |
| 値の前の `*` | 直したが、まだ保存していない |
| 値の前の `#` | 読むだけ(セルを選ぶと理由が出る) |
| 薄い `?` | mdgrid が評価できない `.base` の式 |
| `…⏎` | 改行を含む値(1行目だけ見せる) |

行の左: `>` は今の行、`+` は印を付けた行(`Space`・`v`)、`!` は外で変わったノート(か同期の競合ファイル)、`~` は直して元の位置に留めている行(保存か移動まで)。

## セルや行が直せない

セルを選ぶと、最下行に理由が出ます。よくあるもの:

- **行ごと読むだけ**: フロントマターが無い(か空。`[edit] add_frontmatter` を切っているとき)、BOM がある、改行コードが混ざっている、YAML として読めない、同じキーが2回ある、など。mdgrid は推して書くより断ります。全部の理由と例は[書き戻しの安全](../../safety.ja.md)にあります。
- **そのセルだけ読むだけ**: 入れ子の表、ブロックの文字列(`|`・`>`)、アンカーやタグ、`file.*`・`formula.*` の列、並びを保ったまま書き直せないリスト。[書き戻しの安全](../../safety.ja.md)の「読むだけの値」にあります。
- **全部が読むだけ**: `--readonly` か `--pick` で起動している。

`e` でノートをエディタで開けます(設定の `editor`、無ければ `$VISUAL`・`$EDITOR`・`vi`)。エディタを閉じると、mdgrid が読み直します。

## 直したのにファイルが変わらない

直した値は、保存するまで `*` の付いたためた変更です。`Ctrl+S` で差分を見て、`Enter` で書きます。ためた変更があるまま終わろうとすると、保存するか捨てるかを聞きます。その間にノートが外で変わっていたら、保存の確認でそのファイルにそう出て、選ばない限り(`o`)上書きしません。

## リンクの名前の前に `?` が付く

行き先のノートが見つかりません。mdgrid は行き先を、今のワークスペースの表(ワークスペースが無ければ登録した表)から名前で探し、Markdown のリンクやパスはパスで探します。綴りを確かめるか、行き先のフォルダをワークスペースに入れます。そのフォルダを開いてパレット(`:`)の **この表をワークスペースに足す** を選ぶか、`mdgrid <フォルダ> --add-to <ワークスペース>` を動かします。

## 関係マップに違う表が出る・何も出ない

関係マップは、今のワークスペースの表を描きます。使っているときは、ヘッダーに `· ワークスペース <名前>` が出ます。決まり方の順は、`-w <名前>` → フォルダかその上の印 `.mdgrid/workspace.toml` → `workspaces.toml` → 見つけた Obsidian の保管庫(`[workspace] detect = ["vault", "git"]` なら git のリポも)→ 登録した表 です。何も出ないときは、表を登録するかワークスペースに入れます。[ワークスペース](concepts.md#ワークスペース-どの表が一緒か)も見てください。

自動の表(`[[table]]` を書かない印や、見つけた保管庫の表)は、根の直下のノートのあるフォルダです。`.base` は自動では入れず、`node_modules`・`target` などのフォルダも外します。`.base` を入れたければ `[[table]]` に書きます。

## `.base` の列に `?` が出る

mdgrid がまだ評価できない式・絞り込み・集計の列です。セルを選ぶと、どの部分かが出ます。mdgrid が読むものは [Obsidian Bases の対応範囲](../../obsidian-bases.ja.md)にあります。ビューのほかの部分は動きます。

## 列がずれる・字が広すぎる

`○`・`※`・枠の線などは「幅があいまい」な字で、端末によって1桁にも2桁にも描かれます。2桁に描く端末なら `[terminal] ambiguous_wide = true` にします。枠が ASCII になり、全部がそろいます。チェックボックスや型の印(`☑ ◷ ◉ ⋮`)の字の形が崩れるときは、`[look.style]` の `check = "text"` と `icons = false` にします。

## 色がおかしい・色が出ない

- 色がまったく出ない: `NO_COLOR` がある、`TERM=dumb`、`--no-color` を付けた、設定に `color = false` がある。
- 色が変: 端末が true color に対応していないと、256色のうちいちばん近い色を使います。対応しているなら `COLORTERM=truecolor` にします。
- 前の見た目がよい: `look = "classic"`(と `cells = "plain"`)。[見た目を整える](appearance.md)を見てください。

## フォルダを開くのが遅い

最初の画面はすぐ出て、残りはヘッダーに進み具合を出しながら読み込みます。`Ctrl+G` で読み込みを止め、読んだ分の表を残せます。数万のノートで数秒です。関係マップを開くときはワークスペースの全部の表の全部のノートを読むので、2万のノートで1秒ほどかかります。

## `mdgrid workspace` で workspace という名前のフォルダが開く

そのとおりの動きです。ワークスペースの操作は旗(`--workspaces`・`--add-to`・`--remove-from`・`--remove-workspace`・`--init-workspace`・`-w`)なので、`workspace` という名前のフォルダもほかのフォルダと同じに開きます。

## やり直したい

- ある表の見た目(幅・隠した列・ビュー): **ビューの設定**(`o`)の **既定に戻す**、か `~/.local/state/mdgrid/` のその表の状態を消す。
- 設定: `~/.config/mdgrid/config.toml` をどけます。`mdgrid --print-config` で、全項目の既定値の入った新しい設定を出せます。
- 登録した表とワークスペース: `~/.config/mdgrid/` の `places.toml` と `workspaces.toml` を直すか消す。

どれをしても、ノートには触りません。
