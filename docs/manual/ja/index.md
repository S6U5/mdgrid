# mdgrid

[English](../en/index.md) · 画面つきでは https://s6u5.github.io/mdgrid/manual/ja/ で読めます(画面はそこで本物の mdgrid から撮り、リポには置きません)

Markdown のノートのフォルダを、ターミナルで表として開いて直す道具です。

![フォルダを開いたところ](images/table.svg)

## こんなとき

タスクのノートが 40 枚あって、終わったものの `status` を `done` にしたい。読書の記録に `rating` を付け忘れたノートが何枚かある。ブックマークをフォルダごとに眺めたい。どれも、1枚ずつエディタで開くには多すぎて、表計算に写すには惜しい。

mdgrid にフォルダを渡すと、ノートが行、フロントマターのキーが列の表になります。セルで `Enter` を押して直し、`Ctrl+S` で差分を見てから保存します。書くのは直した値の行だけ。キーの順もコメントも本文も、そのままです。ノートはただの Markdown のままなので、ふだんのエディタやノートの道具と同じフォルダを、閉じずに開けます。`.base` のビューもそのまま開きます。

## どう見えるか

表のほかに、まとまり(グループ)、フォルダの木、表どうしのつながりの図、列の値の分布、ノート1枚の詳細。木・関係マップ・値の分布・詳細はキー1つで、まとまりはビューの設定から切り替わり、`Esc` で表に戻ります。画面を1枚ずつ、[見せ方の一覧](views.md)に並べました。

## まず試す

[Releases](https://github.com/S6U5/mdgrid/releases/latest) のアーカイブを展開して `mdgrid` を PATH の通った所に置くのがいちばん早い道です(Rust があるなら `cargo install mdgrid --locked` でも入りますが、ビルドに数分かかります)。見本はリポにあります。

```sh
git clone https://github.com/S6U5/mdgrid && cd mdgrid
cp -R examples/studio /tmp/mdgrid-sample
mdgrid /tmp/mdgrid-sample/Tasks
```

「Northwind Studio」のタスクの表が出れば成功です。`j` `k` で動き、`Enter` で直し、`q` で終わります。写しの上なので、保存しても見本は変わりません。入れ方のほかの道と画面の読み方は[はじめかた](getting-started.md)に。

## 自分の場面で

タスク・ブックマーク・読書の記録・人と会議の4つのスターターが入っています。空のフォルダに印と雛形と見本を書き出すので、最初から表の形で始められます。

```sh
mdgrid ~/books --init-workspace --starter reading --with-samples
mdgrid ~/books
```

スターターは 0.4.0 からあります。やり方は[スターターから台帳を作る](tasks.md#スターターから台帳を作る)に。自分のノートがすでにあるなら、そのフォルダを渡すだけです。
