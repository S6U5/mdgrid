# 見せ方の一覧

[English](../en/views.md) · [目次](index.md)

同じノートを、画面を変えて見られます。切り替えはキー1つか、ビューの設定から。どの画面もノートには何も書かず、`Esc` で表に戻ります。ここでは画面を1枚ずつ並べました。やり方は各項のリンク先にあります。

## 表

![フォルダを開いたところ](images/table.svg)

いちばん基本の画面です。1行が1つのノート、列がフロントマターのキー。先頭の列はファイル名です。セルで `Enter` を押すとその場で直せて、下の帯に未保存の数と今押せるキーが出ます。

[はじめかた](getting-started.md#画面の見方)に画面の読み方があります。

## ビューのタブ

![.base を開く](images/base-tabs.svg)

列・絞り込み・並べ替えの組み合わせに名前を付けたものがビューで、表の上にタブで並び、`[` と `]` で行き来できます。`.base` を開けば、その中の table ビューがそのままタブに。自分で作ったビューは設定のフォルダに残り、ノートの横には置きません。

[見せ方を決めて保存する](tasks.md#見せ方を決めて保存する)

## まとまり(グループ)

![status ごとのまとまり](images/demo-group.svg)

列の値でまとめて、見出しの行で区切った形。見出しで `Enter` を押せば畳めます。`.base` のグループも同じ見た目になり、進み具合ごとにタスクを眺めるのに向いています。ビューに集計があれば、見出しの行の右にそのまとまりの小計が出て、畳んでも残ります。

[見せ方を決めて保存する](tasks.md#見せ方を決めて保存する)(ビューの設定の「並べ替え・グループ」)

## 木

![木の画面](images/tree.svg)

ワークスペースの印(`.mdgrid/workspace.toml`)の表に `tree = { path = "folder" }` と書いておくと、`T` でその列の階層(`bar > Dev > Web` など)がフォルダの木になります。左が木と件数、右が選んだフォルダのノートです。ブックマークや資料の整理に向いていて、組み込みのスターター bookmarks はこの形で作られます。木の画面は 0.4.0 からあります。

[設定の `tree`](../../config.ja.md)、[スターターから台帳を作る](tasks.md#スターターから台帳を作る)

## ガント

![ガントの画面](images/gantt.svg)

`C` で、今のビューの行を時間軸の横棒にします。始まりと終わりの列は印の `gantt = { start = "start", end = "due" }` で決め、設定が無くても `start`・`due` のような名前の日付の列から推定します。親子の字下げと WBS が効いていれば、その並び・番号・進み具合(棒の塗り)のまま。親に日付が無ければ子の範囲が親の棒になります。`+` `-` で日・週・月、`t` で今日へ。`r` で期間を今週・今月・四半期・全体と切り替えます。週と今週は、設定の `dates.week_start`(既定は日曜)の曜日から始まります。同じ操作は、窓の下の縁の帯(`◀ ▶`・単位・今日・期間)をクリックしても押せます。予定をずらすときは、行を選んで `H` `L` で棒を1単位動かし、`<` `>` で終わりを縮める・伸ばします。日付は表と同じく保存の前にためられ、`u` で取り消せます。ガントの画面は 0.4.0 からあります。

[キーの割り当て](../../keys.ja.md)の `gantt` の節、[設定](../../config.ja.md)

## カンバン

![カンバンの画面](images/kanban.svg)

`B` で、今のビューの行を状態ごとのレーンに札として並べます。レーンは列の決まり(`[rules.status] values`)の順なので、todo・doing・waiting・done がこの順に並び、札の無い状態にも空のレーンがあって、そこへ札を動かせます。`H` `L` で選んでいる札を隣のレーンへ動かすと、その行の状態が書き換わります。表のセルを直したときと同じく未保存としてたまり、保存するまでノートは変わりません。列は印の `kanban = { column = "status" }` で決め、設定が無くても `status` のような名前の列から推定します。カンバンの画面は 0.4.0 からあります。

見本のタスクの台帳の札には、名前の下に期限と優先度が出ています。印に `card = ["due", "priority"]` と書いた分で、本なら著者と進み、会議なら日時と出席者のように、表に戻らずに読みたい列を並べられます。値は表のセルと同じ見え方です。長い名前は2行まで折り返すので、問いのような長い題も頭だけで切れません。

[キーの割り当て](../../keys.ja.md)の `kanban` の節、[設定](../../config.ja.md)

## グラフ

![グラフの画面](images/chart.svg)

`P` で、今のビューの行を数えてグラフにします。状態ごとの件数、担当ごとの見積もりの合計、月ごとの期限の数を、表を数えずに一目で見られます。種類は棒・積み上げ棒・折れ線・散布図・ヒートマップの5つで、`Tab` で切り替え、`x` で分ける列、`y` で値(件数か数の列の合計)、`b` で内訳の列を変えます。数の列で分けると区間ごとの件数(ヒストグラム)に、積み上げ棒の `%` で割合になります。棒で `Enter` を押すと、その値の行だけに絞って表に戻ります。よく見るグラフは印の `chart = { kind = "line", x = "due", unit = "month" }` に書いておけて、複数書けば `[` `]` で移れます。書いていなくても、状態の列などから推し量って開きます。値に `[rules.<列>]` の名前とアイコンを付けていれば、棒の名前・凡例・ヒートマップの見出しも、表のまとまりの見出しと同じ「字 名前」で出ます。週の区切りは設定の `dates.week_start`(既定は日曜)の曜日から始まります。色はテーマの地に合わせて付くので、明るい地のテーマでもヒートマップの数が読めます。グラフの画面は 0.4.0 からあります。

[キーの割り当て](../../keys.ja.md)の `chart` の節、[設定](../../config.ja.md)

## 親子の字下げと WBS

ノートに `parent: "[[親]]"` があれば、ビューの設定の「親子」で、子を親の下に字下げして並べられます。`Z` で畳む・開く。同じ区画で WBS をオンにすると `1.2.1` の番号が付き、進み具合の列の値から割合を出します(子のある行は子孫の平均)。見本のノートには親子が無いので、ここには画面を置いていません。動きは[リリースの録画](https://github.com/S6U5/mdgrid/releases/latest/download/demo-tree.gif)で見られます。

[見せ方を決めて保存する](tasks.md#見せ方を決めて保存する)

## 関係マップ

![関係マップ](images/demo-relmap.svg)

`R` で、ワークスペースの表を箱、リンクの列を矢印にした図になります。どの表がどの表を指しているかを確かめ、`Enter` でその表へ移れます。親子のように同じ表の中を指す列は箱へ戻る矢印で、箱の列には型の印と、表の見出しと同じ列の名前が付きます。

[関係マップ](concepts.md#関係マップ)

## 縦に並べた表

![表を縦に並べる](images/stack.svg)

別の表を同じ画面の上下に4つまで並べます。表ごとに「表の名前 · ビュー · 行の数」の見出しが付き、`▶` の付いた表にだけキーが効きます。`Ctrl+w` `j`・`k` で表を移り、並べ方は名前を付けてページとして残せます。

[表を縦に並べる](tasks.md#表を縦に並べる)

## 値の分布

![列の値を数える](images/demo-freq.svg)

`%` を押すと、今の列の値ごとの件数と割合。`Enter` でその値の行だけに絞れます。status が何件ずつあるか、担当が偏っていないか、といったことを見るのに。

[キーの割り当て](../../keys.ja.md)の `freq` の節

## 1つのノートの詳細

![1つのノートの詳細](images/detail.svg)

`K` で、選んだ行の全部のキーと値を縦に並べます。列が多くて横に収まらないときの画面です。

[キーの割り当て](../../keys.ja.md)の `detail` の節

## 絞り込みの帯

![設定の帯](images/chips.svg)

効いている絞り込み・並べ替え・まとまりが、表の上に札で並びます。`f` で帯に入り、`Backspace` で1つ外せます。何で絞っていたか分からなくなる、ということがありません。

[探す・絞る・並べる](tasks.md#探す絞る並べる)

## 行番号・しましま・列の線

![行番号と列の区切り線](images/display-row-numbers.svg)

ビューの設定の「表示」で、行番号、一行おきの色、列の区切り線を付けられます。ビューごとに覚えます。

[見せ方を決めて保存する](tasks.md#見せ方を決めて保存する)

## 列の固定

![列を固定する](images/freeze-columns.svg)

`F` で、その列までを左に固定します。横に動かしても、ファイル名と status は見えたままです。

[キーの割り当て](../../keys.ja.md)の `table` の節

## テーマ・部品の形

![テーマ: Nord](images/theme-nord.svg)

色のテーマは 12 から選べ、札やチェックボックスの形も変えられます。変わるのは見た目だけで、文字と印は同じです。[見た目のカタログ](../../catalog/index.html)で見比べて、出てきた設定を `config.toml` に貼ります。

[見た目を整える](appearance.md)、[テーマ](themes.md)

## 気軽に戻れる

開いた画面は `Esc` で表に戻ります(木と関係マップは `q` でも、詳細は `K`、帯は `f` でも)。表のままの見せ方では `q` は mdgrid を終えます。キーを忘れたら `?`、名前で探すなら `:`。画面を切り替えても、保存するまでファイルは変わりません。
