mdgrid 見た目のカタログ

テーマと部品の形を選ぶと、右の画面がその見た目になります。画面はクリックとキーで触れます(セルを選ぶ・Enter で値を選ぶ・/ で検索・\ で絞る・, で同じ値だけ・K で詳細・R で関係マップ・o で設定・S で並べ替え・? でヘルプ)。

左下の設定を config.toml に貼ると、mdgrid が同じ見た目になります。部品の名前と値は本体の設定と同じもので、ずれたら試験が落ちます。
