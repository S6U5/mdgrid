# showcase: いろいろな機能を有効にした見本

設定(`config.toml`)と型の宣言(`vault/.obsidian/types.json`)と `.base` のビューを用意した見本の保管庫。
設定なしの素の見え方は [examples/vault](../vault) を見る。

ノートは架空の「社内の受付の仕組みを作り直す」仕事のタスク(`vault/プロジェクト/` に17個)とメモ(`vault/メモ/` に4個)。
日付は 2026年の9月〜11月に寄せてある。

## 開く

リポの根で、ビルドしてから一時フォルダに写して開く(写した先なら編集して保存してよい):

```sh
cargo build --release
cp -R examples/showcase /tmp/mdgrid-showcase
target/release/mdgrid --config /tmp/mdgrid-showcase/config.toml /tmp/mdgrid-showcase/vault/プロジェクト.base
```

写さずに見るだけなら `--readonly` を付ける:

```sh
target/release/mdgrid --config examples/showcase/config.toml examples/showcase/vault/プロジェクト.base --readonly
```

フォルダで開くと、`.base` を使わない既定の表(全21行)になる:

```sh
target/release/mdgrid --config /tmp/mdgrid-showcase/config.toml /tmp/mdgrid-showcase/vault
```

`--config` を付けないと、いつもの設定(`$XDG_CONFIG_HOME/mdgrid/config.toml`)で開く。

## 設定(config.toml)で変わるところ

| 項目 | 値 | 見えるところ |
|---|---|---|
| `[dates] format` | `"YYYY/MM/DD (ddd)"` | 表の日付が `2026/10/02 (金)` の形。打ち込みもこの形で読む(ノートには `YYYY-MM-DD` で書く) |
| `[dates] week_start` | `"mon"` | 日付のカレンダーが月曜から始まる |
| `[edit] candidates` | `30` | テキストのセルの候補の上限 |
| `[display] search_bar` | `true` | 表の上の「検索:」の欄 |
| `[edit] add_frontmatter` | `true` | フロントマターの無いメモにも書ける(先頭にフロントマターが足される)。空のフロントマター(`---` が2行だけ)のノートにも書ける(区切りの間にキーの行が足される)。`false` ならこの2つは読むだけ。区切りの間に空行やコメントの行があれば、空ではなく普通のフロントマター |
| `[keys.table]` | `"ctrl+f" = "search"` | `Ctrl+F` でも検索(`/` と同じ)に入る |

## ビューごとの見どころ

`[` `]` でビューを切り替える。`--view <名前>` で最初から開ける。

| ビュー | 見どころ |
|---|---|
| 今週の作業 | 絞り込み(フォルダ・未完了・期日が7日以内)と並べ替え(期日 → 優先度)。式の列「状況」が 期限切れ / もうすぐ / これから を出す。**今日の日付で見え方が変わる** |
| 担当ごと | `groupBy` で主担当(`owner`)ごとのまとまり。主担当の無いタスクは `(空)` のまとまり。見出しの行で Enter を押すと開閉 |
| 優先度と見積 | 式の列(「優先」= 高・中・低、「見積(時間)」= 見積(日)× 8)と `displayName` の見出し。並べ替え(優先度 → 見積の大きい順)のあと `limit: 8` で8行だけ |
| 完了 | `done == true` のものだけを、期日の新しい順に |
| 全部 | 絞り込みなし。メモも入るので、列が空の行や、フロントマターの無いメモ(入力して保存すると、先頭にフロントマターが足される)が混ざる |

### 今日の日付で見え方が変わるビュー

「今週の作業」の行と、式の列「状況」は今日の日付で決まる。2026-10-02 に開くと、期日を過ぎた「契約書の確認を頼む」から「ログイン画面を作る」(10/7)までの4行が出る。
ほかの日に開いて見え方を合わせたいときは、今日の日付を環境変数で決めて開く:

```sh
MDGRID_TODAY=2026-10-02 target/release/mdgrid --config /tmp/mdgrid-showcase/config.toml /tmp/mdgrid-showcase/vault/プロジェクト.base
```

## 試す操作

| 操作 | どこで | 見えるもの |
|---|---|---|
| `o` | 表のどこでも | ビューの設定。列の表示と順、絞り込みの条件、並べ替え、グループを変えて「反映」。`Esc` で取り消し |
| `\` | 表のどこでも | 上の検索の欄に入る。打つと行がその場で絞られる(例: `資料`)。`Enter` で決めて表に戻り、`Esc` で解く |
| `Ctrl+F` | 表のどこでも | 設定で割り当て直した検索(最下行に `/`)。`n` `N` で次と前の一致 |
| `Enter` | 「担当」「タグ」のセル(リストの列) | リストの選択。保管庫の中の候補が件数の多い順に出て、`Space` で付け外し、打つと絞り込み、`Enter` で確定 |
| `Enter` | 「期日」「開始」のセル(日付の列) | 月曜から始まるカレンダー。`←` `→` で1日、`↑` `↓` で1週、`Ctrl+T` で今日。欄の文字を消して `+3` と打てば今日から3日後 |
| `Enter` | 「状態」「主担当」のセル(テキストの列) | 保管庫の中の値の候補。打つと自由入力に切り替わる |
| `Enter` | 「済」のセル(チェックボックスの列) | true と false の切り替え(`u` で取り消し) |
| `K` | 行の上 | その行の全部のキーを縦に並べた詳細 |
| `Ctrl+S` | 編集のあと | 差分を見てから保存する(`--readonly` では出ない) |

型は `vault/.obsidian/types.json` で決めている: `due`・`start`・`date` は日付、`priority`・`estimate` は数、`done` はチェックボックス、`tags`・`assignees` はリスト。
リストの列は、ノートによって縦の形(`- 佐藤`)と1行の形(`[佐藤, 鈴木]`)が混ざっている。どちらも同じように編集できる。

一部のタスクは親のタスクを `parent: "[[試作を作る]]"` の形で持つ(「担当ごと」「全部」の「親」の列)。今は値として見えるだけで、階層の表示はまだ無い。

## 気をつけること

- 列の並び・幅・隠した列・ビューの設定(`o`)は、開いた場所とビューごとに `$XDG_STATE_HOME/mdgrid/` に覚える。同じ場所で開き直すと前の見た目に戻る(`.base` を書き換えて列を足すと、足した列は右の端に出る)。ビューの設定を `.base` のとおりに戻すには `o` の「既定に戻す」を使う。
- `examples/showcase` を `--readonly` なしで直接開いて保存すると、リポの中の見本が書き換わる。
