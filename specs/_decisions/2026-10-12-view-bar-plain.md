# ビューの帯は既定で線なし・上下に余白の3行にし、線で囲む形と1行の形は設定で選ぶ(view-bar-plain)

## きっかけ

search-box(2026-10-12)で、検索の欄と絞り込み・並べ替えのボタンを線で四角く囲む3行の帯を既定にした。人が、囲んでいるときは中の灰色の地は要らないと言い、囲みは要らないかもしれないので既定では囲まなくてよいが、余白は既定でも同じように要ると言った(会話 2026-10-12 の要約)。

```
 w Tasks ▾  12行                                ▦ 表 ▾   o ⚙ 設定

 既定の表   \ 検索…            | 絞り込み   S 並べ替え   分類   列   a + 新規

 ノート          status  due
```

## 差分

- 変更: SR-1 旧「画面は上から、ヘッダー(範囲と表のパンくずと行数。右の端に画面の型のメニュー(REL-8)と設定のボタン。SR-42)・ビューの帯(左にビューのタブ、右に検索の欄(NV-23)と、絞り込み・並べ替え・分類・列のボタン、右の端に、作れるときは「+ 新規」(CE-25)。検索の欄と絞り込み・並べ替えのボタンを線で四角く囲むので、高さは3行。NV-23)・設定の帯(条件が効いているとき。NV-16)・表・下の帯(今のモード、選んだセルの位置、未保存の数、今押せるキー)・メッセージ行で構成するべき。ビューの帯のタブと検索の欄、設定の帯は SR-20 で隠せ、タブと検索の欄を両方隠せばビューの帯の行ごと出さない。」→ 新「画面は上から、ヘッダー(範囲と表のパンくずと行数。右の端に画面の型のメニュー(REL-8)と設定のボタン。SR-42)・ビューの帯(左にビューのタブ、右に検索の欄(NV-23)と、絞り込み・並べ替え・分類・列のボタン、右の端に、作れるときは「+ 新規」(CE-25)。上下に1行ずつ余白を取るので、高さは3行。NV-23)・設定の帯(条件が効いているとき。NV-16)・表・下の帯(今のモード、選んだセルの位置、未保存の数、今押せるキー)・メッセージ行で構成するべき。ビューの帯のタブと検索の欄、設定の帯は SR-20 で隠せ、タブと検索の欄を両方隠せばビューの帯の行ごと出さない。」
- 確かめ方: SR-1 旧の例「80×24 の端末で起動 → 1行目にヘッダー、2〜4行目にビューの帯(3行目にタブと、線で囲んだ検索の欄とボタン)、5行目から表、下の帯に「未保存 0」(ゴールデン `test_SR_1`)」→ 新の例「80×24 の端末で起動 → 1行目にヘッダー、2〜4行目にビューの帯(2行目と4行目は空き、3行目にタブと検索の欄とボタン)、5行目から表、下の帯に「未保存 0」(ゴールデン `test_SR_1`)」
- 変更: NV-23 旧「ビューの帯(SR-1)の、ビューのタブの右に、検索(NV-2)の欄を常に出し、欄の頭にキーと「検索」を示し(例「\ 検索」)、効いている語と、合う行の数(例「12/80行」)を見せるべき。欄の右には、ボタン「絞り込み」(NV-29)・「並べ替え」(NV-24)・「分類」・「列」をこの順に並べ、帯の右の端には、作れるときは「+ 新規」(CE-25)を置き、キーのあるボタンにはそのキーを添えるべき(例「S 並べ替え」。マウスで使う人もキーを覚えられるように)。ボタンの頭のキーの字は、名前と見分けられる見た目(太字で、名前と違う色。色を使わない表示では太字)にするべき(キーの字を名前の一部や数字と取り違えないように。ヘッダーのボタン(SR-42)も同じ)。「分類」と「列」は、ビューの設定の画面(NV-18)をその区画で開くべき。端末の幅が足りないときは、列・分類のボタン、今のでないビューのタブの順に省き、今のビューのタブと検索の欄と、絞り込み・並べ替え・「+ 新規」のボタンをなるべく残すべき。検索の欄と、絞り込み・並べ替えのボタンは、それぞれ線で四角く囲み(上下の線を含めて3行の高さ)、ほかのボタンとビューのタブは囲みの真ん中の行に並べるべき(打てる欄とよく使うボタンだと、見てすぐ分かるように)。窓(NV-24・NV-29)は囲みの下の線のすぐ下に開くべき。囲むかどうかは設定 `display.buttons` で選べ、`"box"`(線で囲む。既定)か `"flat"`(囲まず1行)にできるべき(合わない人や、表の行を多く残したい人のため)。`"box"` でも、端末の高さが16行に満たないときは、囲まずに1行で描くべき(表の行を残すため)。欄は設定で出さないこともでき、出さないときは囲みも出さず1行にしてよい。」→ 新「ビューの帯(SR-1)の、ビューのタブの右に、検索(NV-2)の欄を常に出し、欄の頭にキーと「検索」を示し(例「\ 検索」)、効いている語と、合う行の数(例「12/80行」)を見せるべき。欄の右には、ボタン「絞り込み」(NV-29)・「並べ替え」(NV-24)・「分類」・「列」をこの順に並べ、帯の右の端には、作れるときは「+ 新規」(CE-25)を置き、キーのあるボタンにはそのキーを添えるべき(例「S 並べ替え」。マウスで使う人もキーを覚えられるように)。ボタンの頭のキーの字は、名前と見分けられる見た目(太字で、名前と違う色。色を使わない表示では太字)にするべき(キーの字を名前の一部や数字と取り違えないように。ヘッダーのボタン(SR-42)も同じ)。「分類」と「列」は、ビューの設定の画面(NV-18)をその区画で開くべき。端末の幅が足りないときは、列・分類のボタン、今のでないビューのタブの順に省き、今のビューのタブと検索の欄と、絞り込み・並べ替え・「+ 新規」のボタンをなるべく残すべき。ビューの帯は、上下に1行ずつ余白を取った3行の高さにし、タブとボタンを真ん中の行に並べるべき(表の上が詰まって見えないように)。帯の形は設定 `display.buttons` で選べ、`"plain"`(線で囲まず、欄とボタンを地の色で示す。既定)・`"box"`(検索の欄と、絞り込み・並べ替えのボタンを、それぞれ上下の余白の行まで使って線で四角く囲み、線の中は地の色で塗らない)・`"compact"`(余白を取らず1行)にできるべき。窓(NV-24・NV-29)は帯のすぐ下(`"box"` では囲みの下の線のすぐ下)に開くべき。どの形でも、端末の高さが16行に満たないときは、余白を取らず1行で描くべき(表の行を残すため)。欄は設定で出さないこともでき、出さないときは帯を1行にしてよい。」
- 確かめ方: NV-23 旧の例「起動(80×24)→ 2〜4行目がビューの帯で、3行目にタブ「既定の表」、その右に線で四角く囲んだ空の検索の欄「\ 検索…」と、線で囲んだキーを添えた絞り込み・並べ替えのボタン(例「S 並べ替え」)、「分類」「列」、右の端に「a + 新規」。設定の ⚙ は無い。「会議」で絞る → 欄に「会議」と「3/16行」。「分類」を押す → ビューの設定の画面の分類の区画。幅 60 → 列・分類が無く、絞り込みと並べ替えと「+ 新規」は出る。ボタンの頭のキーの字は太字で、名前と見た目が違う。「\| 絞り込み」を押す → 窓は囲みの下の線のすぐ下に開く。高さ 14 → 囲みが無く、ビューの帯は1行。設定 `display.buttons = "flat"` → 囲みが無く、ビューの帯は1行。設定で欄を消す → 欄が無く、`\` を押せば最下行で打てる(`test_NV_23`)」→ 新の例「起動(80×24)→ 2〜4行目がビューの帯で(2行目と4行目は空き)、3行目にタブ「既定の表」、その右に空の検索の欄「\ 検索…」と、キーを添えた絞り込み・並べ替えのボタン(例「S 並べ替え」)、「分類」「列」、右の端に「a + 新規」。設定の ⚙ は無い。「会議」で絞る → 欄に「会議」と「3/16行」。「分類」を押す → ビューの設定の画面の分類の区画。幅 60 → 列・分類が無く、絞り込みと並べ替えと「+ 新規」は出る。ボタンの頭のキーの字は太字で、名前と見た目が違う。「\| 絞り込み」を押す → 窓は5行目に開く。設定 `display.buttons = "box"` → 欄と絞り込み・並べ替えが線で四角く囲まれ、線の中は地の色が無い。`"compact"` → ビューの帯は1行。高さ 14 → ビューの帯は1行。設定で欄を消す → 欄が無く、`\` を押せば最下行で打てる(`test_NV_23`)」

## 却下した案

| 案 | 理由 |
|---|---|
| 既定を線で囲む形のままにする | 人が、囲みは要らないかもしれないと言った |
| 既定を1行に詰める | 人が、余白は既定でも要ると言った |
| 囲むときも中を地の色で塗る | 線と地の色が重なり、うるさい |
