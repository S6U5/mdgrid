# 並べ替えを選んで覚える(並べ替えの窓・見出しの並べ替えの保存・既定のビュー)(sort-views)

## きっかけ

人が、既定の並べ替えとそれを保存する機能、よくある SaaS のように並べ替えを選べる形が欲しいと言った。AI が、並べ替えのボタンと窓・自動の保存・見出しの並べ替えの保存・既定のビューを示し、見出しの並べ替えも保存してよいかを尋ね、人が了承した(会話 2026-10-10 の要約)。人の依頼を AI が要件の文に起こした。

## 差分

- 変更: NV-3 旧「列の見出しから、一時的な並べ替え(昇順 → 降順 → 解除)ができるべきで、`.base` の並べ替えを変えるべきでない。」→ 新「列の見出しから並べ替え(昇順 → 降順 → 解除)ができるべきで、その並べ替えは今のビューの設定の並べ替え(NV-13)として当て、見た目の状態(SR-12)に保存して、次に開いても同じ並びにするべき(よくある表の道具と同じく、選んだ並びを覚えるため)。`.base` の並べ替えとファイルは変えるべきでない。」
- 変更: NV-20 旧「設定のフィルターとグループ分けは `.base` の filters・groupBy の結果の上に重ね、並べ替えは設定があれば `.base` の sort に代わり、簡易の絞り込み(NV-2)・同じ値の絞り込み(NV-8)・一時的な並べ替え(NV-3)は設定の上にさらに重ねるべき。値を直した行の留め方(NV-12)は設定のフィルターにも効くべき。」→ 新「設定のフィルターとグループ分けは `.base` の filters・groupBy の結果の上に重ね、並べ替えは設定があれば `.base` の sort に代わり、簡易の絞り込み(NV-2)・同じ値の絞り込み(NV-8)は設定の上にさらに重ねるべき。見出しからの並べ替え(NV-3)と並べ替えの窓(NV-24)は、設定の並べ替えそのものを変えるべき。値を直した行の留め方(NV-12)は設定のフィルターにも効くべき。」
- 変更: SR-12 旧「見た目の状態は、`.base` のパス(`.base` なしで開いたときはフォルダのパス)とビューの名前ごとに保存し、壊れていたら捨てて既定で起動するべき。見た目の状態の列の並びと隠す列は、今の `.base` にある列にだけ当て、`.base` に増えた列は右に足すべき。一時的な並べ替え(NV-3)は残さないべき。」→ 新「見た目の状態は、`.base` のパス(`.base` なしで開いたときはフォルダのパス)とビューの名前ごとに保存し、壊れていたら捨てて既定で起動するべき。見た目の状態の列の並びと隠す列は、今の `.base` にある列にだけ当て、`.base` に増えた列は右に足すべき。見出しからの並べ替え(NV-3)は設定の並べ替えとして残すべき。」
- 変更: BV-13 旧「`.base` の views が2つ以上あれば、ビューを切り替えられるべき。起動時は先頭のビューを開くべき。」→ 新「`.base` の views が2つ以上あれば、ビューを切り替えられるべき。起動時は既定に選んだビュー(NV-25)を、無ければ先頭のビューを開くべき。」
- 変更: BV-20 旧「mdgrid のビューの定義は、設定の置き場の `views.toml` に、開いた対象の実体のパスごとに、ビューの名前・列の並びと隠す列・ビューの設定(NV-13〜NV-22 のフィルター・並べ替え・グループ)を持つべきで、知らない項目は警告にとどめ(CLI-3)、壊れた `views.toml` は警告して読まずに起動するべき。`.base` で開いたときのタブは `.base` のビューのあとに mdgrid のビューを並べ、起動時は BV-13 のとおり先頭のビューを開くべき。保存は一時ファイル → 名前の変更で書き、`--readonly`(WB-15)では書かないべき。見た目の状態(SR-12)の列の幅と畳んだまとまりは、mdgrid のビューにも名前ごとに当てるべき。」→ 新「mdgrid のビューの定義は、設定の置き場の `views.toml` に、開いた対象の実体のパスごとに、ビューの名前・列の並びと隠す列・ビューの設定(NV-13〜NV-22 のフィルター・並べ替え・グループ)を持つべきで、知らない項目は警告にとどめ(CLI-3)、壊れた `views.toml` は警告して読まずに起動するべき。`.base` で開いたときのタブは `.base` のビューのあとに mdgrid のビューを並べ、起動時は BV-13 のとおり既定に選んだビューか先頭のビューを開くべき。保存は一時ファイル → 名前の変更で書き、`--readonly`(WB-15)では書かないべき。見た目の状態(SR-12)の列の幅と畳んだまとまりは、mdgrid のビューにも名前ごとに当てるべき。」
- 追加: NV-24(節「要件: 版1 — 並べ替えと列」)「検索の欄(NV-23)の行の右の端に「並べ替え」のボタンを出し、押すと、今のビューの並べ替えの決まり(列と向き。複数)を並べた小さな窓を開くべき。窓では、決まりを足す(列を選ぶ)・外す・向きを変える・順を入れ替えることができ、変えるとすぐ表に効かせ、設定の並べ替え(NV-13)として見た目の状態(SR-12)に保存するべき。並べ替えが効いている間は、ボタンに先頭の決まりを見せる(例「↑ due」、2つ以上なら「↑ due +1」)。窓の外のクリックか Esc で閉じる。検索の欄を出さない設定(NV-23)では、同じ窓を操作の一覧とコマンドのパレットから開けるべき。」(確かめ方: 検索の欄の右の「並べ替え」を押す → 窓が開き「+ 並べ替えを足す」。due を選ぶ → すぐ due の昇順になり、ボタンに「↑ due」。due の行で Enter → 降順「↓ due」。終了して開き直す → 同じ並び。窓で決まりを外す → 元の並び。読むだけの起動でも並べ替えられる(ノートは書かない)(`test_nv_24_*`))
- 追加: NV-25(節「要件: 版1 — 並べ替えと列」)「ビューのタブのうち1つを「既定のビュー」に選べるべきで、操作の一覧とコマンドのパレットの「既定のビューにする」で今のビューを選び、mdgrid の設定の置き場の `views.toml` の、開いた対象の項目に名前で残すべき(ノートのフォルダと `.base` には書かない)。起動時は、ビューを名前で指定していなければ(`--view`・登録した表のビュー)、既定のビューを開くべき。既定のビューの名前が無くなっていたら、警告せずに先頭のビューを開くべき。読むだけの起動(`--readonly`)では選べないべき。」(確かめ方: ビューが3つの対象で「進行中」のタブを選び「既定のビューにする」→ views.toml の対象に default_view = "進行中"。終了して開き直す → 「進行中」が選ばれている。`--view 既定の表` で開く → 既定の表。「進行中」を消す → 次の起動は先頭。`--readonly` → 「既定のビューにする」が出ない(`test_nv_25_*`))

## 却下した案

| 案 | 理由 |
|---|---|
| 見出しの並べ替えは一時的なまま、保存は別の操作 | よくある表の道具では選んだ並びをそのまま覚える。人が保存する形を了承した |
| 既定の表の並べ替えを views.toml に書く | 既定の表は views.toml に定義が無い。今ある見た目の状態(SR-12)の保存で足りる |
