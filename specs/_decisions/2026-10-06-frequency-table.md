# 列の値の頻度表を版1に入れる(frequency-table)

## きっかけ

会話 2026-10-06 の改善の繰り返しで、初めて使う人の目の点検(docs/todo.md の U-13)が、値ごとの件数(担当ごとの仕事の数など)を見る手段が無く、表の道具で最も惜しまれる機能だと指摘した(VisiData の頻度表 Shift+F)。NV-9 は「次の段」に「してよい」で置いてあったので、開き方と絞り方を決めて版1に上げる。

## 差分

navigation の spec.md の NV-9 を「次の段」から「版1」の要件の節(NV-22 の次)に移し、文を変える。

- 変更: NV-9 旧「列の値の頻度表(値ごとの件数。リストの値は要素ごと)を出し、そこから値を選んで絞り込めてよい。」→ 新「選んでいる列の値の頻度表(値ごとの件数。リストの値は要素ごと、空は「(空)」)を、キー(既定 `%`。SR-4 のキーの表で割り当て直せる)・パレット・操作の一覧(SR-24 の列の節)から、表の上に重ねる窓で開けるべき。件数の多い順(同じ数は値の順)に、件数と全行に対する割合を添えて並べ、↑↓ で選んで Enter でその値の行だけに絞り(NV-8 の同じ値の絞り込みと同じく設定の帯(NV-16)に出る条件にし)、Esc で何もせず閉じるべき。数えるのは今のビューの絞り込みのあとの行とするべき。」(確かめ方: tags の列で `%` → 窓に「会議 3 (25%)」「家 2 (17%)」…が多い順。「会議」で Enter → tags に会議を持つ行だけになり、上の帯に条件が出る。Esc → 何も変わらない。値の無い行は「(空)」として数える(`test_NV_9`))

## 却下した案

| 案 | 理由 |
|---|---|
| 何もしない | 件数を知るには絞り込みを繰り返すしかない |
| 別の画面(全画面の表)にする | 表の上の窓のほうが、どの列の表かが見えたまま。操作の一覧の窓と同じ部品で作れる |
| Shift+F(VisiData と同じ) | F は列の固定(NV-4)に使っている。`%` は空いていて「割合」を思わせる |
