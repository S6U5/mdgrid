# リストで打つと、打った文字で候補を絞って出し続ける(list-narrow)

## きっかけ

会話 2026-10-06 の改善の繰り返しで、3回目の点検(docs/todo.md の A-8)が、候補のリストで文字を打つとリストが消え、長い値(`in-progress` など)を選ぶには ↑↓ で探し直すか全部打つしかないと指摘した。ほかの表のツールや入力欄の補完は、打った文字で候補を絞る。

## 差分

- 変更: CE-3 旧「テキストの列で、読み込んだノート全部(BV-2 の範囲。ビューの絞り込みの前)の同じキーに現れる異なる値が一定数以下(既定 20)なら、その値のリストから選べるようにし、自由入力にも切り替えられるようにするべき。リストには今の値に印を付け、空の値は「なし」として並べるべき。リストを開いた直後(リストで選び直したあとも)に文字を打ったときは、候補に無い新しい値を打つのに今の値が邪魔をしないよう、今の値を消して打った文字から自由入力を始めるべき。」→ 新「テキストの列で、読み込んだノート全部(BV-2 の範囲。ビューの絞り込みの前)の同じキーに現れる異なる値が一定数以下(既定 20)なら、その値のリストから選べるようにし、自由入力にも切り替えられるようにするべき。リストには今の値に印を付け、空の値は「なし」として並べるべき。リストを開いた直後(リストで選び直したあとも)に文字を打ったときは、候補に無い新しい値を打つのに今の値が邪魔をしないよう、今の値を消して打った文字から自由入力を始めるべき。自由入力で打っている間は、候補のうち打った文字を含むもの(大文字小文字を問わない)を、選んでいない形でリストに出し続け、↑↓ でその候補の中から選べるように(打った文字のまま Enter なら打った文字を書くように)するべき。」(確かめ方: status の値 `doing` のセルで Enter → リスト。`blocked` と打って Enter → `blocked` のためる変更。リストで ↓ のあと `x` と打つ → `x`。← を押してから `!` と打つ → `doing!`。Ctrl+R のあとに打つ → 今の値の続き(`test_ce_3_type_replaces_*`)。`status` の値が todo・doing・done だけ → 3つと「なし」のリストが出て、今の値に印。ビューの絞り込みで見えていないノートの値も候補に入る(`test_CE_3`)。`do` と打つ → doing と done だけの候補が選びなしで出て、Enter → `do`。`do` のあと ↓ → doing を選び Enter → doing。どの候補にも当たらない文字 → 候補は出ない(`test_ce_3_narrow_*`))

## 却下した案

| 案 | 理由 |
|---|---|
| 何もしない | 候補の多い列で、リストが入力の助けにならない |
| 打った文字に最初に当たる候補を自動で選ぶ | 候補に無い新しい値(`do`)を打って Enter したとき、意図しない候補が書かれる。選ぶのは ↑↓ のときだけにする |
