# .md のファイルを渡したらそのフォルダを開いてその行を選ぶ(open-md-file)

## きっかけ

会話 2026-10-06 の改善の繰り返しで、初めて使う人の目の点検(docs/todo.md の U-12)が、`mdgrid x.md` が「フォルダでない」で終了コード 2 になると指摘した。シェルの補完でファイルまで打つ人は多い。

## 差分

cli の spec.md の CLI-14 の次に足す。

- 追加: CLI-15「起動の引数に `.md` のファイルを渡したときは、ファイル名を補完で渡す人が「フォルダでない」で止められないよう、そのファイルのあるフォルダを渡したのと同じに開き、画面ではそのノートの行を選んで始めるべき。ファイルが無いときは CLI-4 と同じく理由1行と終了コード 2 にするべき。」(確かめ方: `mdgrid notes/b.md` → notes の既定の表が開き、b.md の行が選ばれている。`mdgrid notes/b.md --print` → notes の表と同じ出力。`mdgrid notes/無い.md` → 理由1行と終了コード 2(`test_CLI_15`))

## 却下した案

| 案 | 理由 |
|---|---|
| 何もしない | 補完でファイルを渡すたびに止められる |
| 理由の文だけを良くする(「フォルダか .base を渡す」) | 開ける場所が分かっているのに、打ち直させる |
| そのノート1つだけの表を開く | 1行の表は役に立たず、同じフォルダのほかのノートと見比べられない |
