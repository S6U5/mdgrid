# 折り返したタブの行を、帯の上の余白の下(真ん中の行のすぐ上)に置く(tab-wrap-adjacent)

## きっかけ

人が、タブ(絞り込みのビュー)を何行かに分けてから使い勝手が悪くなったようなので直してほしい、と言った(中継 2026-10-15。プロジェクトのチャットからまとめ役が写した)。

本物の台帳(タブ11個、幅 100)で見ると、足した行はヘッダーのすぐ下に詰まり、残りのタブのある真ん中の行との間に帯の上の余白(空き行)が挟まる。タブの並びが空き行で2つに割れ、今のタブ(先頭)が検索の欄やボタンから離れて見える。置き場をどこにするかは AI が足した細部。

## 差分

- 変更: NV-31 旧「設定 `display.tab_wrap`(真偽。既定 false)を true にした表では、ビューのタブが帯の真ん中の行(検索の欄とボタンと同じ行。NV-23)に入りきらないとき、今のでないタブを省かずに、帯の上に行を足してタブを左から幅いっぱいに並べて折り返し、残りのタブを真ん中の行の左に置くべき(タブが多くても全部を見て選べるように)。足した行は帯の上の余白(`bar_padding`)のさらに上に置き(囲みの線(`buttons = "box"`)と余白は今のまま)、足した行のぶん表は下がり、足した行のタブもクリックで選べるべき。タブを出さないとき(SR-34 の `tabs = "never"` と、1つだけで隠す `"auto"`)は何もしないべき。ビューの設定の「表示」の区画(NV-18)では切り替えない(SR-47 と同じく、表示の区画の数とその写しを増やさないため。ビューごとの値は views.toml のビューの `display` に書ける)。入りきるときと false のときは、今の1行のまま(NV-23)にするべき。表のプロファイルの項目として全体・ワークスペース・表・ビューの範囲(SR-44)に書けるべき。」→ 新「設定 `display.tab_wrap`(真偽。既定 false)を true にした表では、ビューのタブが帯の真ん中の行(検索の欄とボタンと同じ行。NV-23)に入りきらないとき、今のでないタブを省かずに、帯の上に行を足してタブを左から幅いっぱいに並べて折り返し、残りのタブを真ん中の行の左に置くべき(タブが多くても全部を見て選べるように)。足した行は、線で囲まない帯(`buttons = "plain"`。既定)では帯の上の余白(`bar_padding`)の下、真ん中の行のすぐ上に置き(折り返したタブが真ん中の行のタブと間を空けずに続き、ヘッダーとの間に余白が残るように。余白の端数で帯の行に地の色を敷くときは、足した行にも同じ地の色を敷く)、囲む帯(`"box"`)では帯の上の余白のさらに上に置き(囲みの線は真ん中の行に接する余白の行に引くため)、足した行のぶん表は下がり、足した行のタブもクリックで選べるべき。タブを出さないとき(SR-34 の `tabs = "never"` と、1つだけで隠す `"auto"`)は何もしないべき。ビューの設定の「表示」の区画(NV-18)では切り替えない(SR-47 と同じく、表示の区画の数とその写しを増やさないため。ビューごとの値は views.toml のビューの `display` に書ける)。入りきるときと false のときは、今の1行のまま(NV-23)にするべき。表のプロファイルの項目として全体・ワークスペース・表・ビューの範囲(SR-44)に書けるべき。」(確かめ方: 7つのタブの表を幅 60 の端末で `tab_wrap = true` → 帯の上に1行以上足され、7つのタブの名前が全部画面にあり、検索の欄と「絞り込み」のボタンも見える。足した行は検索の欄の行のすぐ上にあり、余白 1 では足した行とヘッダーの間に空き行が1つある。`buttons = "box"` では足した行は囲みの上の線より上。足した行のタブをクリック → そのビュー。幅 200 → 足す行は無く今と同じ。`tab_wrap = false`(既定)で幅 60 → 今のタブだけ(NV-23 のまま)(`test_nv_31_*`))

## 却下した案

| 案 | 理由 |
|---|---|
| 何もしない | タブの並びが空き行で割れ、足した行がヘッダーに詰まる(本物の台帳で確かめた) |
| 折り返すときはタブを全部、検索の欄とボタンの行から外して専用の行に置く | 幅 100 の台帳ではタブが1行に入らず、足す行が1つ増えて表が狭くなる。真ん中の行の左に残りを置く今の形のまま、間を詰めれば足りる |
| `"box"` でも余白の下に置く | 囲みの上の線は真ん中の行に接する余白の行に引くので、間に足した行を挟むと囲みが切れる |
