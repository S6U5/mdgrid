# チェックボックスの列で空・真・偽の3つを選べるようにする(checkbox-three-state)

## きっかけ

会話 2026-10-02 で、人が、真偽の列で最初から値が入っていないときに空か true しか取れないので、値が入っていても入っていなくても3つの状態を取れるようにしたいと依頼した。今の切り替えは、空のセルでは 空 → true → 空 と回り、false を選ぶには打ち込むしかない。人の依頼を AI が要件の文に起こした。

## 差分

- 変更: CE-4
  - 旧: 「チェックボックスの列は、1回の操作で真と偽を切り替えるべき。」(確かめ方: `done: false` のセルで Enter → `done: true` がためる変更になる(`test_CE_4`))
  - 新: 「チェックボックスの列は、1回の操作で、元の値が入っているかどうかにかかわらず、空 → 真 → 偽 → 空 の順に3つの状態を回せるべき。空は CE-9 と同じく `key:` と書き、元にキーが無いノートで空に戻ったときは書かない(元に戻すのと同じ)。」(確かめ方: `done: false` のセルで Enter → 空(`done:`)のためる変更。キーの無いノートで Enter → `done: true`、もう一度 → `done: false`、もう一度 → ためる変更なし。`done: true` で Enter → `done: false`。`done:` の空のセルで Enter → `done: true`(`test_CE_4`))

## 却下した案

| 案 | 理由 |
|---|---|
| 何もしない | 空のセルから false を入れるのに打ち込みが要り、真偽の列で手早く3つを選べない |
| 真と偽の2つだけを回し、空は打ち込みで | 依頼は3つを回すこと |

## 承認の記録

2026-10-02 人の承認(要約: 真偽の列で、値が入っていても入っていなくても、空・true・false の3つを取れるようにしようと依頼した。依頼が承認)
