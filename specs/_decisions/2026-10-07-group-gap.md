# まとまりの見出しの上を空ける表示の設定(group-gap)

## きっかけ

人と AI のタスクを分ける見本(examples/ai-human)の画面を見た人が、「🤖 ロボットのタスク」の見出しの上を空けて、まとまりどうしの間隔を取れるようにしたいと頼んだ(会話 2026-10-07)。既定は今の見た目のまま(空けない)と人が選んだ。人の依頼を AI が要件の文に起こした。

## 差分

- 追加: SR-30「表の見せ方(SR-20)に、まとまりの見出しの上の空きを足すべきで、`groupBy`(NV-15 の設定のグループ分けを含む)のまとまりがあるとき、2つ目以降の見出しの行の上に空きの行を1つ入れるべき。既定は空けず、設定の `[display]` の `group_gap`(既定 false)で既定を決め、SR-20 のほかの項目と同じく、ビューの設定(NV-13)でビューごとに切り替えられ、mdgrid のビュー(BV-17)に保存できるべき。空きは見た目のためだけにあるので、空きの行は行として数えず(行の数・行番号・`--print` に出さない)、カーソルを止めず、クリックしても選びを変えないべき。」(確かめ方: `[display] group_gap = true` で status でまとめたビューを開く → 2つ目の見出しの上に空きの行があり、1つ目の見出しの上には無い。1つ目のまとまりの最後の行で `j` → 空きを飛ばして2つ目の見出しへ。空きの行をクリック → 選びは変わらない。`group_gap` の無い設定 → 今と同じ画面。まとまりの無いビュー → 空きは出ない(`test_sr_30`))

## 却下した案

| 案 | 理由 |
|---|---|
| 何もしない | まとまりが2つ以上あると、見出しが前のまとまりの最後の行に続いて見え、区切りが分かりにくい |
| 既定で空ける | 人が「既定は空けない」を選んだ。まとまりを写す画面の試験の答えと README の画像を撮り直すことになる |
| SR-20・SR-21 の項目の並びに足す | SR-20・SR-21 は人の決めた守られる要件で、項目の数を前提にした試験がある。別の要件にすれば触らずに済む |

## 承認の記録

2026-10-07 人の承認(要約: 見出しの上を空けて、まとまりどうしの間隔を取れるようにしたい。既定は空けない)
