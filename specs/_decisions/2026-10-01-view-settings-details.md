# ビューの設定の細部(フィルターの条件・重なり方・戻し方)(view-settings-details)

## きっかけ

人の依頼の提案 view-settings(NV-13〜NV-18)を実装に移すには、フィルターの条件の種類、今ある絞り込み(NV-2・NV-8)・一時的な並べ替え(NV-3)・`.base` の設定との重なり方、設定を戻す操作が決まっていない。Notion のビューの設定と Excel のオートフィルターの振る舞いから、AI が細部を足す。

## 差分

navigation の spec.md の「要件: 版1 — ビューの設定」の節に足す。

- 追加: NV-19「設定のフィルターの条件は、値の一覧にチェックを付け外しする形(値ごとの件数を添え、空は「(空)」、リストの値は要素ごと)を基本にし、テキストの「含む・含まない」、数と日付の比較(`=`・`≠`・`<`・`≤`・`>`・`≥`)、「空である・空でない」も選べてよい。複数の条件は全部を満たす行だけを残すべき。」(確かめ方: tags の値の一覧で 会議 だけにチェック → 会議 を要素に持つ行だけ。priority `≥ 3` と status の done を外す を並べる → 両方を満たす行だけ。日付の列の `< 2026-10-01` → それより前の行だけ、`someday` のような型の合わない値は残らない(`test_NV_19`))
- 追加: NV-20「設定のフィルターとグループ分けは `.base` の filters・groupBy の結果の上に重ね、並べ替えは設定があれば `.base` の sort に代わり、簡易の絞り込み(NV-2)・同じ値の絞り込み(NV-8)・一時的な並べ替え(NV-3)は設定の上にさらに重ねるべき。値を直した行の留め方(NV-12)は設定のフィルターにも効くべき。」(確かめ方: `.base` の filters で 10 行のビューに設定で done を外す → 10 行のうち done でない行だけ。その上で `\` で「会議」→ さらに絞る。設定で並べた列と別の列を `s` で並べる → `s` の並びが勝ち、`s` を外すと設定の並び。done を外した表で done に直した行は保存か移動まで残る(`test_NV_20`))
- 追加: NV-21「グループ分けは、空の値のまとまりを隠すことと、まとまりの並び(昇順・降順)を選べてよい。」(確かめ方: status でグループ分けし、空を隠す → `(空)` の見出しと行が出ない(`test_NV_21`))
- 追加: NV-22「設定を `.base` のビューの既定(`.base` なしなら何もしない状態)に戻す操作と、表の上の帯の項目から1つの条件を外す操作を持つべき。読むだけで開いたとき(WB-15)も設定は変えられるべきで、ノート・`.base`・見た目の状態のどのファイルも書かないべき。」(確かめ方: 設定を戻す → 帯が消え、`.base` のままの表。帯の「status: done を除く」を外す → done の行が戻る。`--readonly` で設定を反映 → 表は変わり、ノート・`.base`・状態の置き場のどれも書かれない(`test_NV_22`))

## 却下した案

| 案 | 理由 |
|---|---|
| 何もしない | 依頼の要件(NV-13〜NV-18)だけでは、条件の種類と今ある絞り込みとの重なり方が実装ごとにぶれる |
| 条件を `.base` の式(NV-10)で書く形にする | 人の答えは列と値を選ぶ形。式は NV-10(次の段)として残す |
| 設定のフィルターを今の簡易の絞り込みに置き換える | NV-2・NV-8 の速い操作が無くなる。重ねる形にする |
