# 親子で並べた表に WBS の番号と進み具合を出し、値の対応表を設定で作って保存する(wbs)

## きっかけ

人が、WBS のような機能は、設定の画面でそれを当てて、要る値とラベルの対応表を作って保存すれば使える形がよいと言った(会話 2026-10-10)。親子の並べ方(NV-27)の上に乗せる。人の依頼を AI が要件の文に起こした。

## 差分

- 追加: NV-28 ビューの設定の画面の「親子」の区画で、親子で並べているビュー(NV-27)に WBS をオンにできるべき。オンのとき、行の名前の前に WBS の番号(まとまりの中で一番上の段を 1 から、子は親の番号に `.` と兄弟の中の順をつなぐ。例 `1.2.1`)を付けるべき。区画では進み具合のキー(既定 `status`)と、その値ごとの割合(0〜100)とラベルの対応表を作れるべきで、表の行に出てくる値を件数つきで並べ、値ごとに割合とラベルを打って決める。子の無い行は、名前のあとに対応表のラベルを、子のある行は、子孫の子の無い行の割合の平均を `%` で出すべき(対応表に無い値と値の無い行は 0% と数える)。WBS のオン・オフ、進み具合のキー、対応表はビューの設定として反映で効き、見た目の状態と mdgrid のビュー(BV-17)に残るべき。親子で並べていないときは WBS を出さないべき。(確かめ方: 設計の下に画面(その下に部品 done・ボタン todo)と API(doing)がある表で、親子と WBS をオンにし、対応表で done = 100 完了・doing = 50 作業中・todo = 0 未着手 → 「1 設計 · 50%」「1.1 画面 · 50%」「1.1.1 部品 · 完了」「1.1.2 ボタン · 未着手」「1.2 API · 作業中」。API の status を空にする → 「1 設計」は 33%(100+0+0 の平均)。対応表に無い値 blocked → 0% と数え、ラベルは出さない。親子をオフ → 番号と進み具合が消える。開き直す → 対応表が残る。`test_nv_28_*`)

## 却下した案

| 案 | 理由 |
|---|---|
| 進み具合を別の列にする | 列はノートのキーと式のもので、ビューの設定で足す見せ方は名前の欄に添える方が、保存の対象と混ざらない |
| 対応表を設定ファイル(config.toml)に置く | 人の案は、設定の画面で当てて作って保存する形。ビューごとに違うキーを使える |
