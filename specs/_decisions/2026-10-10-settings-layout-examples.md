# 設定の画面の作り直しに合わせて、関わる要件の例(確かめ方)の操作を直す(settings-layout-examples)

## きっかけ

人が良いと言った設定の画面の作り直し(specs/_decisions/2026-10-10-settings-layout.md。会話 2026-10-10 の要約)で、表示・フィルター・ビューの保存は左の一覧の区画から操作するようになった。これらを確かめる例と試験の操作を、その形に合わせる。要件の文は変えない。

## 差分

- 変更: NV-13 旧「表の見せ方を変えるビューの設定の画面を持ち、そこでフィルター・並べ替え・グループ分け・表示する列を組んで、反映の操作で表に効かせるべきで、反映するまでは表を変えず、取り消せば元のままにするべき。」→ 新「表の見せ方を変えるビューの設定の画面を持ち、そこでフィルター・並べ替え・グループ分け・表示する列を組んで、反映の操作で表に効かせるべきで、反映するまでは表を変えず、取り消せば元のままにするべき。」(確かめ方: 設定の画面(左の一覧のフィルターの区画)で status の done を隠す → 反映の前は表に done の行が残り、反映で消える。取り消しで閉じる → 表は開く前のまま(`test_NV_13`))
- 変更: NV-16 旧「設定で効いているフィルター・並べ替え・グループ分けを、表の上の帯に並べて見せるべき。何も効いていなければ帯を出さないでよい。」→ 新「設定で効いているフィルター・並べ替え・グループ分けを、表の上の帯に並べて見せるべき。何も効いていなければ帯を出さないでよい。」(確かめ方: 設定の画面のフィルターの区画で status の done を外して、上の「反映」 → 表の上に「status: done を除く」の項目が出る(`test_NV_16`))
- 変更: NV-23 旧「表の上(ビューのタブの下)に、簡易の絞り込み(NV-2)の検索の欄を常に出し、効いている語と、合う行の数(例「12/80行」)を見せるべき。欄は設定で出さないこともできてよい。」→ 新「表の上(ビューのタブの下)に、簡易の絞り込み(NV-2)の検索の欄を常に出し、効いている語と、合う行の数(例「12/80行」)を見せるべき。欄は設定で出さないこともできてよい。」(確かめ方: 起動 → タブの下に検索の欄が空で出ている。「会議」で絞る → 欄に「会議」と「3/16行」。設定(ファイルか、設定の画面の表示の区画)で欄を消す → 欄が無く、表が1行広い。`\` を押せば最下行で打てる(`test_NV_23`))
- 変更: BV-17 旧「`.base` を使わずに、開いた対象(フォルダか `.base`)ごとに、mdgrid 独自のビューを名前つきで複数持ち、ビューのタブで切り替えられるべきで、その定義は mdgrid の設定の置き場の、人が読み書きできる TOML に置き、ノートのフォルダには書かないべき。mdgrid のビューは、`.base` のビューより多くの機能を持ってよい。」→ 新「`.base` を使わずに、開いた対象(フォルダか `.base`)ごとに、mdgrid 独自のビューを名前つきで複数持ち、ビューのタブで切り替えられるべきで、その定義は mdgrid の設定の置き場の、人が読み書きできる TOML に置き、ノートのフォルダには書かないべき。mdgrid のビューは、`.base` のビューより多くの機能を持ってよい。」(確かめ方: `.base` の無いフォルダで開き、設定の画面の「名前を付けて保存」でビューを2つ作る → タブに「既定の表」と2つの名前が並び、切り替えると絞り込みや列が変わる。終了して開き直すと同じ。設定の置き場の TOML を手で書き足す → タブが増える。ノートのフォルダに新しいファイルが無い(`test_BV_17`))
- 変更: SR-21 旧「SR-20 の設定は `[display]` の表に `row_numbers`(既定 false)・`zebra`(既定 false)・`column_lines`(既定 false。true で列の間に `│` を引く)・`tabs`(既定 true)・`chips`(既定 true)を持ってよく、検索の欄は既にある最上位の `search_bar` をそのまま使ってよい(`[display]` に同じ名前を足さない)。ビューごとの値はビューの設定(settings)の `display` に、設定と違う項目だけを持ってよい。」→ 新「SR-20 の設定は `[display]` の表に `row_numbers`(既定 false)・`zebra`(既定 false)・`column_lines`(既定 false。true で列の間に `│` を引く)・`tabs`(既定 true)・`chips`(既定 true)を持ってよく、検索の欄は既にある最上位の `search_bar` をそのまま使ってよい(`[display]` に同じ名前を足さない)。ビューごとの値はビューの設定(settings)の `display` に、設定と違う項目だけを持ってよい。」(確かめ方: `[display] row_numbers = true` → 番号が出て、設定の画面の表示の区画でも「行番号」がオン。`--print-config` に `[display]` の5項目(読んで判定))
- 変更: SR-20 旧「表の見せ方の次の4つを、設定(CLI-3 の設定ファイル)で既定を決め、ビューの設定(NV-13)の「表示」の区画(NV-18)でビューごとに切り替えられ、mdgrid のビュー(BV-17)に保存できるべき: 行番号(表の左に1始まりの番号。既定は出さない)・一行おきの色(既定は付けない)・列の区切り線(既定は今の見た目)・上の帯(ビューのタブ・検索の欄(NV-23)・設定の帯(NV-16)をそれぞれ出すか)。帯を隠しても、その帯の操作(タブの切り替えのキー・`\`・`f`)は効くべき。一行おきの色は色を使わない表示(`--no-color`・NO_COLOR)では付けないべき(SR-15)。」→ 新「表の見せ方の次の4つを、設定(CLI-3 の設定ファイル)で既定を決め、ビューの設定(NV-13)の「表示」の区画(NV-18)でビューごとに切り替えられ、mdgrid のビュー(BV-17)に保存できるべき: 行番号(表の左に1始まりの番号。既定は出さない)・一行おきの色(既定は付けない)・列の区切り線(既定は今の見た目)・上の帯(ビューのタブ・検索の欄(NV-23)・設定の帯(NV-16)をそれぞれ出すか)。帯を隠しても、その帯の操作(タブの切り替えのキー・`\`・`f`)は効くべき。一行おきの色は色を使わない表示(`--no-color`・NO_COLOR)では付けないべき(SR-15)。」(確かめ方: 設定で行番号を出す → 各行の左に 1・2・3。ビューの設定の表示の区画で消して保存 → そのビューだけ番号が無く、開き直しても同じ。一行おきの色 → 偶数の行の背景が違う、`--no-color` では同じ。区切り線を入れる → 列の間に `│` が出る。既定(今の見た目)では `│` が無い。検索の欄を隠す → 表が1行広く、`\` は最下行で打てる。タブを隠す → `]` で切り替わる(`test_SR_20`))
- 変更: NV-18 旧「設定の画面は、よくある表の道具の設定の画面に倣い、左に区画の一覧(表示する列(表示・非表示と順)・フィルター・並べ替え(複数の列と向き)・グループ分け・表示(SR-20))を、それぞれの今の状態(例「列 5/6」「並べ替え 2」)を添えて並べ、右に選んだ区画の中身(何をする所かの一行の説明と項目)を置くべき。「反映」と「取り消し」は画面の上の右にいつも見せ、反映していない変更があればその数を添えるべき。オン・オフの項目はスイッチの形で見せ、色だけに頼らず文字でも状態が分かるようにするべき(SR-15)。」→ 新「設定の画面は、よくある表の道具の設定の画面に倣い、左に区画の一覧(表示する列(表示・非表示と順)・フィルター・並べ替え(複数の列と向き)・グループ分け・表示(SR-20))を、それぞれの今の状態(例「列 5/6」「並べ替え 2」)を添えて並べ、右に選んだ区画の中身(何をする所かの一行の説明と項目)を置くべき。「反映」と「取り消し」は画面の上の右にいつも見せ、反映していない変更があればその数を添えるべき。オン・オフの項目はスイッチの形で見せ、色だけに頼らず文字でも状態が分かるようにするべき(SR-15)。」(確かめ方: `o` → 左に「列 6/6」「フィルター —」「並べ替え —」「グループ —」「表示」、右に列の区画の説明と項目。Tab で並べ替えの区画 → 右がその中身に変わる。並べ替えを足す → 上に「未反映 1」。上の「反映」をクリック → 表に効く。色なしでも区画の印とスイッチの文字で分かる。低い画面では区画の中を流し、選んだ項目がいつも見える(ゴールデン `test_NV_18`))
