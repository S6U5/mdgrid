# ノートの欄の名前を出さない値 off を足す(note-path-off)

## きっかけ

人が、タスクの台帳の表で、左のノートの欄に出るファイルのパスと作成日(ファイル名の先頭の日付)は出さなくてよいと言った(会話 2026-10-15。プロジェクトのチャット)。台帳の表には題名の列があるので、ノートの欄の名前は要らない。

`display.note_path`(2026-10-15-note-path)に、名前を出さず行の印だけを出す値 `"off"` を足す。値の名前は AI が足した細部。

## 差分

- 変更: SR-29 旧「表の左のノートの欄は、末尾の `.md` を除いた名前を、設定 `display.note_path`(SR-46)に従ったフォルダとともに出すべき: `"common"`(既定)は読み込んだ全部の行に共通のフォルダを除いたパス、`"name"` はフォルダを除いた名前だけ、`"full"` は根からのパス。表の列に `file.name` があるときは、欄に名前と見出しを出さず、行の印(`!`・`~`)だけを出すべき。検索(NV-1)と、メッセージ・詳しく見る画面のノートの名前は、根からのパスのままにするべき。」→ 新「表の左のノートの欄は、末尾の `.md` を除いた名前を、設定 `display.note_path`(SR-46)に従ったフォルダとともに出すべき: `"common"`(既定)は読み込んだ全部の行に共通のフォルダを除いたパス、`"name"` はフォルダを除いた名前だけ、`"full"` は根からのパス。表の列に `file.name` があるときと `"off"` のときは、欄に名前と見出しを出さず、行の印(`!`・`~`)だけを出すべき(`"off"` は題名の列で行が分かる表のため)。どちらのときも、親子の字下げと ▾・▸、WBS の番号と進み具合(NV-27・NV-28)は欄に残すべき。検索(NV-1)と、メッセージ・詳しく見る画面のノートの名前は、根からのパスのままにするべき。」(確かめ方: `Tasks/a.md`・`Tasks/b.md` だけの表 → 欄は `a`・`b`。`Tasks/a.md`・`Notes/c.md` → `Tasks/a`・`Notes/c`。`note_path = "name"` で `todo/a.md`・`archive/todo/b.md` → `a`・`b`。`note_path = "full"` で `Tasks/a.md`・`Tasks/b.md` → `Tasks/a`・`Tasks/b`。`note_path = "off"` で `todo/20261015_a.md` → 欄に名前も見出しも出ず、外で変わった行には `!`。親子で並べた表で `"off"` → ▾・▸ と字下げは残る。`"name"` でも `\` の検索で `archive` と打つと `archive/todo/b.md` の行が当たる。order に `file.name` のある `.base` → 欄に名前も見出し「ノート」も出ず、外で変わった行には `!` が出る(`test_sr_29_*`))
- 変更: SR-46 旧「ノートの欄(SR-29)のフォルダの出し方 `display.note_path`(`"common"`・`"name"`・`"full"`。既定 `"common"`)を、表のプロファイルの項目として全体・ワークスペース・表・ビューの範囲(SR-44)に書けるべきで、ビューの設定の「表示」の区画(NV-18)で3つを順に切り替えられ、mdgrid のビュー(BV-17)に保存できるべき。知らない値は警告して既定にするべき(CLI-3)。」→ 新「ノートの欄(SR-29)のフォルダの出し方 `display.note_path`(`"common"`・`"name"`・`"full"`・`"off"`。既定 `"common"`)を、表のプロファイルの項目として全体・ワークスペース・表・ビューの範囲(SR-44)に書けるべきで、ビューの設定の「表示」の区画(NV-18)で4つを順に切り替えられ、mdgrid のビュー(BV-17)に保存できるべき。知らない値は警告して既定にするべき(CLI-3)。」(確かめ方: config.toml に `[display] note_path = "name"` → どの表の欄も名前だけ。ビューの設定の「表示」で「ノートのパス」を `full` にして反映 → そのビューだけ根からのパス。もう一度押して `off` → 欄に名前が出ない。名前を付けて保存して開き直す → 同じ。`note_path = "short"` → `config.toml: display.note_path:` で始まる警告と既定の見た目。`--print-config` の出力と docs/config.md に項目がある(`test_sr_46_*`))

## 却下した案

| 案 | 理由 |
|---|---|
| 何もしない | 題名の列がある台帳で、ノートの欄にファイル名(日付つき)が毎行重ねて出る |
| 欄ごと消す(印も消す) | 外で変わった行と留めた行の印が見えなくなる(2026-10-07-note-column で却下した案と同じ理由) |
| 台帳の .base の order に `file.name` を足して隠す | ファイル名の列が増えるので、人の言う「出さない」にならない |

## 錨との照合

新しい文脈の検証役(書込なし)の照合の要約。`specs/principles.md` は無いので、人の決定の記録(trigger: 人の発言)とだけ照らした。

- 沿う: 一番新しい人の発言(会話 2026-10-15)が、台帳ではノートの欄のパスと日付を出さなくてよいと言った。同じ日の 2026-10-15-note-path に値を1つ足すだけ。2026-10-02-display-options で、人は行の名前の欄を隠すことを却下せず後に残していた。
- ぶつかり: 無い。2026-10-07-note-column が却下したのは「欄ごと消す(印も消す)」で、`"off"` は印を残し、`file.name` の列があるときと同じ扱いに乗る。既定は `"common"` のまま。
- 抜け: 親子(NV-27)と WBS(NV-28)の字下げ・▾・▸・番号は残すと文に書くべき(差分に入れた)。`"off"` で `file.name` の列も無い表では、名前のクリックで開く入口(SR-19)は無くなり、`e` が残る。
