# 長い値を折り返して、表の行を設定した行の数まで伸ばす(row-lines)

## きっかけ

会話 2026-10-12 で人が、列の幅を変えても長い説明が表で読めないと言い、表の行を何行まで伸ばすかを設定で指定できるようにしたい(既定は 0)と提案し、作業の並びの最初にこれを選んだ。人の依頼を AI が要件の文に起こした。行の高さを行ごとに変えること(人の言う「可変で伸ばす」)、折り返しの切り方、2行目より下の飾り、スクロールとクリックの数え方、設定の画面での切り替えの値(0〜3)、範囲(0〜9)は、AI が置いた細部で、承認のときに確かめてもらう。

## 差分

- 追加: CV-8「表の行は、設定 `display.row_extra_lines`(0〜9 の整数。既定 0)で、長い値と改行のある値を折り返し、データの1行を最大で「1 + その数」の行の高さまで伸ばせるべき(列の幅を広げなくても、長い説明を詳細の表示を開かずに表で読めるように)。行の高さは、その行のセルのうち一番多くの行が要るものに合わせ、行ごとに変わってよい(短い値だけの行は1行のまま)。折り返しは列の幅で、字の幅(CV-6)に従って切り、改行のある値は改行で行を分けるべき。伸ばした行に入りきらない値は、最後の行の後ろに `…` を付けるべき。リストの値の札・まとまりの見出しの行・まとまりの間の空き行は1行のままにしてよい。2行目より下の行には行の印(`>` など)と行番号を出さず、列の区切りと、一行おきの色・選んでいる行の色は行の高さ全部に付けるべき。縦のスクロール・ページ送り・マウスのクリックは伸ばした行の高さで数え、選んでいる行は高さ全部が見えるように表を流すべき(画面より高い行は上から入る分だけ見せる)。値の編集の欄と候補の窓は、その行の1行目に出すべき。0 では今の1行の見え方と1字も変わらないべき。ビューの設定の「表示」の区画(NV-18)で 0・1・2・3 を順に切り替え、ビューごとに上書きできるべき(SR-20 と同じ)。範囲の外の値は警告して既定にするべき。」(確かめ方: `row_extra_lines = 2`、列の幅 20 に 50 字の説明 → その行は3行の高さで、説明が全部見える。60 字 → 3行目の終わりが `…`。2行の説明(改行あり) → 2行の高さで1行目と2行目。短い値だけの行 → 1行。伸ばした行の2行目をクリック → その行を選ぶ。一番下の行を選ぶ → その行の高さ全部が見えるまで表が流れる。`row_extra_lines = 0` → 今と同じ(ゴールデン `test_CV_3` が変わらない)。`row_extra_lines = 12` → 警告して 0(`test_cv_8_*`))
- 変更: CV-3 旧「改行を含む値は、1行目の後ろに `…⏎` を付けて表に出し、全文は詳細の表示で見せるべき。」→ 新「改行を含む値は、1行目の後ろに `…⏎` を付けて表に出し(行を伸ばす設定(CV-8)で伸ばせる行があるときは、改行で行を分けて見せ、入らない分だけ最後の行の後ろに `…` を付ける)、全文は詳細の表示で見せるべき。」
- 変更: SR-21 旧「SR-20 の設定は `[display]` の表に `row_numbers`(既定 false)・`zebra`(既定 false)・`column_lines`(既定 false。true で列の間に `│` を引く)・`group_gap`(既定 false。SR-30)・`tabs`(既定 `"always"`。SR-34)・`search_bar`(既定 true。NV-23)・`chips`(既定 true)を持つべき。ビューごとの値はビューの設定(settings)の `display` に、設定と違う項目だけを持ってよい。」→ 新「SR-20 の設定は `[display]` の表に `row_numbers`(既定 false)・`zebra`(既定 false)・`column_lines`(既定 false。true で列の間に `│` を引く)・`group_gap`(既定 false。SR-30)・`tabs`(既定 `"always"`。SR-34)・`search_bar`(既定 true。NV-23)・`chips`(既定 true)・`buttons`(既定 `"plain"`。NV-23)・`bar_padding`(既定 1。NV-23)・`top_padding`(既定 1。SR-1)・`row_extra_lines`(既定 0。CV-8)を持つべき。ビューごとの値はビューの設定(settings)の `display` に、設定と違う項目だけを持ってよい。」
- 変更: SR-21 の例 旧「`[display] row_numbers = true` → 番号が出て、設定の画面の表示の区画でも「行番号」がオン。`[display] search_bar = false` → 検索の欄が無い。`--print-config` の `[display]` に7項目(`test_sr_21_*`)」→ 新「`[display] row_numbers = true` → 番号が出て、設定の画面の表示の区画でも「行番号」がオン。`[display] search_bar = false` → 検索の欄が無い。`--print-config` の `[display]` に11項目(`test_sr_21_*`)」

SR-21 の一覧には、2026-10-12-search-box・bar-padding・bar-padding-half で足した `buttons`・`bar_padding`・`top_padding` が書き漏れていたので、あわせて足す(項目の数は前から10、今回で11)。

## 却下した案

| 案 | 理由 |
|---|---|
| 何もしない(全文は詳細の表示で読む) | 行ごとに K で開くのは手間で、長い説明の列を並べて見比べられない |
| すべての行を同じ高さ(1 + 設定の数)にする | 短い値だけの行まで高くなり、1画面に入る行が減る。人の言う「可変で伸ばす」に合わない |
| 選んでいる行だけを伸ばす | 動かすたびに表の行の位置が上下に揺れる。並べて読む用途に合わない |
