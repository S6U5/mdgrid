# テーマが default のときはガントの時間軸に地の帯を塗らず、帯の試験の錠を掛け直す(gantt-bands-default-theme)

## きっかけ

変更 2026-11-01-gantt-axis で、ガントの時間軸に月ごと・年ごとの地の帯と土日の地を足した。レビューで、テーマが既定の `default`(色の表なし)のときも帯を塗るのは、SR-33・SR-40 の「テーマが default なら端末の地と文字を変えない」と食い違うと指摘された。端末の地の色は既定の設定では問い合わせないので、暗い地とみなして暗い灰で塗り、明るい端末では黒い字が暗い灰に乗って読みにくい。AI が3つの案(default では帯なし・端末の地から作る・今のまま塗る)を示し、人は会話 2026-11-01 で「default では帯なし」を選んだ。

## 差分

- 錠: GA-2(src/ui/test_gantt_axis.rs の `test_ga_2_band_day_months_and_weekends`・`test_ga_2_band_month_by_year` と、それが共有する色の組 `PAINTS`。テーマなしの 24 ビット・256 色・明るい端末の組で帯を期待していたのを、テーマのある組(24 ビットと 256 色、暗いテーマと明るいテーマ)で帯を確かめる形にし、テーマが default のときは帯が無いことを別の試験で確かめる)

要件の文と例は変えない(GA-2 は「色なしでも見分けられる」までで、帯を敷く条件を決めていない。SR-33・SR-40 は今のまま守る)。

## 却下した案

| 案 | 理由 |
|---|---|
| default でも、端末の地を起動時に問い合わせて、分かれば地を少しずらした色で帯を塗る | SR-40 に例外を足す変更が要る。人が選ばなかった |
| default でも、地を暗いとみなして今のまま塗る | SR-40 に例外を足す変更が要り、明るい端末で読みにくいまま。人が選ばなかった |
| 試験の色の組を変えず、試験を消す | 帯を確かめる強さが落ちる |

## 承認の記録

2026-11-01 人の承認(要約: テーマが default のときはガントの帯を塗らない案を選んだ)
