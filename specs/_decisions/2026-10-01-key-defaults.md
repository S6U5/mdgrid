# 既定のキーのぶつかりと抜けを決める(key-defaults)

## きっかけ

仕様の点検(書込なしの点検役、2026-10-01)の指摘: (1) Ctrl+C が、表のモードで読み込みの中止(BV-16)とコピー(OUT-1)の2つに割り当たっていて、SR-16 の「同じモードで1つのキーに2つの動作を割り当てない」に反する。(2) SR-16 の確かめ方は詳細の表示で Enter = 閉じる だが、NV-6 は詳細の表示から編集できるとする。(3) SR-13 は Bases の主なキーとして Tab・Backspace を効かせると定めるが、表のモードでの動作がどこにも無い。(4) WB-10 のやり直しの Ctrl+Shift+Z は多くの端末で区別できず、設計(docs/design.md のテストの節)は `U` も割り当てるとするが、仕様に無い。(5) WB-11 の `q`・NV-5 の全部を選ぶ・選択を解く・NV-8 の強調と絞り込みに既定のキーが無い。SR-16 の既定の表と、新しい SR-18 にまとめて決める。

## 差分

- 変更: SR-16 旧「キーは、モード(表・編集・パレット・保存の確認・詳細の表示)ごとに割り当てるべきで、同じモードの中で1つのキーに2つの動作を割り当てるべきでない。既定は、表で Enter = 編集(グループの見出しの行では開閉、チェックボックスのセルでは切り替え)、Space = 行の印、`K` = 詳細の表示、Ctrl+R = やり直し、編集で Ctrl+R = 編集前の値に戻す、とするべき。`:` はパレットを開き、パレットは行番号(`:120`)と `w`(保存)も受け付けるべき。」→ 新「キーは、モード(表・編集・パレット・保存の確認・詳細の表示)ごとに割り当てるべきで、同じモードの中で1つのキーに2つの動作を割り当てるべきでない。既定は、表で Enter = 編集(グループの見出しの行では開閉、チェックボックスのセルでは切り替え)、Space = 行の印、`K` = 詳細の表示、Ctrl+R = やり直し、編集で Ctrl+R = 編集前の値に戻す、詳細の表示で Enter = 選んだプロパティの編集(NV-6)・Esc と `K` = 閉じる、とするべき。`:` はパレットを開き、パレットは行番号(`:120`)と `w`(保存)と `q`(終了)も受け付けるべき。」(確かめ方: キーの表をモードごとに調べて重複が無い。表で Enter はセルの編集、詳細の表示で Enter は選んだプロパティの編集、Esc で閉じる(`test_SR_16`))
- 変更: WB-10 旧「ためる変更は、取り消し・やり直し(`u` / Ctrl+R と Ctrl+Z / Ctrl+Shift+Z)ができるべき。」→ 新「ためる変更は、取り消し・やり直しができるべき。既定のキーは、取り消しが `u` と Ctrl+Z、やり直しが Ctrl+R と `U` と Ctrl+Shift+Z(Ctrl+Shift+Z は、区別して受け取れる端末だけで効く)とするべき。」(確かめ方: 直して `u` → 元の値に戻り「未保存 0」。Ctrl+Shift+Z を区別できない端末でも `U` でやり直せる(`test_WB_10`))
- 変更: BV-16 旧「ノートが1万あっても、最初の画面は読み込みを待たずに出し、読み込み中は進捗を出し、Ctrl+C で読み込みを止められるべき。」→ 新「ノートが1万あっても、最初の画面は読み込みを待たずに出し、読み込み中は進捗を出し、読み込みの中止の操作(既定は Ctrl+G。Ctrl+C はコピー(OUT-1))で読み込みを止められるべき。」(確かめ方: 1万ノートの材料 → 1秒以内に画面が出て、進捗が増える。Ctrl+G → 読み込みが止まり、読んだ分の表が残る(`test_BV_16`))
- 追加: SR-18「表のモードで、ほかの要件で既定のキーを決めていない動作の既定は、Tab / Shift+Tab = 右 / 左のセルへ移る、Backspace と Delete = 選んだセルの値を空にする(ためる変更。CE-9)、`q` = 終わる(WB-11)、Ctrl+A = 全部の行を選ぶ、Esc = 選択を解く(選択が無ければ簡易の絞り込みを解く。NV-5・NV-2)、`*` = 選んだセルと同じ値の行を強調する、`,` = 同じ値の行だけに絞る(NV-8)、Ctrl+G = 読み込みの中止(BV-16)とするべき。」(確かめ方: 表で Backspace → そのセルが null のためる変更になり「未保存 1」。読むだけのセルでは理由を表示して何もしない。読み込み中に Ctrl+C → コピーになり、読み込みは止まらない(`test_SR_18`)。置き場所: screen/spec.md)

決めた理由: コピーの Ctrl+C は Bases の流儀(SR-13)なので残し、読み込みの中止は Emacs の中止のキー Ctrl+G にした。詳細の表示の Enter は NV-6 に合わせて編集にし、閉じるは Esc と開いたキー `K` にした。`*` は vim の「カーソルの語で検索」、`,` は VisiData の「同じ値の行を選ぶ」に近い。Esc は表のモードで「今かかっている一時的なもの(選択、無ければ簡易の絞り込み)を解く」1つの動作とした。どのキーも SR-13 のとおり設定で割り当て直せる。

## 却下した案

| 案 | 理由 |
|---|---|
| 何もしない | 同じモードで Ctrl+C がぶつかったまま実装に入り、キーの表(SR-4)で重複の検査に落ちる |
| 読み込み中だけ Ctrl+C を中止にする | 同じモードの中で状況によって動作が変わり、読み込み中にコピーしようとした人の読み込みが止まる |
| Ctrl+C を中止にし、コピーは `y` だけにする | Bases の主なキー(SR-13)の Ctrl+C のコピーが効かなくなる |

## 承認の記録

AI 自己採択(検証の指摘の直し。SR-16・SR-18・WB-10・BV-16 は人の決定の要件ではない。キーの流儀(SR-13)を人が選んだ範囲の中の既定の割り当てで、SR-13 の文は変えない。次の決めるモードの束の末尾で事後確認)
