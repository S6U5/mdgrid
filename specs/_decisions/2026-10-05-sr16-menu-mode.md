# SR-16 のモードの並びに操作の一覧を足す(sr16-menu-mode)

## きっかけ

action-menu(SR-24)の実装で新しいモード「操作の一覧」(設定の名前 `menu`)を足した。レビュー役が、SR-16 のモードの並びにそれが無いと指摘した。並びを今のモードに合わせる(意味は変えない)。

## 差分

- 変更: SR-16 旧「キーは、モード(表・編集・パレット・保存の確認・終了の確認・ヘルプ・検索・絞り込み・詳細の表示・ビューの設定・設定の値の入力・設定の帯・リストの選択)ごとに割り当てるべきで、同じモードの中で1つのキーに2つの動作を割り当てるべきでない。既定は、表で Enter = 編集(グループの見出しの行では開閉、チェックボックスのセルでは切り替え)、Space = 行の印、`K` = 詳細の表示、Ctrl+R = やり直し、編集で Ctrl+R = 編集前の値に戻す、詳細の表示で Enter = 選んだプロパティの編集(NV-6)・Esc と `K` = 閉じる、とするべき。`:` はパレットを開き、パレットは行番号(`:120`)と `w`(保存)と `q`(終了)も受け付けるべき。」→ 新「キーは、モード(表・編集・パレット・保存の確認・終了の確認・ヘルプ・検索・絞り込み・詳細の表示・ビューの設定・設定の値の入力・設定の帯・リストの選択・操作の一覧(SR-24))ごとに割り当てるべきで、同じモードの中で1つのキーに2つの動作を割り当てるべきでない。既定は、表で Enter = 編集(グループの見出しの行では開閉、チェックボックスのセルでは切り替え)、Space = 行の印、`K` = 詳細の表示、Ctrl+R = やり直し、編集で Ctrl+R = 編集前の値に戻す、詳細の表示で Enter = 選んだプロパティの編集(NV-6)・Esc と `K` = 閉じる、とするべき。`:` はパレットを開き、パレットは行番号(`:120`)と `w`(保存)と `q`(終了)も受け付けるべき。」
