# ワークスペースの表を、左から重ねて出す引き出しで切り替える(ws-drawer)

## きっかけ

人が、今のワークスペースの中の表を、左のサイドバーを開いてクリックで切り替えたいと言った。そのうえで、左に自分の一覧を出す端末の道具の中で動かすと、サイドバーが2本並んで良くないと心配した。AI が、普段は出さず、必要なときだけ左から表の上に重ねて出し、選ぶと閉じる引き出しにする形を勧め、人がその方向で提案を書くよう頼んだ(会話 2026-10-11 の要約)。今は名前を選んでから表を選ぶ2段階の窓(WS-2)を通るので、同じワークスペースの隣の表へ移るだけでも手数が多く、どんな表があるかも窓を開くまで見えない。人の依頼を AI が要件の文に起こした。

## 差分

- 追加: WS-8「今の範囲(WS-6)の表の一覧を、画面の左から表の上に重ねて出す引き出しで見せ、選んだ表へ移れるようにするべき。引き出しは普段は出さず、表の画面と関係マップのどちらでも、ヘッダーのボタン「ワークスペース」(SR-42)・表の画面のキー `w`(割り当て直せる。SR-13)・パレットで開き、表を選ぶ(クリックか Enter)・Esc・引き出しの外のクリック・開いたのと同じボタンかキーで閉じるべき(出しっぱなしにすると、左に自分の一覧を持つ端末の道具の中で動かしたとき左に帯が2本並び、表の幅も減るため)。引き出しには今の範囲の表を並べて今の表に印を付け、その下にほかのワークスペースを名前の見出しだけ畳んで並べ、見出しを開くとその表が並ぶようにするべき。範囲がワークスペースでない(検知(WS-5)か登録した表(CLI-18))ときは、その範囲の表を並べるべき。ためた変更があるときに別の表へ移るなら、登録した表へ移るとき(CLI-19)と同じく保存か取りやめを確かめるべき。関係マップで開いたら、表の画面に戻ってから開くべき。」(確かめ方: ワークスペース「仕事」に tasks・projects、「趣味」に books → tasks で開き `w` → 左に重ねて tasks(印付き)・projects、その下に畳んだ「趣味」。projects を Enter → projects の表になり、引き出しは閉じる。「趣味」を開いて books をクリック → books の表で範囲は「趣味」。開いて Esc → 何も変わらずに閉じる。未保存の変更があるときに projects を選ぶ → 保存の確かめ。ワークスペースが無く登録した表だけ → 登録した表が並ぶ。普段の画面に引き出しの帯が無い(`test_ws_8_*`))
- 変更: SR-42 旧「ヘッダー(SR-1)の右の端の、画面の型のタブ(REL-8)の左に、ボタン「ワークスペース」と「設定」をいつも出すべき。「ワークスペース」は、ワークスペースの一覧(コマンドのパレットの「ワークスペースを開く」と同じ)を開き、今の範囲がワークスペースならその名前を見せる。「設定」は、ビューの設定の画面(`o`)を開く。どちらも表の画面と関係マップで同じ位置に出し、関係マップで押したら表の画面に戻ってから開くべき。端末の幅が足りないときは、ボタンを隠してタブと「+ 新規」を残すべき(ボタンは近道で、同じことはキーとパレットでできるため)。」→ 新「ヘッダー(SR-1)の右の端の、画面の型のタブ(REL-8)の左に、ボタン「ワークスペース」と「設定」をいつも出すべき。「ワークスペース」は、表の一覧の引き出し(WS-8)を開け閉めし、今の範囲がワークスペースならその名前を見せる。「設定」は、ビューの設定の画面(`o`)を開く。どちらも表の画面と関係マップで同じ位置に出し、関係マップで押したら表の画面に戻ってから開くべき。端末の幅が足りないときは、ボタンを隠してタブと「+ 新規」を残すべき(ボタンは近道で、同じことはキーとパレットでできるため)。」(確かめ方: 「ワークスペース」をクリック → 左に表の一覧の引き出し。もう一度クリック → 閉じる。ほかの例は今のまま)

## 却下した案

| 案 | 理由 |
|---|---|
| 何もしない | 同じワークスペースの隣の表へ移るだけでも、名前と表を選ぶ2段階の窓を通る。どんな表があるかも窓を開くまで見えない |
| 左にいつも出すサイドバー | 左に自分の一覧を持つ端末の道具の中で動かすと、左に帯が2本並び、表の幅も減る(人の心配) |
| その道具の中かを環境変数で見分け、そのときだけ出さない | 特定の道具のための特例になる。ほかの道具の中でも同じことが起きるので、どこでも邪魔にならない形で解く |
| 設定でいつも出すように固定できるようにする | 求められていない。要れば別の提案で足す |
| 表の下にビューも字下げして並べる | ビューの切り替えにはタブ(BV-13・BV-17)がある。引き出しは表の切り替えに絞る |
