# 画面のテーマを見本の7つから選べるようにする(themes)

## きっかけ

会話 2026-10-05(リポの外の会話)で、人の依頼で画面の色の見本を7枚作った(docs/images/theme-mockups/)。会話 2026-10-06 で、人がこれを説明書に載せたいと言い、AI が「見本を残す → テーマを本物の機能にする → 説明書にテーマを選ぶ節を足す」の順を推し、人がその順で最後まで実装するよう頼んだ。人の依頼を AI が要件の文に起こした。設定の名前・既定・色なしと 256 色の扱いは、AI が足す細部として別の提案(themes-details)にした。

## 差分

screen の spec.md の「要件: 版1 — 設定と見た目の状態」に足し、範囲外の次の段の行を、残る自動判定だけに直す。cell-view の範囲外の行も同じに直す。

- 追加: SR-26「画面の色の組み合わせ(テーマ)を、見本の7つ(今の見た目・Nord・Solarized Light・Dracula・Gruvbox・Pink Monster・Dozy Pink)から設定(CLI-3)で選べるべき。今の見た目以外のテーマは、画面の地と文字・ヘッダー・選択・下の帯・列の見出し・強調(太字)・一行おきの色(SR-20)・行の印 `>` を、テーマごとに決めた色で塗るべき。テーマは、色だけで意味を伝えない SR-15 を保ち、画面の型を変える SC-9 と分けるため、色だけを変え、画面の構成・文字・印は変えないべき。」(確かめ方: 設定でテーマを Nord にして起動 → 左上の背景が #2e3440、選んでいるセルの背景が #5e81ac、下の帯の背景が #3b4252。7つのどのテーマでも、画面の文字はテーマなしと1字も違わない(`test_SR_26`))
- 変更: screen の範囲外 旧「次の段: テーマの切り替え(端末のダーク / ライトの自動判定を含む)。」→ 新「次の段: 端末のダーク / ライトの自動判定でテーマを選ぶこと(テーマは SR-26 のとおり設定で選ぶ)。」
- 変更: cell-view の範囲外 旧「次の段: テーマの切り替え(screen の範囲外を参照)。」→ 新「テーマ(色の組み合わせ)は screen の SR-26・SR-27。端末のダーク / ライトの自動判定は screen の範囲外を参照。」

## 却下した案

| 案 | 理由 |
|---|---|
| 何もしない | 見本は試作の画像だけで、人は選べるようにして説明書に載せることを頼んだ |
| 端末の色(16 色の番号)だけで塗る | 端末の配色しだいで見本と違う色になり、見本の7つを選べることにならない |
| テーマで画面の構成も変える | SC-9 のとおり画面の型はテーマで作らない。テーマは色だけ |
