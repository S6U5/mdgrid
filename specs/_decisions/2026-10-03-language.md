# 画面の文言を英語と日本語で切り替える(language)

## きっかけ

docs/todo.md の O-3。画面の文言が全部日本語で、英語を主にする公開と食い違う。会話 2026-10-03 の判断の束で、人が「文言を1か所の表に集め、LANG と設定の language で切り替える。既定は LANG に従う(日本語以外は英語)。公開の条件にする」を選び、のちに対象を挙げて承認した。人の選択を AI が要件の文に起こした。

## 差分

screen の spec.md の「要件: 版1 — 設定と見た目の状態」に足す。

- 追加: SR-23「画面と起動の文言(使い方(`--help`)・起動できない理由・ヘルプ・パレット・下の帯とメッセージ行・キーの表示名・確認の画面・読むだけや未対応や保存が止まった理由・`--print` と `--pick` の警告)を、英語と日本語で出せるべき。設定(CLI-3)の `language`(`"auto"`・`"en"`・`"ja"`。既定 `"auto"`)で選び、`auto` は環境変数 `LC_ALL`・`LC_MESSAGES`・`LANG` の順で最初の空でない値が `ja` で始まれば日本語、それ以外(どれも無いときも)英語にするべき。文言は1か所の表に集め、英語と日本語のどちらかが欠けた文言があれば試験で落ちるべき。ノートの値・列の名前・`.base` の中身・ファイルの名前は訳さないべき。」(確かめ方: `LANG=en_US.UTF-8` で起動 → 下の帯と `--help` が英語。`LANG=ja_JP.UTF-8` → 日本語。`LANG=en_US.UTF-8` で設定に `language = "ja"` → 日本語。どの環境変数も無い → 英語。表の文言に英語か日本語の欠けがある → 試験が落ちる(`test_SR_23`))

## 却下した案

| 案 | 理由 |
|---|---|
| 既定を日本語にして、auto は選んだ人だけ | 人は既定を LANG に従う形を選んだ |
| 英語だけにする | 人は切り替えを選んだ |
| 錠のある試験を書き換えて言語を指定する | 試験の環境の言語を cargo の設定(.cargo/config.toml の [env])で日本語に固定すれば、錠のある試験に触らずに済む |
