# ビューの帯の余白を行の数の設定 bar_padding にし、囲み方の設定から1行の形を外す(bar-padding)

## きっかけ

view-bar-plain(2026-10-12)で、帯の形を `display.buttons` の3つの値(plain・box・compact)にした。人が、plain というより設定の値が 1 なだけで、0 などに調整できればよいのではと言った(会話 2026-10-12 の要約)。余白の行の数と囲み方を別々の設定に分ける。

## 差分

- 変更: NV-23 旧「ビューの帯(SR-1)の、ビューのタブの右に、検索(NV-2)の欄を常に出し、欄の頭にキーと「検索」を示し(例「\ 検索」)、効いている語と、合う行の数(例「12/80行」)を見せるべき。欄の右には、ボタン「絞り込み」(NV-29)・「並べ替え」(NV-24)・「分類」・「列」をこの順に並べ、帯の右の端には、作れるときは「+ 新規」(CE-25)を置き、キーのあるボタンにはそのキーを添えるべき(例「S 並べ替え」。マウスで使う人もキーを覚えられるように)。ボタンの頭のキーの字は、名前と見分けられる見た目(太字で、名前と違う色。色を使わない表示では太字)にするべき(キーの字を名前の一部や数字と取り違えないように。ヘッダーのボタン(SR-42)も同じ)。「分類」と「列」は、ビューの設定の画面(NV-18)をその区画で開くべき。端末の幅が足りないときは、列・分類のボタン、今のでないビューのタブの順に省き、今のビューのタブと検索の欄と、絞り込み・並べ替え・「+ 新規」のボタンをなるべく残すべき。ビューの帯は、上下に1行ずつ余白を取った3行の高さにし、タブとボタンを真ん中の行に並べるべき(表の上が詰まって見えないように)。帯の形は設定 `display.buttons` で選べ、`"plain"`(線で囲まず、欄とボタンを地の色で示す。既定)・`"box"`(検索の欄と、絞り込み・並べ替えのボタンを、それぞれ上下の余白の行まで使って線で四角く囲み、線の中は地の色で塗らない)・`"compact"`(余白を取らず1行)にできるべき。窓(NV-24・NV-29)は帯のすぐ下(`"box"` では囲みの下の線のすぐ下)に開くべき。どの形でも、端末の高さが16行に満たないときは、余白を取らず1行で描くべき(表の行を残すため)。欄は設定で出さないこともでき、出さないときは帯を1行にしてよい。」→ 新「ビューの帯(SR-1)の、ビューのタブの右に、検索(NV-2)の欄を常に出し、欄の頭にキーと「検索」を示し(例「\ 検索」)、効いている語と、合う行の数(例「12/80行」)を見せるべき。欄の右には、ボタン「絞り込み」(NV-29)・「並べ替え」(NV-24)・「分類」・「列」をこの順に並べ、帯の右の端には、作れるときは「+ 新規」(CE-25)を置き、キーのあるボタンにはそのキーを添えるべき(例「S 並べ替え」。マウスで使う人もキーを覚えられるように)。ボタンの頭のキーの字は、名前と見分けられる見た目(太字で、名前と違う色。色を使わない表示では太字)にするべき(キーの字を名前の一部や数字と取り違えないように。ヘッダーのボタン(SR-42)も同じ)。「分類」と「列」は、ビューの設定の画面(NV-18)をその区画で開くべき。端末の幅が足りないときは、列・分類のボタン、今のでないビューのタブの順に省き、今のビューのタブと検索の欄と、絞り込み・並べ替え・「+ 新規」のボタンをなるべく残すべき。ビューの帯は、既定で上下に1行ずつ余白を取った3行の高さにし、タブとボタンを真ん中の行に並べるべき(表の上が詰まって見えないように)。上下の余白の行の数は設定 `display.bar_padding`(0〜2。既定 1)で変えられ、0 では余白を取らず1行にするべき。囲み方は設定 `display.buttons` で選べ、`"plain"`(線で囲まず、欄とボタンを地の色で示す。既定)か `"box"`(検索の欄と、絞り込み・並べ替えのボタンを、それぞれ上下の余白の行に線を引いて四角く囲み、線の中は地の色で塗らない。余白が 0 なら囲まない)にできるべき。窓(NV-24・NV-29)は帯のすぐ下(`"box"` では囲みの下の線のすぐ下)に開くべき。端末の高さが16行に満たないときは、余白を 0 として描くべき(表の行を残すため)。欄は設定で出さないこともでき、出さないときは帯を1行にしてよい。」
- 確かめ方: NV-23 旧の例「起動(80×24)→ 2〜4行目がビューの帯で(2行目と4行目は空き)、3行目にタブ「既定の表」、その右に空の検索の欄「\ 検索…」と、キーを添えた絞り込み・並べ替えのボタン(例「S 並べ替え」)、「分類」「列」、右の端に「a + 新規」。設定の ⚙ は無い。「会議」で絞る → 欄に「会議」と「3/16行」。「分類」を押す → ビューの設定の画面の分類の区画。幅 60 → 列・分類が無く、絞り込みと並べ替えと「+ 新規」は出る。ボタンの頭のキーの字は太字で、名前と見た目が違う。「\| 絞り込み」を押す → 窓は5行目に開く。設定 `display.buttons = "box"` → 欄と絞り込み・並べ替えが線で四角く囲まれ、線の中は地の色が無い。`"compact"` → ビューの帯は1行。高さ 14 → ビューの帯は1行。設定で欄を消す → 欄が無く、`\` を押せば最下行で打てる(`test_NV_23`)」→ 新の例「起動(80×24)→ 2〜4行目がビューの帯で(2行目と4行目は空き)、3行目にタブ「既定の表」、その右に空の検索の欄「\ 検索…」と、キーを添えた絞り込み・並べ替えのボタン(例「S 並べ替え」)、「分類」「列」、右の端に「a + 新規」。設定の ⚙ は無い。「会議」で絞る → 欄に「会議」と「3/16行」。「分類」を押す → ビューの設定の画面の分類の区画。幅 60 → 列・分類が無く、絞り込みと並べ替えと「+ 新規」は出る。ボタンの頭のキーの字は太字で、名前と見た目が違う。「\| 絞り込み」を押す → 窓は5行目に開く。設定 `display.buttons = "box"` → 欄と絞り込み・並べ替えが線で四角く囲まれ、線の中は地の色が無い。`display.bar_padding = 0` → ビューの帯は1行。`2` → 上下に2行ずつ空く。高さ 14 → ビューの帯は1行。設定で欄を消す → 欄が無く、`\` を押せば最下行で打てる(`test_NV_23`)」

## 却下した案

| 案 | 理由 |
|---|---|
| 囲み方の値に 1行の形(compact)を残す | 余白の行の数と囲み方が1つの値に混ざり、余白だけを変えられない |
