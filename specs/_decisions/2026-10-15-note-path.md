# ノートの欄にフォルダを出すかを、設定とビューごとに選べるようにする(note-path)

## きっかけ

人が、タスクの台帳(`todo/` と `archive/todo/` のノートを1つの表に並べる)で、表の左のノートの欄に `archive/todo/…` のようなフォルダのついた名前が出るのを見て、フォルダまで出すかどうかを、既定の設定でもビューごとの設定でも変えたいと言った(会話 2026-10-15。プロジェクトのチャット)。

人の依頼を AI が要件の文に起こした。項目の名前 `display.note_path` と3つの値(今どおりの `"common"`・名前だけの `"name"`・根からのパスの `"full"`)は AI が足した細部。SR-21 の `[display]` の項目の一覧に足すのは、検証役の指摘による。

## 差分

- 変更: SR-29 旧「表の左のノートの欄は、読み込んだ全部の行に共通のフォルダと、末尾の `.md` を除いた名前を出すべき。表の列に `file.name` があるときは、欄に名前と見出しを出さず、行の印(`!`・`~`)だけを出すべき。検索(NV-1)と、メッセージ・詳しく見る画面のノートの名前は、根からのパスのままにするべき。」→ 新「表の左のノートの欄は、末尾の `.md` を除いた名前を、設定 `display.note_path`(SR-46)に従ったフォルダとともに出すべき: `"common"`(既定)は読み込んだ全部の行に共通のフォルダを除いたパス、`"name"` はフォルダを除いた名前だけ、`"full"` は根からのパス。表の列に `file.name` があるときは、欄に名前と見出しを出さず、行の印(`!`・`~`)だけを出すべき。検索(NV-1)と、メッセージ・詳しく見る画面のノートの名前は、根からのパスのままにするべき。」(確かめ方: `Tasks/a.md`・`Tasks/b.md` だけの表 → 欄は `a`・`b`。`Tasks/a.md`・`Notes/c.md` → `Tasks/a`・`Notes/c`。`note_path = "name"` で `todo/a.md`・`archive/todo/b.md` → `a`・`b`。`note_path = "full"` で `Tasks/a.md`・`Tasks/b.md` → `Tasks/a`・`Tasks/b`。`"name"` でも `\` の検索で `archive` と打つと `archive/todo/b.md` の行が当たる。order に `file.name` のある `.base` → 欄に名前も見出し「ノート」も出ず、外で変わった行には `!` が出る(`test_sr_29_*`))
- 変更: SR-21 旧「SR-20 の設定は `[display]` の表に `row_numbers`(既定 false)・`zebra`(既定 false)・`column_lines`(既定 false。true で列の間に `│` を引く)・`group_gap`(既定 false。SR-30)・`tabs`(既定 `"always"`。SR-34)・`search_bar`(既定 true。NV-23)・`chips`(既定 true)・`buttons`(既定 `"plain"`。NV-23)・`bar_padding`(既定 1。NV-23)・`top_padding`(既定 1。SR-1)・`row_extra_lines`(既定 0。CV-8)を持つべき。ビューごとの値はビューの設定(settings)の `display` に、設定と違う項目だけを持ってよい。」→ 新「SR-20 の設定は `[display]` の表に `row_numbers`(既定 false)・`zebra`(既定 false)・`column_lines`(既定 false。true で列の間に `│` を引く)・`group_gap`(既定 false。SR-30)・`tabs`(既定 `"always"`。SR-34)・`search_bar`(既定 true。NV-23)・`chips`(既定 true)・`buttons`(既定 `"plain"`。NV-23)・`bar_padding`(既定 1。NV-23)・`top_padding`(既定 1。SR-1)・`row_extra_lines`(既定 0。CV-8)・`note_path`(既定 `"common"`。SR-29・SR-46)を持つべき。ビューごとの値はビューの設定(settings)の `display` に、設定と違う項目だけを持ってよい。」(確かめ方: `[display] row_numbers = true` → 番号が出て、設定の画面の表示の区画でも「行番号」がオン。`[display] search_bar = false` → 検索の欄が無い。`--print-config` の `[display]` に12項目(`test_sr_21_*`))

## 却下した案

| 案 | 理由 |
|---|---|
| 何もしない | 台帳で todo と archive の行を並べると、名前の前に毎行フォルダが出て読みにくい。決めたビューで名前だけにする道が無い |
| 真偽値(フォルダを出す・出さない)にする | 今の「共通のフォルダだけを除く」と、根からのパスを全部出すのを見分けられない |
| 名前だけのときに同じ名前の行を見分ける印を付ける | 人は頼んでいない。台帳はファイル名に日付を持つので重なりにくい。要れば別の提案にする |
