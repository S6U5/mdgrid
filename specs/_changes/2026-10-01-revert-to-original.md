## 要求

報告の要約(会話 2026-10-01): セルの値を直したあとで元の値に戻しても、変更として扱われる(未保存に数えられる)。元の値に戻したら変更でないのが期待。

今の仕様に「元の値に戻したら外す」決まりは無く、照合でも「禁じる要件が無い」として通っていた(変更の記録 v1-full-spec のタスク 7 のレビュー)。戻したつもりでも、書き戻しで書式・クオートが変わりうる(例: クオートの無い日付は二重引用符つきで書かれる。write-back の未決の問い)ので、見た目だけでなくファイルを守るためにも外す。

終わりの条件: ためた値がそのセルの最後に読んだ値と同じになったら、その (行, 列) はためる変更から外れ、未保存の数・保存の差分・セルの `*` の印に出ない。取り消し・やり直しで戻せる。関係する要件: WB-9・WB-10・WB-1・SR-15・CE-10。

## 不明点と仮定

- 仮定: 「元の値」は、そのセルの最後に読んだ値(`Source::get`)とする。外で変わって読み直したあと(WB-16)も、今の読んだ値と比べる。外れたら: 最初にためた時点の値と比べる形に直す。
- 問い → 答え(要約、会話 2026-10-02): 元が空(キーが無い・`key:`)のチェックボックスで Enter を2回押すと、false を書く変更が残る → 2回で元に戻す(空 → true → 空と切り替え、false はリストから選ぶ)。
- 仮定: 値の同じさは型を見て比べる(数の `3` と文字の `"3"` は違う、`3` と `3.0` は同じ数、Null と空の文字列は違う)。書くと意味が変わるものは違う値として扱う。

## 設計

核の `Changes::set` と `set_many`(src/changes.rs)で、ためる値を `Source::get(row, col).value`(最後に読んだ値)と比べ、同じなら、その (行, 列) のためた値を外す手として積む(ためていなければ何もせず手も積まない)。行のためる変更が無くなれば、その行の基準と印も、今の取り消しの決まり(タスク 7 のレビューで直した形)どおりに扱う。比べ方は `NewValue` と `Value` を型つきで比べる関数を changes の中に置く(Null と Null、Str と Str は完全一致、Int・Float は数として同じ、Bool と Bool。キーが無いセルに Null は今の SR-18 のとおり何もしない)。画面は Changes の数と pending を見るだけなので変えない(1行の入力の「文字が同じなら書かない」は今のまま)。

選ばなかった案: 保存のときに同じバイトになる行を除く(未保存の数と印が残る。書式が変わる値を除けない)。
