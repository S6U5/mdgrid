## 要求

docs/todo.md の O-3(公開の条件)。画面と起動の文言を英語と日本語で出し、設定の `language`(auto/en/ja、既定 auto)で選ぶ。auto は LC_ALL・LC_MESSAGES・LANG の順で ja で始まれば日本語、ほかは英語(SR-23)。日本語の出力は今とバイトまで同じにする(golden と錠のある試験がそのまま通る)。

終わりの条件: SR-23 の例のとおり。文言の表に英日の欠けが無く、lib・ui・main の文字列のリテラルに日本語が残っていない(訳さないものは許す表で)。

## 不明点と仮定

- 人の選択(2026-10-03): 既定は LANG に従う(案 A)。錠のある試験は書き換えず、試験の環境の言語を `.cargo/config.toml` の [env](LC_ALL・LANG を ja_JP.UTF-8 に force)で固定する(cargo の [env] が試験の実行と、そこから立てる実行ファイルに効くことを scratchpad で確かめた)。env_clear して立てる tests/pty/mod.rs(錠の外)は LANG を ja_JP.UTF-8 にする。
- 仮定: clap の誤りは設定を読む前に出るので、環境の言語で出す(SR-23 の小さな例外。docs/design.md に書く)。
- 仮定: .cargo/config.toml の [env] の force は `cargo run` にも効くので、開発中の `cargo run` は利用者の LANG や設定の auto に関係なく日本語になる(英語で見るには設定に `language = "en"` か、target の実行ファイルを直接起動する)。docs/design.md に書く(タスク4)。
- 仮定: man と補完の説明(clap の about・long_about・`///`)は日本語のまま(訳さないものの表に入れる。英語にそろえるかは後で)。
- 仮定: `--print-config` のコメント(今は英語)と man・補完の説明は、この変更では今のまま(英語にそろえるかは後で)。config_items.rs の ja と ty_ja は文書と突き合わせる正本なので表に移さない。
- 仮定: 曜日の名前(types.rs の WEEKDAY_NAMES。日付の形の ddd の読み書き)はノートの値の形に関わるので訳さない。
- 仮定: 日本語が同じでも意味の違う文(「取り消し」など)は表で別の行にする。

## 設計

設計役の調べ(2026-10-03)による。

- 文言の表: lib に `src/i18n.rs`(`pub mod i18n`)。`msgs! { Key = "english", "日本語"; … }` のマクロで `pub enum Msg`・`Msg::ALL`・`const fn en/ja`・`fn text()`(今の言語)・`fn fill(&[&dyn Display])`(`{0}`・`{1}` の番号の差し込み。ほかの `{` はそのまま)を作る。片方が欠けた行はコンパイルで落ちる。依存は足さない(fluent は重く、const で持てず、欠けを型で閉じられない)。
- 言語の届け方: `Lang { En, Ja }`・`Language { Auto, En, Ja }`・`resolve(setting, env_fn)`・`set_default(lang)`(main だけ)・`current()`(スレッドの上書き > 既定 > 環境)・`scoped(lang)`(試験用の guard)。main は最初に環境から決め、`take_options` のあと `config::peek_language` で設定の language だけを読んで上書きする。`Config` に `language` を足す(`Startup` と App には足さない。錠の試験が構造体の式で作るため)。
- 公開の定数は残す: `writeback::NO_PERMISSION = Msg::NoPermission.ja()`、`EMPTY_HEADING`、`USAGE`(日本語のまま。`USAGE_EN` と `usage()` を足す)。表示には `.text()`。
- キーの表: `Binding`・`Command` に `msg: Msg` を足し、`label`・`section` は日本語の &'static str のまま(錠のある test_keymap.rs が label を見る)。表示(hints・ヘルプ・パレット)は、日本語のときは `label`・`section`(既定の表では `msg.ja()` と同じ。試験が表に無い名前の行を足して確かめるため)、ほかの言語では `msg`。`Mode::by_name` は名前・日本語・英語のどれでも受ける。
- 試験の言語: `.cargo/config.toml` の [env] で LC_ALL・LANG を ja_JP.UTF-8 に force。英語の試験は `scoped(En)` か、実行ファイルに LANG=en_US.UTF-8 を明示(LC_ALL・LC_MESSAGES は env_remove)。
- 却下: 引数で渡す(公開の trait の形が変わる)、App・Source に持たせる(Startup に足せない、lib にも要る)、日本語の文をキーにして表示の直前に訳す(差し込みの逆引きが壊れやすく、表が1か所にならない)。
- 確かめ方(各段): `UPDATE_GOLDEN` を付けずに `cargo test`・clippy・`check.py`。`git diff --exit-code tests/golden specs/test-locks.json` が空、錠のあるファイルを触っていない。

## 実装の気づき
