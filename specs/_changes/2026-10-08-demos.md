## 要求

人の依頼(会話 2026-10-08 の要約): 機能ごとの紹介をスクリプトにして、動くのを見たい。全部をまとめたものも欲しい。置き場所は mdgrid のリポ。そのあと人は、ターミナルを自動で操作するのは危ないと気にし、録画をコミットしたくないとし、ほかのプロジェクトの定番のやり方にすると決めた。

## 不明点と仮定

- 人に聞いた: 置き場所は mdgrid のリポ。やり方は定番(台本から録画を作り、録画はコミットしない)。
- 仮定: 道具は VHS(Charm)。台本(.tape)だけをコミットし、GIF は demos/out/(git に入れない)。使う人のターミナルでは何も動かさない。
- 仮定: 画面は日本語。字の形は日本語を含む等幅の BIZ UDGothic(手元にある前提。無ければ README の案内で替える)。

## 設計

- demos/setup.tape: 録画に映さない準備。examples/ を一時フォルダに写し、ホーム・設定・状態をその中にする。
- demos/<機能>.tape: 設定(字の形・大きさ)→ Source setup.tape → 操作。出力は demos/out/<機能>.gif。
- demos/record.sh: 組んでから、全部か選んだ台本を撮る。
- 説明: demos/README.md、CONTRIBUTING の1節。.gitignore に /demos/out/。

## 実装の気づき

- 最初は、今のターミナルで mdgrid を自動で操作する Python のスクリプトを作った。人が危なさを気にし(キーがずれるとシェルにコマンドとして入る余地がある)、定番のやり方を選んだので、VHS の台本に置き換えた。
- VHS の既定の字の形には日本語が無く、文字の間が空いて見えた。BIZ UDGothic にし、行の高さを 1.25 にした。
- 登録した表の一覧のパスを短く見せるため、準備でホームを一時フォルダにした(`~/examples/…` と出る)。
- 登録した表があると、引数なしの mdgrid は一覧を出す。places 以外の台本は `mdgrid .` とフォルダを渡す。

## 照合
