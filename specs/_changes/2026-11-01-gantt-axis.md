## 要求

人が会話 2026-11-01 で、Artifact に載せたガントの画面(見本の台帳 examples/tasks を日・週・月の単位で撮ったもの)を見て、月の単位が醜くないか、縦線を入れる方がよいかを尋ねた。AI が原因(1か月1字のため見出しが月の一の位の数字の列になり、年の見出しが「20262027」とくっつき、棒がどれも1〜2字の塊になる。日の単位の見出しも日の一の位の列)と直し方(月は1か月3字・日は月曜の日だけ・縦線でなく地の帯)を示し、人が直すと決めた。あわせて、ガントの画面の一番下に表の画面の案内「見出しの行(1件)。Enter で開閉」が残る崩れも直す。

終わりの条件:
- 月の単位: 1か月が3字で、見出しの下の行に月の数(` 9 10 11 12  1`)、上の行に年が1月の位置にだけ出て、年どうしがくっつかない。棒は旬(1〜10日・11〜20日・21日〜末日)の字で塗る。
- 日の単位: 見出しの下の行は月曜の日だけ(`5`・`12`・`19`・`26`)。
- テーマ(色の表)のある色ありの表示で、時間軸の地が日・週の単位では月ごと、月の単位では年ごとに交互に変わり、日の単位の土日は別の地になる。テーマが default(色の表なし)と色なしでは地を付けない(SR-40。gantt-bands-default-theme)。
- ガントの画面(と木・関係マップの画面)のメッセージ行に、表の選んでいる行の案内が出ない。

関係する要件: GA-2・GA-3・GA-4(ガント)、SR-15(色なしでも見分けられる)、TR-1・REL-7(木・関係マップの画面のメッセージ行)。

## 不明点と仮定

- 仮定: 人の「直しましょうか」は、AI が示した3つ(月の3字・日の見出し・地の帯)と、前に挙げた2つの崩れ(年がくっつく・表の案内が残る)の全部を直す意味。外れたら: 地の帯を外す。
- 仮定: 週の単位の見出し(年と、1日を含む週の月の数、ほかは `·`)は今のまま変えない。人は月の単位を挙げ、週は読めているため。外れたら: 週も月の数の形を揃える。
- 仮定: 地の帯は、色の表(テーマ)の地と選びの地の間の色で作り、テーマの無いときは端末の地(分かれば)から作る。分からなければ暗い地とみなす(下の帯の地 `bar_bg` と同じ前提)。→ 外れた: レビューで SR-33・SR-40(テーマが default なら端末の地と文字を変えない)と食い違うと指摘された。人に3つの案を聞き、人は「default では帯なし」を選んだ(会話 2026-11-01。決定 gantt-bands-default-theme)。帯はテーマのあるときだけ敷く。
- 仮定: 選んでいる行は、地の帯より選びの見た目を先にする(行の全体が選びの地。今と同じ)。
- 仮定: メッセージ行の表の案内を消すのは、ガントだけでなく木と関係マップの画面でも同じ(原因が同じで、表の行の案内は表の画面のものだから)。

## 設計

変える場所:
- 核 `src/gantt.rs`(画面に依存しない): 時間軸の「字」の層を足す。`col_chars(unit) -> i64`(日・週は 1、月は 3)、`col_of(day, origin, unit) -> i64`(日が左端から何字目か。月は `cell_of * 3` に旬の 0・1・2 を足す)、`col_days(j, origin, unit) -> (i64, i64)`(j 字目の日の範囲。月は旬の範囲)。今の `cell_of`・`cell_start`・`fit_unit`・`floor_unit` は単位のマスのまま変えない(錠のある試験 test_ga_2_* のとおり)。
- 画面 `src/ui/gantt.rs`:
  - `bar_cells`: マスの代わりに字で回す。字 j の日の範囲(`col_days`)が棒の範囲と重なれば棒、塗りの長さは棒の字の数(`col_of` の始まりから終わり)に対する割合(左にはみ出しても棒の始まりから数えるのは今のまま)。印 `◆` と今日 `┊` も字の範囲で見る。
  - `axis_header`: 字で組む。日: 上は今のまま(月の始まりと左端に「YYYY-MM」か「MM」)、下は月曜の字にその日の数(1〜2字)。週: 今のまま。月: 下は月のマスの先頭の字から月の数を右寄せ2字(`{m:>2}`)、上は1月のマスと左端に「YYYY」(次の切れ目までの字が4以上のときだけ)。今日の字は、下の行が空(空白か `·`)なら `▾`、数に重なれば数を残してその字を反転(週だけだった扱いを全部の単位に)。
  - 地の帯: 時間軸の字ごとに地の段(0 = なし、1 = 帯、2 = 土日)を決める関数 `band_of(j)`(日・週: 月の番号の偶奇、月: 年の偶奇。日の単位の土日は 2)。見出しの2行と、選んでいない行の時間軸の字に、段ごとの地の色を付ける(続く同じ段はまとめて1つの Span)。選んでいる行は今のまま行の全体を選びの見た目にする。色なし(`ColorMode::None`)では付けない(字は変えない。SR-15)。
  - `gantt_today`: 今日を左から 1/3 に置く戻りの数を、字ではなくマスで数える(月は3字なので `cols / 3 / TODAY_AT` マス)。
- 地の色 `src/ui/look.rs`: `axis_band(app, level) -> Option<Color>`。色なしとテーマが default(色の表なし。SR-40、決定 gantt-bands-default-theme)は None。テーマの地を明暗の逆へ寄せ、段を土日 → 帯 → 帯の上の土日の順に、寄せ幅 9・18・27(前の段より 9 は先)から、地・選びの地・決めた段のどれとも成分で 8 以上離れる所まで寄せる。256 色は番号を色に戻して比べ(`theme::indexed_rgb`。src/theme.rs)、一行おきの色(24 ビットの (58,58,58)、256 色の 237)は使わない。(最初の設計の `mix(bg, sel_bg, …)` と端末の地からの色は、レビューと人の決定で今の形にした。経緯は「実装の気づき」と「レビューの指摘」)
- メッセージ行 `src/ui/bands.rs` の `message`: `on_gantt`・`on_tree`・`on_relmap` のときは、表の選んでいる行とセルの案内(見出しの行・外の変化・ためた値・読むだけの理由など)を出さない(`app.message` の知らせは今どおり出す)。
- 文書: docs/design.md のガントの節に時間軸の形(字の層・見出し・地の帯・メッセージ行)、docs/keys.md・docs/keys.ja.md の `gantt` の節に「月の単位は1か月3字(旬ごと)、色のテーマ(default 以外)では月か年ごとに地の色を変える、今日が見出しの数に重なれば反転」の1文。

変えない場所: 単位の決め方(`fit_unit`)、`h` `l` が1単位動くこと、週の単位の見出し、棒・印・今日の字(`█` `░` `◆` `┊` `▾`)、錠のある試験。

選んだ案と却下した案:
- 地の帯を選ぶ。却下: 縦線の字(1字が1日なので線がそのマスを使い、棒の通る所で切れて点線に見える。今日の印 `┊` と見分けにくい)。
- 月は1か月3字で旬を塗る。却下: 1か月1字のまま見出しだけ直す(月の数を書く場所が無く、棒がどれも1字の塊のまま)。却下: 1か月4字で「10月」(言語ごとに幅が変わり、数だけで読める)。
- 字の層を核に足し、単位のマスの関数は変えない(錠のある単位の試験を保ち、`h` `l`・単位の決め方はマスで考える)。

要件ごとの対応: GA-2 → gantt.rs(字の層)・ui/gantt.rs(見出し・棒・帯)・look.rs。GA-3 → ui/gantt.rs の塗り(月の単位の字で数える)。GA-4 → ui/gantt.rs の `gantt_today`。SR-15 → 色なしで地を付けない・今日の数の反転。TR-1・REL-7 → bands.rs の `message`。

## 実装の気づき

- 錠の無い既存の試験 `src/ui/test_gantt_more.rs::test_ga_2_header_labels_do_not_swallow_the_next_month` は、古い見出しの形(日の一の位の並び「7890123」、月の一の位の並び「▾12123456789012」)を期待していた。形を変えることがこの変更の目的なので、同じ所(日の下の行・月の見出しの年の位置)を新しい形で確かめるよう期待を直した(弱めていない。日は 11/02 の月曜の「2」の位置、月は「10 11 12  1  2  3」と、年がくっつかないことを足した)。
- 最初の地の帯は、月ごとの帯が薄すぎ(撮った画面で 10月と11月の違いがほぼ見えない)、土日の縞が強すぎて縦線のように見えた。帯を主(地と選びの地の 0.25)、土日はその上に 0.12 だけ重ねる形にした(`look::axis_band` の level を2つの位にした)。
