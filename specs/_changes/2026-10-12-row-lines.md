## 要求

人が会話 2026-10-12 で、列の幅を広げても長い説明が表で読めないと言い、表の行を何行まで伸ばすかを設定で指定できるようにしたい(既定は 0)と提案した。そのあと、作業の並びの最初にこれを選んだ。

今は表のセルがいつも1行で、改行のある値は1行目と `…⏎`(CV-3)、長い値は列の幅で `…`(CV-5)で切れ、全文は詳細の表示(NV-6)でしか読めない。

終わりの条件:
- 設定(例 `display.row_extra_lines`)で、データの1行を最大で 1 + N 行の高さまで伸ばせる。既定 0 では今と同じ1行。
- 例: N = 2 で、列の幅 20 に 50 字の説明 → その行は3行の高さで、説明が折り返して全部見える。60 字なら3行目の終わりが `…`。改行のある値は、改行で行を分けて見せる。
- 境界: N = 0 の画面は今と1字も変わらない(既存のゴールデンが通る)。

関係する要件: CV-3・CV-5(セルの見せ方)、NV-6(詳細の表示の折り返し)、SR-1・SR-3(表の行とスクロール)、SR-20・SR-21(表示の設定の項目と書き出し)、NV-18(ビューの設定の画面の「表示」の区画)。

## 不明点と仮定

人に聞く問いは無い(依頼の芯は「何行まで伸ばすかを設定で、既定 0」で決まっている)。細部は仮定を置き、仕様の提案に書いて承認で確かめてもらう。

- 仮定: 行の高さは行ごとに変える(人の言う「可変で伸ばす」)。外れたら: 全部の行を同じ高さにする。
- 仮定: 折り返しは字の単位(詳細の表示 NV-6 の折り返しと同じ。語の切れ目は見ない)。外れたら: 英字は空白で切る形を足す。
- 仮定: リストの値の札・まとまりの見出し・空き行・集計の行は1行のまま。外れたら: 札も折り返す。
- 仮定: 表の先頭の行(top)はデータの行の単位のままにし、行の途中から描かない。画面より高い行は上から入る分だけ見せる。
- 仮定: 列の幅の決め方(CV-5)は変えない。幅を決めてから、その幅で行の高さを数える(幅と高さの循環を避ける)。
- 仮定: 設定の画面では 0→1→2→3→0 と回す。設定ファイルでは 0〜9 を書ける。外れたら: 範囲を広げる。

## 設計

変える場所:
- 設定の項目: `src/display.rs`(`Display.row_extra_lines: u8`、`Item::RowExtraLines`、`ITEMS` を 11 に、`DisplayOverride`・`OVERRIDE_KEYS`・`all`・`apply_to`、0→1→2→3→0 の `set_row_extra_lines`)、`src/profile.rs`(読み込み。0〜9 の整数でなければ警告して既定)、`src/schema.rs`、`src/i18n.rs`、`src/ui/display.rs`(`toggle_display`・`draft_*`)、`src/ui/settings_view.rs`(値の字「N行」)、`docs/config.md`・`docs/config.ja.md`。
- 行の高さ: 新しい `src/ui/rows.rs` に、行の高さと位置の計算を1か所に集める。`height(app, lay, cols, i)`(slot i の行の数)、`frame(app)`(見えている slot と、その表の中の y と描く高さ)、`slot_y(app, i)`(slot i の1行目の表の中の y。見えなければ None)、`slot_at(app, dy)`(表の中の y にある slot)、`page(app)`(ページ送りの行の数)、`top_for(app)`(選んだ行の高さ全部が見える top)。どれも `row_extra_lines == 0` なら今の算術(1 slot = 1行)をそのまま返す(0 で1字も変わらないことを、計算の道を分けて守る)。
- セルの文字: `src/ui/cell.rs` に、改行を残す道(`first_line_marked` が、`keep_newlines` の間は行ごとに sanitize して `\n` でつなぐ。`width.rs` の `set_ambiguous_wide` と同じスレッドローカルの切り替え)と、`cell_lines(app, row, col, cw, max)`(折り返した行の列。入らなければ最後の行の後ろに `…`)を置く。折り返しは `detail.rs` の `wrap` を `width.rs` に移して共有する。
- 描く所: `src/ui/view.rs` の render のループを `rows::frame` で回し、`data_row` が `Vec<Line>`(行の高さの分)を返す。2行目より下は、行の印・行番号・ノートの名前の欄を空白にし、列の区切り・一行おきの色・選んでいる行の色は1行目と同じに付ける。札(Chips)・編集中の入力の欄の列は2行目より下を空白にする。`visible_rows`・`selected_drawn`・`hit` は `rows` を使う。
- スクロールとクリック: `src/ui/app.rs` の `scroll_into_view`(下へ流すときは `rows::top_for`)と PageUp・PageDown(`rows::page`)、`src/ui/nav.rs` の Ctrl+d・Ctrl+u(`page / 2`)。行から画面の y を出す `data_y + row - top` の3か所(`src/ui/input.rs`・`src/ui/menu.rs`・`src/ui/listpick.rs`)は `rows::slot_y` に。

変えない場所: 列の幅の決め方(CV-5。幅を先に決め、高さはその後で数える)、ノートの名前の欄(1行のまま。行の名前で、字下げと木の印を持つ)、まとまりの見出し・空き行・集計の行、`app.top` の意味(slot の添字)、詳細の表示。

判断:
- 列の幅を測る行は、`top` から表の高さの数の slot(1 slot を1行と数えたときに見える範囲)にする。行を伸ばすと実際に見える行はそれより少ないが、見える行で測り直すと高さが変わり、高さが変わると見える行が変わって循環する。多めの範囲で測れば幅は1回で決まり、スクロールで列の幅が揺れにくい。0 では今と同じ範囲。
- 行の高さは、見えている列(横に流した後)のセルで数える。隠れた列の長い値で行が高くならないように。
- 改行を残す道は、`shown` に引数を足さずスレッドローカルで切り替える。`shown` は多くの所(検索・幅・コピー)から呼ばれ、改行を残すのは表の行を描くときだけなので。文字が列の幅に入り、`…⏎` を含まないセルは切り替えずに1行と決める(重い計算を避ける)。
- 却下: 全部の行を同じ高さにする(提案で却下)。表を Line でなく「画面の行の位置つきの slot」に作り直す(影響が overlay 全部に及び、0 での不変を守りにくい)。

要件との対応:
- CV-8: `display.rs`・`profile.rs`・`schema.rs`(設定)、`rows.rs`(高さ・スクロール・クリック)、`cell.rs`(折り返し・`…`)、`view.rs`(描く・飾り)、`input.rs`・`menu.rs`・`listpick.rs`(1行目に欄と窓)、`settings_view.rs`・`ui/display.rs`(0〜3 の切り替え)。
- CV-3: `cell.rs` の改行を残す道(伸ばせるときは改行で行を分ける)。
- SR-21: `display.rs` の `DisplayOverride::all`(`--print-config` の11項目)、`docs/config*.md`。

## 実装の気づき

- 仕様の CV-8 の例「60 字 → 3行目の終わりが `…`」は、幅 20 の列の3行にちょうど入る(`…` は付かない)。受け入れの試験は 61 字で確かめた。
- 受け入れの試験の2本は、試験の側の誤り(検索の欄の「検索…」の `…` を拾った・行番号の前に空白があると仮定した)だったので、実装のときに直した(試験のファイルは錠の無い新しいファイル)。
- 表示の区画の項目が11になると、錠のある試験の2本が逆の前提を持つ: test_display_more の1本は「最後の項目は設定の帯」、test_display_options の共通の道具は「下へ10回まで」。新しい項目を設定の帯の前に置き、共通の道具の探す回数を項目の数にした。錠は人の承認で掛け直した([row-lines-locks](../_decisions/2026-10-13-row-lines-locks.md))。
