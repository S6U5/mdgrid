## 要求

台帳で todo と archive/todo のノートを1つの表に並べると、左のノートの欄に毎行フォルダが出る。フォルダの出し方 `display.note_path`(`"common"`・`"name"`・`"full"`)を設定とビューごとに選べるようにする(会話 2026-10-15。決定 [2026-10-15-note-path](../_decisions/2026-10-15-note-path.md))。終わりは SR-21・SR-29・SR-46 の例が試験で通ること。

## 不明点と仮定

- 仮定: ビューの設定の「表示」の区画の項目の名前は「ノートのパス」(英語は "Note path")。値は `common`・`name`・`full` をそのまま出す。
- 仮定: `"name"` で同じ名前の行が並んでも見分けの印は付けない(決定の却下した案)。

## 設計

- 変える場所: `src/display.rs` に `NotePath`(Common・Name・Full。`TabsMode` と同じ形の文字列の値と順の切り替え)と、`Display`・`DisplayOver` の `note_path`、表示の区画の項目 `Item::NotePath`。`src/profile.rs` の `[display]` の読み取り、`src/views.rs` のビューの上書きの確かめ、`src/schema.rs` の項目の説明(`--print-config` と docs の照合 CLI-12)。`src/ui/view.rs` のノートの欄で、共通のフォルダを除く処理を値で分ける。`locales/{en,ja}.toml` の項目の名前。docs/config.md・docs/config.ja.md。
- 変えない場所: 検索(NV-1)・メッセージ・詳しく見る画面のノートの名前(根からのパスのまま)。
- 対応: SR-29 → ui/view.rs、SR-46 → display.rs・profile.rs・views.rs・ui の表示の区画、SR-21 → schema.rs と docs。
- 検証: `cargo test`、`python3 .decidespec/scripts/check.py .`。

## 実装の気づき

- 値 off は決定 2026-10-15-note-path-off で足した。台帳で off にしたら名前まで消えたと人に言われ、名前を正規表現で抜き出す・削る note_name を足した(決定 2026-10-15-note-name)。タスク 4 は試験を実装のあとに独立の試験役が書いた(先に置く順ではない)。
- 「表示」の項目は設定の帯(Chips)の前に置く(最後の項目が設定の帯であることを確かめる試験があるため)。表示の区画の数は 6/12 になり、ゴールデン nv_18・nv_18_values を書き直した。
- `[display]` の項目の数を11と決め打ちした2つの試験は、決定 2026-10-15-note-path-locks で12に直して錠を掛け直した。
- レビューの残り(要件違反ではない): off と WBS を一緒に使うと番号のあとに空白が残る(file.name の列のときと同じ)。説明書の appearance.md の [display] の例に note_path は無い。
