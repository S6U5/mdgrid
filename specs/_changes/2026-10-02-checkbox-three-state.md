## 要求

依頼の要約(会話 2026-10-02): 真偽の列で、最初から値が入っていないと空か true しか取れない。値が入っていても入っていなくても、3つの状態を取れるようにしたい。

終わりの条件: チェックボックスの列のセルで切り替えの操作(Enter・Space など今の操作)を繰り返すと、空 → true → false → 空 と回る。一括の切り替えでも同じ。関係する要件: CE-4・CE-9・CE-10・WB-17。

## 不明点と仮定

- 仮定: 回る順は 空 → true → false → 空。外れたら: 順を入れ替える。
- 仮定: 空は `key:`(CE-9)で書き、元にキーが無いノートで空に戻ったら、ためる変更を消す(WB-17 の元に戻すのと同じ)。元が `key:` の空なら同じく変更なし。
- 仮定: 一括の切り替え(CE-10)は、今の行の次の状態を、選んだ行の全部に入れる。
- 仮定: 打ち込みの候補のリスト(true・false)に空は足さない(打ち込みで空にできる)。
- 仮定(レビューで決めた): 一括の切り替えでは、ためた変更が無く元の値が型に合わない行(`done: yes` など。1行なら入力を開く行)は上書きせず「N行を飛ばした(型が合わない)」で飛ばす。CE-10 の飛ばす対象(読むだけ)には書かれていないので、要件にするかは人に聞く。外れたら: 今までどおり上書きする。

## 設計

src/ui/input.rs の切り替え(toggle_checkbox)を、今の行の表示の値から次の状態(空 → true → false → 空。型の合わない値はこれまでどおり切り替えずに入力を開く)を決め、空なら NewValue::Null を、ただし元の値がキーなし・空なら変更を消す(set_each に None)形にする。一括は同じ次の状態を各行に当て、空の行ごとの扱いは同じ規則。
