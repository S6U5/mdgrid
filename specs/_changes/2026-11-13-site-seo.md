## 要求

人が、サイト(GitHub Pages)が検索でまったく見つからないことを気にした(会話 2026-11-13)。調べると、検索で mdgrid が出ず、外からのリンクも少なく、公開リポの About にサイトの URL が無く、Cargo.toml に `homepage` が無く(crates.io からサイトへ飛べない)、サイトの地図(sitemap.xml)も検索の管理(Search Console)への登録も無かった。人と決めた順のうち、1(入口をつなぐ)と2(検索エンジンに知らせる)を進める。

- 1: 公開リポの About の homepage にサイトの URL を入れる(人の許可を得て、会話 2026-11-13 に `gh repo edit` で済。リポのファイルは変えない)。Cargo.toml に `homepage`(サイト)と `documentation`(説明書)を足す。crates.io に出るのは次の版を出したとき。
- 2: サイトを作るときに sitemap.xml を作る。検索の管理の持ち主の確認のタグ(`google-site-verification`)を、公開リポの Actions の変数から入口のページに埋められるようにする(変数が無ければ何も足さない)。登録そのものは人が自分のアカウントでする。

終わりの条件: 手元で作った site/ に、公開するページだけを並べた sitemap.xml があり、どの URL もサイトの中にある。変数を渡したときだけ入口に確認のタグが付く。Cargo.toml に homepage と documentation がある。

## 設計

- `scripts/pages.py`:
  - `sitemap(out)`: 作った site/ の HTML を歩いて `sitemap.xml` を書く。載せないもの: 言語を選んで移るだけの根の入口(`index.html`)と前の画面の一覧の URL(`gallery.html`。検索の取得は en/ へ移されるので、移る先の ja/・en/ を載せる)と、`noindex` のページ(mdBook の印刷の版・目次)と、mdBook の目次の部品と 404(`toc.html`・`404.html`。404 には noindex が付かない)。URL の形は hreflang に合わせる(言語の入口・カタログの `index.html` はフォルダの形、説明書は mdBook のファイル名のまま)。並びは道筋の順(作るたびに同じ)。`lastmod` は書かない(作るたびに全部変わり、正しい日付にならないため)。
  - 入口(`index.html`)の head に、環境変数 `GOOGLE_SITE_VERIFICATION` があれば `<meta name="google-site-verification">` を足す。値は英数字・`-`・`_` だけを受け、ほかの字があれば止める(タグに変な字を入れない)。前の画面の一覧の URL(同じ chooser)には足さない。
  - robots.txt は作らない(ホストの根 `s6u5.github.io/robots.txt` は別のリポのサイトで、`/mdgrid/` の下に置いても読まれない)。サイトの地図は検索の管理に直に出す。
- `.github/workflows/pages.yml`: 「Build the site」の env に `GOOGLE_SITE_VERIFICATION: ${{ vars.GOOGLE_SITE_VERIFICATION }}` を足す。値は秘密でない(ページに出る)ので secrets でなく vars。手元のリポと公開リポの中身を同じに保つため、値はリポに書かない。
- `scripts/check_site.py`: sitemap.xml が XML の urlset として読め、どの URL もサイトの URL で始まって site/ の中のページを指し(`..`・`/` で始まる道・末尾の `/` の無いフォルダは外れ)、重ならず、公開するページ(site/ の HTML から載せないものを除いた集合を、pages.py とは別に数える)とちょうど同じことを確かめる(公開の前に落とす)。
- `Cargo.toml`: `homepage = "https://s6u5.github.io/mdgrid/"`、`documentation = "https://s6u5.github.io/mdgrid/manual/en/"`(docs.rs の中の API は道具を使う人の役に立たないため、説明書へ)。
- 却下: 入口の題(`mdgrid` だけ)や説明書の description・og タグの直しは、人と決めた順の4(ページを整える)なのでこの変更に入れない。
- 関わる束: `cargo test --test test_pages --test test_pages_images --test test_pages_check` と、手元で `python3 scripts/pages.py` → `python3 scripts/check_site.py`
- 全体: `cargo test`・`cargo clippy --all-targets -- -D warnings`・`cargo fmt --check`
