## 要求

人が、ブックマークを1件1ノートで持つ台帳(置き場を「根 > フォルダ > …」の列に書く)を、関係マップのように見やすく見る画面を mdgrid に足したいと言い、提案 `specs/_proposals/2026-10-22-tree-view.md` を承認した(会話 2026-10-22。決定 `specs/_decisions/2026-10-22-tree-view.md`)。版1 の TR-1〜TR-7 を作る。TR-8・TR-9(行の移動と並べ替え)は次の段で、作らない。

受け入れの条件(作った値):

- 印に `tree = { path = "folder", order = "order" }` を書いた表で「▦ 表 ▾」を押す → 窓に「木」がある。選ぶと左にフォルダの木(`bar > 開発`・`bar > 開発 > Web`・`other`・空 → bar(3)・開発(3)・Web(1)・other(1)・(なし)(1))、右に選んだフォルダの直下の行が order の順に出る。行で Enter → 表の画面のその行。
- `separator = ""` → 警告1行で、メニューに「木」が出ない(失敗時)。

関係する要件: TR-1〜TR-7(新)、REL-8(画面の型のメニュー)・REL-9・REL-12(段組みとマウスの手本)、SC-9、WS-7・WS-9・WS-10(印の `[[table]]`)、CLI-3(警告の形)、SR-24(操作の一覧)・SR-14(パレット)。

## 不明点と仮定

- 仮定: 木へ切り替えるキーは表のモードの `T`(既定で空いている大文字。関係マップの `R` と同じく窓を開かずに切り替える。木の中の `T` で表に戻る)。外れたら: 別のキーにする(設定の `[keys.table]` でも割り当て直せる)。
- 仮定: 木の画面のフォルダの並び・行の並びは、開いたときの表の行(今のビューを通った行。簡易の絞り込みも含む)で作り、外で変わったら作り直す。外れたら: 開いたときのままにする。
- 仮定: 「操作の一覧」は、木の中の `x` で開く小さな窓(右の欄の行の操作: URL を開く・表でこの行を見る)と、表の画面の操作の一覧(SR-24)の行の節の両方に「URL を開く」を出す。パレットは `:open_url`。外れたら: どちらかに絞る。
- 仮定: 行の URL は、今のビューの列の順に見て最初の `http://`・`https://` で始まる値(空白や制御文字を含むものは除く)。ビューに無い列は、そのあとに表の列の順で見る。
- 仮定: 「(なし)」のフォルダは根の並びの最後に置く(仕様の例の並び)。名前の順は大文字と小文字を区別しない比べ方で、同じなら元の字の順。

## 設計

変える場所:

- `src/folder_tree.rs`(新。ライブラリ): 木の設定 `TreeSpec`、値を区切りで切る `split`、フォルダの木を組む `build`(途中の階層を作り、数を下まで足し、名前の順に並べ、空の階層は「(なし)」)、開いているフォルダだけを前順に並べる `shown`、行の並び(order の数の小さい順、数でない・空は後ろ、同じはノートの名前の順)、`web_url`(http・https だけを通す)。画面に依存しない。既存の `src/tree.rs`(NV-27 の親子の並べ方)とは別のもの。
- `src/workspace.rs`: 印の `[[table]]` の `tree` を読む `marker_tree(開いたもの)`(区切りの省略は ` > `。表でない・path が無い・区切りが空なら CLI-3 の形で警告して None)。`read_tables` は印のときだけ `tree` を知らない項目にしない。`WsTable` と `Scope` には足さない(錠のある試験がその形を直に作るため)。
- `src/ui/folder_tree.rs`(新): 木の画面(状態 `FolderTree`・キーの動作・クリック・描画・木の中の操作の窓)。関係マップ `src/ui/relmap.rs` と同じ形(App に `Option<FolderTree>`、`render` で全画面、ヘッダーと下の帯は bands の物を使う)。枠と題の窓 `panel` と横に並べる `side_by_side` は relmap.rs の物を `pub(crate)` にして使う。
- `src/ui/keymap.rs`: モード `Mode::Tree`(設定の名前 `tree`)、動作 `TreeView`(`tree_view`。表で `T`)と `OpenUrl`(`open_url`。木で `o`、表ではパレットと操作の一覧から)、木のモードのキー。
- `src/ui/screen_menu.rs`: 画面の型に「木」(表に木の設定があり、階層の列が表にあるときだけ)。`src/ui/bands.rs`: 木の画面のヘッダーのボタン「▤ 木 ▾」と下の帯。`src/ui/app.rs`: 振り分け・クリック・ホイール・設定の読み込み(起動のときに `marker_tree`、読み終えたら列の有無を確かめて警告)。
- `src/ui/external.rs`: URL を開く口 `Opener`(本物は macOS `open`・Windows `rundll32 url.dll,FileProtocolHandler`・ほか `xdg-open` に引数で渡す。シェルを通さない)。試験のビルドでは開かずに覚えるだけのもの。
- `src/ui/menu.rs`・`src/ui/help.rs`: 操作の一覧の行の節とパレットに「URL を開く」。パレットを木から開いたら、閉じると木に戻る。
- 文言 `locales/*.toml`、文書 `docs/keys(.ja).md`・`docs/config(.ja).md`・`docs/design.md`、見本 `examples/bookmarks/`。

変えない場所: 表の画面の組み立て(grid.rs)・ビューの読み方(base.rs)・書き戻し(TR-8・TR-9 は次の段)。

選んだ案と却下した案:

- 選んだ: 木の設定は印の文を開いた表のパスで引き直す(`inline_base` と同じ形)。却下: `WsTable` に `tree` を足す — 錠のある試験が `WsTable { name, path, view, profile }` を直に作っていて、足すと組み立てが落ちる。
- 選んだ: 木の画面を新しいモードにする(関係マップと同じ)。却下: 関係マップの画面に木を足す — 提案で却下済み(目的が違う)。
- 選んだ: 木の中の操作の窓は、木のモードのまま `FolderTree` の中の状態で持つ(新しいモードを増やさない)。却下: 表の操作の一覧(SR-24)をそのまま重ねる — 窓の置き場所が表のセルに結びついている。

- テスト役・レビュー役のサブエージェントは使っていない(この作業は親のエージェントから渡された1つの作業役で行い、試験も実装と同じ文脈で書いた)。独立したテスト役・レビューではない。

- 実の台帳で、`[table.base]` だけの表(path なし。`open` で選ぶ)で `T` が「木の設定が無い」になった(人の指摘 2026-10-23)。根を `.` で開くと、開く表のパスが `./名前.base`(ファイルの無い相対のパス)になり、`marker_tree` の `same_path` が実体のパスに直せずに食い違っていた。ファイルの無い `.base` はフォルダの側を実体のパスに直して比べる。
