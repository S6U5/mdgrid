## 要求

会話 2026-10-05(リポの外の会話)で、人の依頼で画面の色の見本を7枚作った(今の見た目・Nord・Solarized Light・Dracula・Gruvbox・Pink Monster・Dozy Pink。本物の画面を写し取り、色だけを塗り替えた試作)。会話 2026-10-06 で、人がこれを説明書に載せたいと言い、AI が「見本を残す → テーマを本物の機能にする → 説明書にテーマを選ぶ節を足す」の順を推し、人がその順で最後まで実装するよう頼んだ。

- 見本の7枚をリポに残す(docs/images/theme-mockups/)。
- 7つのテーマを設定で選べるようにする。
- 説明書の場面の定義(docs/manual-scenarios.toml)にテーマごとの場面を足して撮り、説明書(manual/、git の外)に「テーマを選ぶ」の節を足す。設定の文書(docs/config.md・config.ja.md)に項目を足す。

終わりの条件: 設定に `theme = "nord"` → 画面の地が Nord の地の色で、選んでいるセルが Nord の選択の色。設定なし → 今の見た目と1桁も変わらない(既存の試験と golden が通る)。`NO_COLOR=1` → テーマを書いても色の指定が無い。

関係する要件: SR-10(色なし)・SR-15(256 色に落とす、色だけで意味を伝えない)・SR-20(一行おきの色)・CLI-3(設定、知らない値は警告)・CLI-12(設定の全項目の文書)。

## 不明点と仮定

人は「推しの順で最後まで」と委ねたので、聞かずに次を仮定にした(人が決める4つとして挙げた点)。

- 仮定: 入れるテーマは見本の7つ全部(人が見本として頼んだもの全部)。外れたら: 表から消すだけ。
- 仮定: 設定の名前は最上位の `theme`、値は `default`・`nord`・`solarized-light`・`dracula`・`gruvbox`・`pink-monster`・`dozy-pink`。既定は `default`(今の見た目。既定を変えると今の利用者の画面が変わるため)。外れたら: 既定の1行を変える。
- 仮定: 端末のダーク / ライトの自動判定は入れない(端末への問い合わせ(OSC 11)は端末ごとに答えが違い、試験もしにくい。範囲外の次の段に残す)。外れたら: 別の変更で足す。
- 仮定: 実行中の切り替え(パレットなど)は入れない。設定だけで選ぶ。
- 仮定: 見本の役割のうち「窓の枠」は塗り分けない(窓の枠は行の文字と1つの文字列で作っていて、枠だけに色を付けるには重ねる窓の作りを全部変える必要がある。窓は地・選択・強調の色で塗る)。外れたら: 窓の枠の部品を分ける別の変更。
- 仮定: 見本の作り方の道具(PIL の試作)はリポに入れない。色の値はコードの表に写す。

## 設計

- 新しい src/theme.rs(ライブラリ。`mdgrid::theme`): `pub enum Theme { Default, Nord, SolarizedLight, Dracula, Gruvbox, PinkMonster, DozyPink }`、`Theme::ALL`(この順の7つ)、`Theme::parse(&str) -> Option<Theme>`(設定の名前 `default`・`nord`・`solarized-light`・`dracula`・`gruvbox`・`pink-monster`・`dozy-pink`)、`Theme::name()`、`Theme::palette() -> Option<Palette>`(`Default` は None)。`pub struct Palette` は役割ごとの `[u8; 3]`: `bg`・`fg`・`header`・`sel_bg`・`sel_fg`・`band_bg`・`band_fg`・`colhead`・`strong`・`zebra_bg`・`zebra_fg`・`mark`。値は見本(docs/images/theme-mockups/ を作った試作の表)をそのまま写す(Nord: bg 2e3440・fg d8dee9・header 88c0d0・sel 5e81ac / eceff4・band 3b4252 / a3be8c・colhead 81a1c1・strong eceff4・zebra 353c4a / d8dee9・mark ebcb8b。ほかは下の色の表。窓の枠と accent は使わない)。`pub fn to_indexed([u8;3]) -> u8`(xterm の 256 色の表で最も近い番号。16〜255 の色の立方体と灰色から選ぶ)。

- src/ui/app.rs: `App.theme: Theme`、`configure` で設定から入れる。

- 新しい src/ui/theme.rs: `paint(buf, full, app)`。src/ui/mod.rs の `draw` の最後(描き終えたバッファ)で、`app.color` が `None` でなく `app.theme.palette()` があるときだけ呼ぶ。画面の全部のセル(空けておく最下行と右端も地の色)を役割で塗り替える: 反転のセルは、下の帯の行(描く範囲の下から2行目)なら帯、ほかは選択の色にして反転を外す(反転で自分の色を持つセルはそのまま)。反転でないセルは、前景を持たなければ 1行目 → header、太字+下線 → colhead、太字 → strong、左端の `>` → mark、ほか → fg。背景を持たなければ bg。一行おきの色(display.rs の 237 / (58,58,58))の背景は zebra_bg・zebra_fg に替える。ためた値・一致の強調・差分の色など、セルが自分で持つ色はそのまま。`ColorMode::Indexed` では `to_indexed` で 256 色の番号にする。
