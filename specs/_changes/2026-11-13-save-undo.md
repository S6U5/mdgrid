## 要求

人から、機能の改善と追加の依頼があり(会話 2026-11-13)、仕様で「次の段」に残っている候補を選択肢で見せたところ、保存後の取り消し・カンバンの画面・正規表現の置き換え・テーマの自動判定の4つが選ばれた。この記録はそのうちの「保存後の取り消し」(write-back の範囲外の「次の段: 保存したあとの取り消し(ファイルを元に戻す)」)を扱う。ほかは別の記録にする(テーマの自動判定は SR-39 でもう入っていた)。

- 何を: 保存(WB-9)で書いたあとに、書いたファイルを保存の前の中身に戻せるようにする。
- なぜ: ためる変更は保存の前なら `u` で戻せる(WB-10)が、保存して書いたものは戻す手が無い。差分を見て確定しても、書いたあとで間違いに気づくことがある。
- 終わりの条件(例。値は作ったもの):
  - `status: todo` のノートを done に直して保存する → ファイルは `status: done`。パレットの「保存を取り消す」→ 今の中身から保存の前の中身への差分(`-status: done`・`+status: todo`)が出る。確定 → ファイルは保存の前と1バイトも違わず、status のセルは done のまま「未保存 1」(ためる変更に戻る)。
  - 保存のあとに外でそのノートの別のキーを直してから「保存を取り消す」→ そのファイルは書かれず、外で変わったと知らせる(外の変更を消さない)。
  - まだ一度も保存していないときに「保存を取り消す」→ 何も書かず、取り消す保存が無いと知らせる。
- 関係する要件: WB-9(保存の前の差分)・WB-10(取り消し)・WB-4・WB-12(基準)・WB-8(書き込みの手順)・WB-2(書いてよい範囲)・WB-14・WB-16・WB-15(読むだけ)。

## 不明点と仮定

- 仮定: 戻すのは最後の1回の保存だけ(何回も前へはさかのぼらない)。理由: 覚える中身(保存の前のバイト)を小さく保ち、どの保存を戻すのかを迷わせないため。外れたら: 保存の積みを持つ形に広げる(提案を足す)。
- 仮定: 覚えるのは起動している間だけ(ファイルには残さない)。理由: ノートのフォルダに mdgrid の控えを作らない(WB-2)ため。外れたら: 設定の置き場に控えを持つ案を提案にする。
- 仮定: 戻したファイルの、その保存で書いた変更は、ためる変更として戻す(保存の直前の状態に戻る。`u` でさらに消せる)。理由: 1つだけ間違えた保存を、直してもう一度保存できるようにするため。外れたら: ためる変更に戻さない形にする。
- 仮定: 既定のキーは割り当てず、パレットから呼ぶ。理由: ファイルを書く操作を1キーの打ち間違いで始めないため(確認の画面は出す)。外れたら: キーの表に足す。

## 設計

- 変える場所:
  - `src/writeback.rs`: `save_with` の「基準の検査 → 一時ファイル → 読み直し → fsync → 直前の再検査 → 名前の変更」を、書くバイトを作る関数を受ける内側の関数にまとめ、`pub fn restore(path, base, bytes)` を足す(今のファイルが `base` と同じときだけ、`bytes` で置き換える。WB-8 と同じ手順、ハードリンク・権限の断りも同じ)。`save_with` の振る舞いは変えない。
  - `src/source.rs`: `Source::restore_unit(&mut self, unit, base, bytes) -> Result<Stamp, SaveError>`(既定は Err)。`Box<S>` の委譲も足す。
  - `src/source/markdown.rs`: `restore_unit` は `writeback::restore` のあと `vault.replace` と `rebuild`。`src/source/csv.rs`: 既にある `write(base, f)` に `bytes` を返す関数を渡す。
  - `src/changes.rs`: `save_rows` で、単位を書く直前に `preview_unit` の「今のディスクのバイト」を取り、書けたあと基準のハッシュと同じときだけ、(単位, 保存の前のバイト, 書いたあとの基準, 書いたセル)を `last_save` に覚える。1回の `save_rows` の呼び出しで1つでも書けたら、前の覚えを置き換える。`pub fn saved_units()`(戻せる単位と保存の前のバイト)、`pub fn undo_save(src) -> Vec<(RowId, Outcome)>`(単位ごとに `restore_unit`。書けた単位は、書いたセルをためる変更として1手で戻し、覚えから消す。`Changed` と失敗は覚えに残す)。保存のあとにその行へ新しくためた値があれば、その値を残し(同じ列は新しい方)、基準を戻したあとの基準に進める。
  - `src/ui/review.rs`: `Review` に `undo: bool` を足す。`open_undo_review()` が、覚えた単位ごとに「今のディスク → 保存の前」の差分を作り(今のディスクのハッシュが書いたあとの基準と違えば、差分の代わりに外で変わった理由)、確認の画面を出す。`SaveAll` は `undo` なら `changes.undo_save`、`Overwrite`・`DiscardRow` は `undo` では効かせない。見出しは別の文言。外の変化で画面を作り直す道(`reopen_review_keeping_overlay`)は、`undo` なら取り消しの差分を作り直す。
  - `src/ui/keymap.rs`: `Action::UndoSave`(名前 `undo_save`)を `COMMANDS`(書くコマンド。読むだけでは出さない)に足す。既定のキーなし。`src/ui/app.rs` の `apply` でつなぐ。
  - `locales/en.toml`・`locales/ja.toml`: コマンドの名前・確認の見出し・結果・取り消す保存が無い・外で変わった の文言。
  - `docs/keys.md`・`docs/keys.ja.md`(キーの無い動作の一覧)、`docs/safety.md`・`docs/safety.ja.md`(保存の取り消しの節)、`docs/manual/<言語>/features.md`(1項と画面1枚)、`docs/design.md`(覚える形)。
  - 名前と文言(試験が探す語): 動作の名前は `undo_save`。パレットのコマンドの表示名は、日本語「保存を取り消す」・英語「Undo the last save」。取り消す保存が無いときのメッセージは、日本語「取り消す保存は無い」・英語「there is no save to undo」。確認の画面の見出しは、日本語「保存の取り消し: N ファイル」・英語「Undo the last save: N file(s)」で始める。外で変わったファイルの理由は、日本語「保存のあとに外で変わったので戻さない」・英語「changed outside since the save, so it is not restored」。確定のキーは保存の確認と同じ(`save_all`。既定のキーは `docs/keys.md` の保存の確認の節)、やめるのは `back`(Esc・`q`)。
  - 核の口(試験が呼ぶ形): `mdgrid::writeback::restore(path: &Path, base: &Baseline, bytes: &[u8]) -> Result<Baseline, SaveError>`、`Source::restore_unit(&mut self, unit: &RowId, base: &Stamp, bytes: &[u8]) -> Result<Stamp, SaveError>`、`Changes::saved_units(&self) -> Vec<(RowId, Stamp, Vec<u8>)>`(単位・書いたあとの基準・保存の前のバイト)、`Changes::undo_save(&mut self, src: &mut dyn Source) -> Vec<(RowId, Outcome)>`。
- 変えない場所: 値を書く `writeback::apply`、保存の基準の決まり(WB-4・WB-12)、`u` の取り消し(WB-10)の意味。
- 選んだ案: 保存の前のバイトをメモリに覚え、同じ安全な書き込みの手順でバイトごと戻す。保存の前と1バイトも違わない中身に戻ることを、値の逆の書き換えでなくバイトの控えで保証する(逆の編集を `apply` で作ると、クオートや空白が保存の前と同じになる保証が無い)。
- 却下した案:
  - 逆の編集(前の値)をためて保存し直す: 書式が保存の前と同じにならない場合があり(キーを足した行を消す操作は CE-29 の別の道)、「元に戻す」と言えない。
  - 控えのファイル(`.bak`)をノートの隣に作る: ノートのフォルダに道具のファイルを増やし、WB-2(新しいファイルを作るのは新しいノートと .base の書き出しだけ)に反する。
  - `u` を保存の直後に押したら戻す: ファイルを書く操作が、ためる変更の取り消しと同じキーで始まり、違いが分かりにくい。
- 要件の対応: WB-21 → 書き込みは `writeback::restore`・`Source::restore_unit`、覚えと戻しは `Changes`(`last_save`・`undo_save`)、確認の画面とコマンドは `ui/review.rs`・`ui/keymap.rs`。
