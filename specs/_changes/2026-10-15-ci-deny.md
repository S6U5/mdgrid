## 要求

会話 2026-10-15(〔伏せ字: 手元の名前〕 の運用のプロジェクト)で、人がサプライチェーン攻撃への備えとして、mdgrid と cellops-creator の ci.sh に `cargo deny check` を足すと決めた。cargo audit は入れない(deny が同じ勧告を見る)。最初は licenses と依存の出どころ(sources)をエラーに、勧告(advisories)を警告にする。deny.toml を置く。cargo-deny が無ければ `cargo install cargo-deny --locked` で入れる。

終わりの条件: `./ci.sh` が cargo-deny を必ず回し、licenses・bans・sources の違反で落ち、advisories の当たりでは警告を出して続く。関係する要件: 該当なし。

## 不明点と仮定

- 仮定: bans(重複は warn、版のワイルドカードは deny)も licenses・sources と同じくエラーの側に置く。外れたら: `cargo deny check licenses sources` だけを落とす側にする。
- 仮定: deny.toml の `[advisories]` は変えず、警告にするのは ci.sh の側(advisories だけ別に回して失敗を警告の1行にする)。cargo-deny 0.20 の version 2 では脆弱性の勧告の重さを設定で下げられないため。外れたら: 当たりを `ignore` に理由付きで書く。
