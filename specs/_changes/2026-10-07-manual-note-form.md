# 説明書の「新しいノートを作る」をフォーム・雛形・エディタに合わせ、その場面だけを撮り直す(manual-note-form)

## フェーズ

状態は 未 / 進行中 / 済 / 対象外: 理由。要求・実装・照合は対象外にしない。前のフェーズが済か対象外になるまで、次を始めない。

| フェーズ | 状態 | 成果物 |
|---|---|---|
| 要求 | 済 | この記録の「要求」 |
| 不明点 | 対象外: tiny(文書だけ) | なし |
| 仕様化 | 対象外: 要件を変えない | なし |
| 設計 | 対象外: tiny | なし |
| タスク | 対象外: tiny | なし |
| 実装 | 済 | コミット |
| 照合 | 済 | この記録の「照合」 |

## 要求

人の依頼(会話 2026-10-07): 足した機能を画面の写しつきで説明書に載せる。画像は撮りすぎない。新しいノートの4つの場面(new-note・new-note-done・new-note-base・new-note-place)だけを撮り直し、手順の文をフォーム・Ctrl+S・Ctrl+E・mode・雛形に合わせる。

## 照合

要件に触らない(文書)。4つの場面だけを `--only` で英語と日本語に撮り直した(画像8枚)。撮影の文字(.txt)で、窓に名前と列の欄が並び、絞り込みの値に「(絞り込みから)」が付くことを確かめた。
