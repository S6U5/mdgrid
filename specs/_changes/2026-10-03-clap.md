## 不明点と仮定

- 人の選択: clap を入れる(2026-10-03 の束)。
- 仮定: `--help` の文言は今の日本語の USAGE を保つ(clap の自動の英語の help にしない。O-3 の英語化で切り替える)。clap の誤りの文言(英語の複数行)は、CLI-4 の「理由を1行」に合わせて1行の日本語に直す。外れたら: clap の文言をそのまま使う。
- 仮定: 錠のある試験 src/test_main.rs が `parse_args`・`parse_args_in`・`take_options`・`Options`(4つの欄)・`Command`・`USAGE`・`load_config` を直接使うので、これらの名前と形は保ち、中身を clap で作る。Options に欄を足せない(試験が4つの欄の構造体の式で比べる)ので、F-5 などの新しい旗は別の構造体か Command の側に置く。

## 実装の気づき

- 定義は src/main.rs の `Cli`(clap derive)1つ。`take_options` は `Cli` で全部を読み、4つの欄を取って、残り(命令の旗とパス。`-` で始まるパスの前に `--`)を args に書き戻す。F-5 の `--print`・`--pick` と sessions の `-s` は `Cli` に欄を足し、`Command` の腕か別の構造体で返す(`Options` は錠の試験が4つの欄で比べるので足せない)。conflicts_with も `Cli` に書ける。
- fish の補完は `-l view` の形で `--view` の綴りが出ない。試験の側で `-l <名前>` も受けるように直し(47544a6)、補完は clap_complete の出力だけを出す。
- 旗が重なると help > version > print-config > completions > man の順。前と違い、`--help --nope` も知らないオプションの誤り(終了コード 2)になる(前は `--help` が先なら 0)。
- clap_derive が syn 3 を入れ、syn 2 と二重になる(cargo deny の bans は warn で通る)。
