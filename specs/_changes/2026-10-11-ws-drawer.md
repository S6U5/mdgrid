## 要求

人が、今のワークスペースの中の表を、左に開くサイドバーのクリックで切り替えたいと頼んだ。左に自分の一覧を持つ端末の道具の中では帯が2本並ぶので、普段は出さず左から重ねて出す引き出しにし、表の画面からも使えるようにする(会話 2026-10-11)。終わりの条件: WS-8 のとおり、ボタン・`w`・パレットで開き、選んだ表へ移り、閉じる。SR-42 の「ワークスペース」のボタンは引き出しを開け閉めする。関係する要件: WS-8・SR-42。

## 不明点と仮定

- 仮定: 引き出しで今の表を選んだら、閉じるだけにする。ただし、その行がビューを持っていて今のビューと違えば、そのビューを選ぶ(関係マップで今の表を選んだとき(REL-7)と同じく、開き直さない)。外れたら: 開き直す。
- 仮定: 今の範囲の表へ移るときは、範囲が workspaces.toml のワークスペース(Source::App)ならその名前で開き直し、ほかの範囲(`-w`・印・検知・登録した表)は今の起動の範囲の選び方のまま開き直す(印や検知の範囲は workspaces.toml に名前が無く、`-w` に渡すと開けないため)。ほかのワークスペースの表へ移るときは、そのワークスペースの名前で開き直す(WS-2 の「ワークスペースを開く」と同じ)。
- 仮定: ほかのワークスペースの見出しには、workspaces.toml のワークスペースのうち、今の範囲と同じ名前のもの以外を並べる。フォルダの印のワークスペースはアプリの側に一覧が無いので並べない。
- 仮定: 並べる表もほかのワークスペースも無いときは、引き出しを開かず理由を出す。端末が狭く低くて窓を出せないときも理由を出す(並べ替えの窓(NV-24)と同じ)。

## 設計

変える場所:

- 新しい `src/ui/drawer.rs`: 引き出しの状態 `Drawer`(選び・開いた見出し)、行の組み立て(今の範囲の表・ほかのワークスペースの見出しとその表)、置き場所(左の端 x=0、ヘッダーの下の行から下の帯の上まで。幅は中身に合わせて 24〜40 桁、端末の幅を超えない)、モードの動作・クリック・重ねて描く `overlay`。窓の部品は `popup.rs`(枠・`blit`・`step_sel`)を使う。
- `src/ui/keymap.rs`: `Mode::Drawer`(設定の名前 `drawer`)と `Action::WsDrawer`(`workspace_drawer`)。表のモードに `w`、パレットのコマンド。引き出しの中は Enter(選ぶ・見出しを開け閉め)・Esc と `q` と `w`(閉じる)・j/k/↑↓・g g/G・l/→(見出しを開く)・h/←(見出しを畳む)。抜ける動作は Close(EXITS)。
- `src/ui/app.rs`: 振り分け(`apply`・クリック・ホイール)に Drawer を足す。SR-42 の `header_button` の Workspace は引き出しの開け閉め。
- `src/ui/view.rs`: 重ねる窓の並びに drawer の overlay。`src/ui/bands.rs`: 下の帯の位置の表示のモードに Drawer。
- 移る: `switch_to` と `begin_quit`(CLI-19 と同じ保存の確かめ)、範囲は仮定のとおり `switch_workspace` を付けるか付けないか。
- `src/i18n.rs`: モード名・節・キーの説明・コマンド・題・理由の文言(日英)。`docs/keys.md`・`docs/keys.ja.md`・`docs/config*.md`: 新しいモードとキー(SR-22 の試験が照らす)。

変えない場所: WS-2 のパレットの「ワークスペースを開く」(2段階の窓)は残す。範囲の決め方(核の mdgrid::workspace)は変えない。

選んだ案: 並べ替えの窓と同じ、モードを持つ重ねる窓。キーの割り当て直し・ヘルプ・下の帯の案内がそのまま効く。却下した案: パレットの Ask(一覧の窓)を使い回す → 見出しの開け閉めと今の表の印を持てず、左に重ねる置き方もできない。却下した案: いつも出す帯として表の幅を詰める → 提案で却下した(二重の帯)。

要件ごとの対応: WS-8 → drawer.rs(行・開く・移る・閉じる・描く)と keymap の `w`・パレット。SR-42 → app.rs の header_button と、引き出しを開いているときのボタンのクリックで閉じる。

検証のコマンド: `cargo test drawer`、`cargo test test_sr_42`、`cargo test test_sr_22`、全体は `cargo test`、仕様は `python3 .decidespec/scripts/check.py .`。

## 実装の気づき

- ui は bin の側にあるので、試験は `cargo test --bin mdgrid test_ws_8` で回す(`--lib` では0件)。
- レビューの指摘で直した: 確かめで戻ったときに移る先の範囲の旗(`switch_workspace`・`switch_leave_workspace`)も捨てる(review.rs と app.rs の Quit)。今の範囲の行は印でなく実体のパスで今の表かを見る。今の範囲と同じ名前の見出しは、印・検知の範囲でも出さない。窓を出せなくなったら動作の前に閉じる。表で割り当て直した開くキーでも閉じる。
- 残した(範囲の外): `--pick` の起動で引き出しから別の表を選ぶと、開き直さずに何も出さず終わる(「ワークスペースを開く」・CLI-19 と同じ前からの作り)。
- 前からある別の落ち: tests/test_cliff.rs の test_cliff_history_prefixes_all_covered が、道具の更新のコミット(件名が `decidespec:`)で落ちる。この変更の前から落ちる。
