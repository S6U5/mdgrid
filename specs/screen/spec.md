# 画面と操作(screen)

表を見て直すための画面。表の TUI への不満の中心は「機能が足りない」より「あるのに見つからない」と「日本語や端末の違いで崩れる」なので、見つけやすさ(下の帯・ヘルプ・パレット)と崩れない描画を、機能より先に決める。cellops(自作のタスクの TUI)で作り直しを重ねて固まった形のうち、タスクに依らない部分も採る。表の中身は [base-view](../base-view/spec.md)、移動と検索は [navigation](../navigation/spec.md)、セルの値・文字の幅・色の見せ方は [cell-view](../cell-view/spec.md) にある。

強さの読み方: 「しなければならない」= 例外なし、「するべき」= 理由があれば外してよい、「してよい」= 任意。
