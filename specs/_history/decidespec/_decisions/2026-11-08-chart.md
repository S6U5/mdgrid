# 画面の型「グラフ」を足し、今のビューの行を棒・積み上げ棒・折れ線・散布図・ヒートマップで見る(chart)

## きっかけ

人は会話 2026-11-06 で、カンバンのあとに棒グラフ・折れ線グラフなど色々なグラフの画面を足すよう頼んだ。会話 2026-11-08 の選択肢の問いで、最初の版の種類に棒・折れ線・積み上げ棒・散布図を選び、ほかにもあれば足すよう添えた。グラフにする列の選び方は、画面の中のキーで切り替えてもよいが、どのグラフを使い、どの値を当てるかを設定できてもよい、と答えた。新しいケイパビリティ `chart`(CH)を置き、木・ガント・カンバンと同じ仕組み(印の `[[table]]` の型の名前のキー → 画面の型のメニュー → 画面のモジュール。GA-7)で足す。ほかの種類としてヒートマップ(2つの列の組ごとの値)を足すこと、数の列で分けた棒を区間ごとの件数(ヒストグラム)にすること、積み上げ棒の割合への切り替えを円グラフの代わりにすること、キーの割り当て、推定の順、`Enter` で表をその値に絞ることは、AI が足した細部。

グラフは今のビューの行を数えて見せる表の見え方の一つで、項目から `Enter` で表の絞り込みに戻れるので、表を見て直す芯(SC-1)の中に収まる。最初の版の仕様(v1-full-spec。AI 自己採択)が navigation の範囲外に「グラフは採らない」と置いていたが、人の依頼で向きが変わったので、その行を直す。

## 却下した案

| 案 | 理由 |
|---|---|
| 何もしない | 状態ごとの件数や月ごとの数は、頻度表(NV-9)で1つの列の件数を見るか、表を数えるしかない。人はグラフの画面を足すよう頼んだ。 |
| 種類ごとに画面の型を分ける(棒・折れ線・散布図をメニューに別々に並べる) | メニューとキーが種類の数だけ増え、同じ列の選び方・数え方を型ごとに持つことになる。1つの型の中で種類を切り替えれば、同じ行の数え方を保ったまま見比べられる。 |
| 印に書いたグラフだけを出す(画面での切り替えなし) | 列や種類を試すたびに印を書き直すことになる。人は、キーで切り替えるのでもよく、設定もできるとよいと答えた。 |
| 印に書いたグラフを1画面に並べる(ダッシュボード) | 人は選ばなかった。1枚ずつ `[` `]` で切り替える形を先に作り、並べる画面は次の段にする。 |
| 円グラフ | 端末の文字の格子では円の形と角度が崩れ、割合が読めない。積み上げ棒の割合(`%`)で同じことを見せる。 |
| 切り替えたグラフを印に書き戻す | 印(設定のファイル)を画面から書き換える道が増える。最初の版は印を読むだけにし、書き戻しは次の段にする。 |
| `.base` の chart のビューを開く | SC-8 は `.base` の table 以外のビューを開かないと決めている。グラフの設定は印の `[[table]]` の `chart`(GA-7 の形)にそろえる。 |
| グラフのキーを `G` にする | `G` は表の末尾の行へ動くキー。`P`(plot)は表のモードで空いている。 |
