## 要求

人は、カンバンの完了の報告のあと、棒グラフ・折れ線グラフなど色々なグラフの画面も足すよう頼んだ(会話 2026-11-06)。画面の型を増やす流れ(ガント → カンバン)の続きで、台帳の値の分かれ方(状態ごとの件数、担当ごとの見積もりの合計)と、時間の流れ(月ごとに作った件数、終えた件数の累積)を、表を数えずに一目で見るため。

終わりの条件(例。値は作ったもの):

- status の列が todo 2件・doing 1件・done 3件の表でグラフを開く → 値ごとの件数の棒が3本(長さの比 2:1:3)で、棒に値と件数が出る。
- due の日付の列で 2026-10 に3件・2026-11 に1件の表で、折れ線を月の単位にする → 10月 3、11月 1 の点を結ぶ線。日付の無い行は数えず、数えなかった件数を画面に示す。
- 境界: 合計を出す数の列に、数でない値の行がある → その行は合計に入れず、外した件数を示す。ビューに行が1つも無い → 理由1行で開かない。

関係する要件: SC-8(`.base` の表でないビューは開かない)、SC-9(画面の型は別の型として足す)、REL-8・TR-1(画面の型のメニュー)、GA-7(型ごとの設定の一般の形)、NV-9(列の値の頻度表。数え方をそろえる)、SR-14(パレット)、SR-15(色なしでも見分ける)、SR-22(キーの文書)、SR-49・SR-51(見せ方とできることの一覧)。

## 不明点と仮定

- 最初の版のグラフの種類 → 棒・折れ線・積み上げ棒・散布図。ほかにもあれば足す(会話 2026-11-08 の選択肢の問い)。ほかにはヒートマップ(2つの列の組ごとの値)を足し、数の列で分けた棒を区間ごとの件数(ヒストグラム)にし、積み上げ棒の割合の切り替えを円グラフの代わりにした(AI の細部)。
- グラフにする列の選び方 → 画面の中のキーで切り替えてもよいが、どのグラフを使い、どの値を当てるかを設定できてもよい(会話 2026-11-08)。印の `chart` に1つか複数のグラフを書け、画面ではキーで種類と列を切り替えられる形にした。複数のグラフを1画面に並べる形(ダッシュボード)は次の段。
- 前のカンバンの KB-4(札を動かして値を書き換える)→ このままでよい。前のガント・木・カンバンの、行の無い表の例外 → 要件の文に書き足す。どちらもこの変更の外の仕様の決定として採択した(334c2f9。specs/_decisions/2026-11-08-kanban-move-confirmed.md・specs/_decisions/2026-11-08-empty-table-screen-columns.md)。
- 仮定: 開くキーは `P`(plot。表のモードで空いている)。外れたら: キーの表(SR-4)で割り当て直せる。
- 仮定: 読むだけの画面にする(値は表で直す)。外れたら: 次の段で、項目から表の一括の直しへつなぐ。
- 仮定: 画面で切り替えたグラフは印に書き戻さない。外れたら: 次の段で、設定の画面か印への書き出しを足す。
- 仮定: 日付の列の区切りの単位は、区切りの並ぶ向き(棒・積み上げ棒・ヒートマップは縦、折れ線は横)の長さに収まる最も細かい単位で開く(CH-3 の「幅に収まる」を、区切りの軸の長さと読む)。外れたら: 棒も横の幅で決める。

選んだ案と却下した案:
- 選んだ: 1つの画面の型の中で種類を切り替える(`Resolved` を変えて数え直す)。却下: 種類ごとに画面の型を分ける。メニューとキーが増え、数え方を型ごとに持つことになる。

- 選んだ: 印のグラフは読むだけで、画面の切り替えは印に書かない。却下: 切り替えるたびに印に書く。設定のファイルを画面から書き換える道が増え、手で書いた印のコメントや並びを崩しうる。
- 選んだ: `marker_setting` の探し方を切り出す。却下: `chart` だけ別の読み方を書く。表を探す規則(`path`・`base`・`real_path`)が2か所になる。
