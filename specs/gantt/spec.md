# ガント(時間軸の横棒の画面)

表(と木・関係マップ)に続く画面の型。今のビューの行を、始まりと終わりの日付の列から時間軸の横棒にして見せる。親子(NV-27)と WBS が効いていれば、その並び・字下げ・番号・進み具合をそのまま使い、親の棒は子の範囲になる。設定は印の `[[table]]` の `gantt = { … }` で、無ければ日付の列の名前から推定する(GA-7 の一般の形)。読むだけの画面で、日付は表で直す。扱わない: 棒のドラッグでの編集、依存の矢印、クリティカルパス、履歴(バーンダウン)。

強さの読み方: 「しなければならない」= 例外なし、「するべき」= 理由があれば外してよい、「してよい」= 任意。

## 次の段

- カンバン(状態の列の値ごとの札)・カレンダー(日付の列を月のます目に)・マトリクス(2つの列で4象限)・集計の棒グラフ(列の値ごとの件数)。どれも GA-7 の形(`[[table]]` の型の名前のキー、無ければ推定)で足す。
- 依存の矢印(`depends_on` の列)とクリティカルパス。棒の端のドラッグで日付を直す。

## 範囲外

- 履歴を要する図(バーンダウン)。
- 時間の単位は日・週・月。時刻の単位(時間)は扱わない。

## 前提(AI の仮定)

- 行の並びと親子・WBS は、表(ビューの設定)が作る行の木をそのまま使う(ガントで独自の並びを持たない)。
- 推定の列の名前の一覧は固定(GA-1)。外れたら印で上書きする。
