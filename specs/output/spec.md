# コピーと書き出し(output)

表の値を外へ持ち出す操作。版1はクリップボードへのコピーと、画面で選んだ行を標準出力に出す `--pick`(OUT-3)で、ファイルへの書き出しと貼り付けは次の段(画面を出さない表の出力は cli の CLI-5)。クリップボードは、ssh 越しや Wayland でも届くように、端末の仕組み(OSC 52)と OS のクリップボードの両方に送る(xleak・harlequin の教訓)。

強さの読み方: 「しなければならない」= 例外なし、「するべき」= 理由があれば外してよい、「してよい」= 任意。

## 要件: 版1 — コピー

| ID | 要件 | 例(確かめ方) | 決定 |
|---|---|---|---|
| OUT-1 | 選んだセル・行・選んだ複数の行を、タブ区切りでクリップボードにコピーできるべき(Ctrl+C と `y`)。クリップボードは OSC 52 と OS のクリップボードの両方に送るべきで、片方が失敗しても止まらずに知らせるべき。 | 2行を選んで `y` → 見出しつきのタブ区切り2行が OSC 52 で出る(`test_OUT_1`) | [2026-09-30](../_decisions/2026-09-30-v1-full-spec.md) |
| OUT-2 | 表のモードで、今画面に出している表(ビューの設定・簡易の絞り込み・一時的な並べ替え・隠した列・列の並びを当てたあとの行と列)を、ファイルに書き出せるべき。形はファイル名の拡張子(`.csv`・`.tsv`・`.json`・`.md`)で選び、値の書き方は `--print` の同じ形(CLI-5)と同じにし、ノートは書き換えないべき。 | status で絞った3行の表で、パレットの「表を書き出す」から `out.csv` → 見出しの行と3行の CSV。隠した列は出ない。`out.tsv` → タブ区切り。`out.txt` → 書かずに理由(`test_out_2_*`) | [2026-10-07](../_decisions/2026-10-07-export-table.md)、[2026-09-30](../_decisions/2026-09-30-v1-full-spec.md) |
| OUT-5 | 画面の表の書き出し(OUT-2)は、先頭の列に各行のノートのパス(`path`。`--print --with-path` と同じ)を入れ、書き出したファイルを `--apply` で戻せるようにするべき。ファイル名は起動したフォルダからの相対か絶対のパスとし、先頭の `~` はホームのフォルダにするべき。同じ名前のファイルが既にあれば、`y` で確かめてから上書きするべき。書いたら、書いた行の数とパスを知らせるべき。読むだけの起動でも書き出せてよい(ノートは書かない)。 | 書き出した CSV の1列目が `path`。`--apply` に渡すと差分なし。既にある `out.csv` → 確かめの問い、`n` で書かない。`~/out.csv` → ホームの下に書く(`test_out_5_*`) | [2026-10-07](../_decisions/2026-10-07-export-table-details.md) |

## 要件: 版1 — 標準出力

| ID | 要件 | 例(確かめ方) | 決定 |
|---|---|---|---|
| OUT-3 | `mdgrid [<.base \| フォルダ> …] --pick path\|<列の名前>` は、画面を端末(`/dev/tty`)に出して読むだけ(WB-15 と同じ)で開き、Enter で、印を付けた行(印が無ければ選んでいる行)ごとに、`path` ならノートのパス(起動の引数のフォルダにノートの相対のパスをつないだもの)、列の名前ならその列の値の素の文字(画面の印を付けず、null と空は空、リストは `, ` でつなぎ、日付は `YYYY-MM-DD`、改行は空白。CLI-5 の csv と同じ決まり)を、1行ずつ標準出力に出して終了コード 0 で終わるべき。`q` と、解くもの(印・範囲・絞り込み・検索)が無いときの Esc で取りやめたら何も出さずに終了コード 1 で終わるべき。標準出力がパイプでも動くべき(SR-10)。表に無い列の名前は CLI-4 と同じく理由1行と終了コード 2 にするべき。 | `mdgrid notes --pick path` で2行に印を付けて Enter → `notes/a.md` と `notes/b.md` の2行が出て終わる。印なしで Enter → 選んでいる行の1行。`--pick status` → 値が1行ずつ。`q` → 何も出ず終了コード 1。`--pick 無い列` → 理由1行と終了コード 2(`test_OUT_3`) | [2026-10-03](../_decisions/2026-10-03-pick-plain.md)、[2026-10-03](../_decisions/2026-10-03-print-pick.md)、[2026-09-30](../_decisions/2026-09-30-rename-mdgrid.md)、[2026-09-30](../_decisions/2026-09-30-v1-full-spec.md) |

## 要件: 次の段

| ID | 要件 | 例(確かめ方) | 決定 |
|---|---|---|---|
| OUT-4 | タブと改行で区切られた値を、ためる変更として、選んだセルから下へ複数の行に貼れてよい。 | 3行の値を貼る → 3つのためる変更(読んで判定) | [2026-09-30](../_decisions/2026-09-30-v1-full-spec.md) |

## 範囲外

- 採らない: 表計算の形式(xlsx など)への書き出し。

## 前提(AI の仮定)

- コピーの既定のキー(Ctrl+C と `y`)は Bases と vim の両方の流儀に合わせた(screen の SR-13)。
