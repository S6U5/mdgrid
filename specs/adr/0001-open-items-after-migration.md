# 0001: 移行で残した期限切れの未確定事項6件を決めて閉じる

- 状態: 採用
- 日付: 2026-11-18
- 決めた人: AI(依頼者が判断を任せた。2026-11-18 の依頼「あなたの思う進め方のベストを選べばいい。なのでこちらに聞き返す必要はないです」)。人の決定ではない

## 背景

trace-gate の形へ移したとき、人の判断を待つ未確定事項を9件置き、6件の期限を「main に取り込む前」にした。2026-11-18 に公開リポの main へ取り込んだ(#64)ので、6件の期限が過ぎた。残る3件(scope.command-column・cli.with-path-name-clash・navigation.problem-jump-filter-shown)は期限の無い製品の問いなので、未確定のまま残す。

## 決定

- P0 の選び分け(p0-selection): 仮の 51 件のまま P0 にする。51 件を1件ずつ見て、どれもデータの消失・ファイルの壊れ・上書きを防ぐ要求(書き戻しの安全・読むだけの起動・`--apply`・`.base` を書かない・読むだけのセル・キーとノートの名前の変更・CSV の書き戻し・スターターと書き出しの上書きの禁止)で、分ける前に人が P0 にした 23 件の文だけから成っていた。
- 秘密を置かない(scope.no-secrets-p0): P1 のまま。P0 は断言のあるテストで確かめられることが条件で、秘密の検査はアプリの振る舞いではなく CI の道具(秘密の走査)の役なので。
- 次の段の優先度(next-stage-priority): 仮の分け方(作っていないものは P2、作ってテストのあるものは P1・P0)にする。
- 断言を補助に任せた性質のテスト3本(rust-helper-asserts): 印を付けない。値の断言が無く「panic しない」だけを見るテストに印を付けると、確かめていない要求を確かめたと数えるので。
- セッション(cli.sessions): 作っていないので、次の段と同じ決まりで9件を P2 にし、要求の文は残す(作るときに P1 に上げてテストを書く)。今の実行ファイルに無い `-s`・`--session`・`--sessions` を、選択肢の要求(cli.options)の文から外して版を2にした(印のテスト8本はどれもセッションの選択肢を見ていないので、印を版2に替えた)。
- Windows(write-back.windows): Windows を対象に入れることは人が決めている(2026-10-14、docs/todo.md の O-11)。ハードリンクのあるノートを読むだけにする要求(write-back.refuse-unsafe-read-only)は P0 なのに、Windows ではハードリンクの数を取らず書いていた。決め直す問題ではなく実装の穴なので、`GetFileInformationByHandle` を直に呼んで数を取るように直した(依存は足さない)。Windows の CI のテスト(write-back.atomic-replace・write-back.keep-on-stop を含む書き戻しの試験と、足したハードリンクの試験)が通ることを、確かめたことにする。

## 理由

期限を過ぎた未確定事項を残すと、仮のまま固まって誰も決めない。6件とも、すでにある決まり(P0 はデータの消失とファイルの壊れ、作っていないものは P2、P0 は断言のあるテスト)か、人の前の決定(Windows を対象に入れる)から決められた。

## 選ばなかった案

| 案 | 選ばなかった理由 |
|---|---|
| 何もしない(期限を延ばす) | 期限が意味を失い、仮の値が決定のように扱われ続ける |
| P0 を分ける前の 23 件に絞る(分けた文のうち1つだけを P0) | 分けた文はどれも同じ書き戻しの安全の一部で、どれか1つを P1 にすると、その文の壊れは P0 の確かめから外れる |
| セッションを要求から消す | 人が前に版1で書いた機能で、作らないとは決めていない。消すのは製品の判断なので、優先度だけを作っていない形に揃えた |
| Windows ではハードリンクの見分けを諦め、要求に Windows を除くと書く | P0 の守りを弱める。std の機能が不安定でも、Win32 を直に呼べば依存を足さずに取れる |

## 影響

P0 は 51 件のまま。P1 のうち9件(セッション)が P2 になり、テストの無い P1 が減る。Windows でもハードリンクのあるノートを書かなくなる。見直す条件: 人が P0 の選び方を変えるとき、セッションを作るとき、Windows の CI でハードリンクの試験が落ちるとき。
