# セルの編集とリストからの選択(cell-edit)

表のセルを選んで、その場で値を直す。直した値はすぐにはファイルに書かず、保存の操作までためておく([write-back](../write-back/spec.md) の WB-9)。値の種類に合わせて、打つ・リストから選ぶ・切り替える・日付を入れる、の入り方を変える。キーの割り当ては [screen](../screen/spec.md)、行の選び方は [navigation](../navigation/spec.md) にある。

強さの読み方: 「しなければならない」= 例外なし、「するべき」= 理由があれば外してよい、「してよい」= 任意。
